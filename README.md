## 简介

面向男性用户的中文情感聊天知识库,围绕三类真实需求构建:

1. **会聊**:开场白、话题库、接话公式、情绪价值、幽默技巧、升温节奏(01/02/05 板块);
2. **看人**:四类人群画像(精神小妹 / 大学生 18-24 / 都市 24-32 / 轻熟龄 32-40)、MBTI/DISC/星座适配(03/04 板块);
3. **防坑**:网络交友"被当 ATM"的信号识别、灰色收割模式、杀猪盘/酒托识别、拒绝止损话术,以及 16 种情感操控战术的识别与反制(06/07 板块)。

> 内容边界:操控类知识仅以"识别 · 机制 · 反制"防御形式收录;星座内容标注"娱乐化参考";盗版书籍零搬运(仅书目情报与原创摘要)。

## 快速开始

```bash
# 关键词检索(零依赖,Python 3.8+)
python 索引/search.py "对方总暗示要礼物" --top 5
python 索引/search.py "大学生 开场" --tag 清单 --json

# 格式自检 / 生成元数据索引
python 索引/check.py
python 索引/build_metadata.py
```

也可以把整个目录导入 Cherry Studio / AnythingLLM 等本地知识库软件,或让任意本地 AI 助手读 `索引/metadata.json` 后按标签(人群/阶段/严重度/置信度)取用条目。

## 条目格式

每个条目为带 YAML frontmatter 的 Markdown 文件:`id / title / tags / audience / stage / type / severity / source / confidence`,支持结构化过滤与全文检索双通道。规范详见仓库内各层 README 说明。
