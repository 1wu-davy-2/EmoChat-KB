## 简介

面向成年用户(18+)的中文情感聊天知识库,围绕四类真实需求构建:

1. **会聊**:开场白、话题库、接话公式、情绪价值、幽默技巧、升温节奏,以及信任修复、边界与长期关系经营(01/02/05 板块);
2. **看人**:四类基础人群 + 26 类处境画像(分手恢复 / 单亲带娃 / 长期单身 / 异地跨文化 / 高压轮班 / 内向慢热 / 性少数 / 已婚 / 恋爱中 / 订婚备婚 / 同居 / 育儿期 / 复合拉扯 / 分居未离 / 相亲介绍 / 重组继亲 / 年龄差 / 丁克不婚与生育分歧 / 中老年再伴 / 慢性病残障与照护 / 失业负债 / 伴侣抑郁焦虑 / 暧昧未定义 / 跨城婚姻 / 伴侣双相 / 出轨修复期)、MBTI/DISC/九型人格/星座使用手册,以及大五人格、高敏感与黑暗三角特质识别(03/04 板块);
3. **防坑**:网络交友"被当 ATM"的信号识别、灰色收割模式、杀猪盘/酒托识别、拒绝止损话术,数字隐私、经济控制与跟踪骚扰的应对,性侵/性骚扰、骗婚彩礼、中老年养老诈骗、传销邪教灵修、网络霸凌与二次收割的识别,以及职场性骚扰、偷拍、投资杀猪盘变种、冒充身份、医美/培训贷、刷单引流、跨境婚恋、咨询中的性剥削、报复性私密影像与自杀风险转介,并附 42 种情感操控战术与灰岩法/断联反制工具(06/07 板块);
4. **选配**:用户侧性别、年龄带(18+)、星座、性取向、亲密偏好、情感需求、关系状态、婚育价值观、消费观、沟通风格、隐私安全偏好与时间预算,供 AI 按组合规则生成适配建议(12 板块)。

## 快速开始

```bash
# 关键词检索(零依赖,Python 3.8+)
python 索引/search.py "对方总暗示要礼物" --top 5
python 索引/search.py "大学生 开场" --tag 清单 --json

# 格式自检 / 生成元数据索引 / 检索验收
python 索引/check.py
python 索引/build_metadata.py
python 索引/acceptance_run.py   # 215 个查询的 top3 命中验收(含 v9 精确 ID 校验)
```

也可以把整个目录导入 Cherry Studio / AnythingLLM 等本地知识库软件,或让任意本地 AI 助手读 `索引/metadata.json` 后按标签(人群/阶段/严重度/置信度)取用条目。

## 条目格式

每个条目为带 YAML frontmatter 的 Markdown 文件:`id / title / tags / audience / stage / type / severity / source / confidence`,支持结构化过滤与全文检索双通道。`audience` 除人群标签外,还支持 `[用户侧]` 供 12 板块选配。规范详见 `知识库格式说明.md`。
