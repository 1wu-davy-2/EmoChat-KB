# 表情包、语气词与回复节奏

## 表情包使用
1. **是社交货币,不是装饰**:对 18-24 人群,接得住她的表情包 ≈ 聊天能力合格;她抛的梗务必接住。
2. **数量节制**:一条消息配一个表情足够;表情包轰炸 = 用热闹掩盖没话说。
3. **质量分级**:通用可爱/搞笑款最安全;涩图、擦边图、含人身攻击的梗图不发。
4. **建立专属梗**:暧昧期把你们的某张图/某句话反复用,形成"只有我们懂"的专属感。

## 语气词校准
- 匹配对方能量级:她用"哈哈哈"+ 语气词,你就别端着书面腔;她整句表达,你别满屏"哈哈哈"。
- 忌两种极端:官方腔("请问您今天方便吗")和过度卖萌腔("好哒么么哒"连发)。
- 精神小妹/大学生人群吃网络语气("绝了""家人们");轻熟龄人群少吃,整句表达更稳。

## 回复节奏(频率本身就是信息)
1. **别秒回绑架**:每次秒回会建立"随叫随到"的预期,偶尔隔一段再回是正常生活感。
2. **也别故意拖延**:刻意装忙=制造虚假稀缺,被识破即出局(见 tactic-003 边界)。
3. **跟对方节奏走**:她回得慢你就放慢;她热络你升温——节奏匹配 > 节奏操控。
4. **在高点结束**:一轮聊得正好的时候主动收尾("我先去忙个事,晚点聊"),比聊到枯竭更好。
5. **晚安是句号不是省略号**:她发晚安就体面结束,别追发。

## 一条自检
把你们最近一轮聊天截图拉出来看:表情包密度、语气词风格、回复间隔是否大致对称?**长期单向迎合对方节奏 = 把遥控器交了出去。**
