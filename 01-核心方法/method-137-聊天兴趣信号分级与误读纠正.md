## 是什么

把"她对我有没有兴趣"这个模糊问题，拆成**可观察的行为信号 + 分级 + 对应的下一步动作**。目的不是给谁打分，而是解决两个反复出现的错误：

- **把礼貌当喜欢**，于是一直推进、造成对方压力；
- **把慢当不喜欢**，于是一有延迟就退场、误伤本来有机会的关系。

三条使用前提：

1. **看组合，不看单条**。任何一条信号都不构成结论，至少看两周、看五轮以上互动。
2. **看趋势，不看切片**。"上周还行这周变淡"比"这周只回三次"信息量大。
3. **看互惠，不看热度**。兴趣的核心指标不是回得多快多热情，而是**她有没有也在往这段对话里投入**（主动开启、给信息、约时间）。

## 三级信号

### 绿：真实的兴趣信号

| 信号 | 为什么算 | 需要注意 |
|---|---|---|
| 主动开启对话（不只在被问时答） | 需要她先想到你，才会先发消息 | 一周一次也算，看是否持续 |
| 反问与追问细节 | 说明她在把你的话当内容，而不是当噪音 | 反问后是否真的听你答 |
| 记住你说过的小事并问回来 | 记忆需要投入，最省事也能装不出的指标 | 记错也没关系，重点是她在核对 |
| 主动分享（照片、链接、日常琐碎、自己的情绪） | 分享是把自己的一部分交出来 | 群发式转发内容不算，要看来向你的、带说明的 |
| 提出见面或接受具体邀约并给替代时间 | 从语言变成行动 | "改天吧"没有具体时间，不算这一条 |
| 愿意让话题变深（观点、感受、期待） | 见 method-011 的问—听—回应—分享循环 | 深聊不等于已经决定在一起 |

### 黄：不能定性，需要观察

- **礼貌性回复**：每次都回，但只有答案没有内容，从不反问。
- **短句**：「哈哈」「是的」「好的」「确实」。一次不算，连续多轮才算。
- **慢回但有实质内容**：隔三小时回你一大段——这是节奏问题，不是兴趣问题。
- **只在固定时段活跃**：可能是工作节奏、通勤、带娃、轮班。
- **只聊自己**：可能是兴趣不足，也可能是社交经验少、不擅长问别人。
- **接受邀约但从不主动开启**：可能被动型互动习惯，也可能只是不排斥。

黄的处置只有一句话：**降低推进强度，保持一次内容型互动，观察两周**。不要加码，也不要立刻退场（冷激活可参考 scene-010）。

### 红：低兴趣或消耗型

- **长期已读不回**，只在你想推进时才出现。
- **只在需要时联系**：投票、砍价、助力、借钱、帮忙改方案、情绪崩溃时的深夜倾倒。
- **反复取消且不给替代时间**：一次是意外，三次是选择。
- **只索取不分享**：全程你说，她只评价；或全程她倾诉，你只当听众。
- **拒绝所有媒介升级与见面**，同时保持线上热度（不定义、不负责、不退出）。
- **明确说过"别等我""我最近不想聊"，你仍在持续投入**。
- **一提关系或节奏就转话题、嘲讽、说你想多了**。

红不等于"她坏"。多数时候只是不匹配、或她自己也没想清楚（长期停在暧昧不定义的状态，需要评估是否被面包屑式撩拨维持，见 tactic-023）。红的作用是**让你停止追加投入**，而不是让你去质问。

## 常见误读纠正

| 常见读法 | 实际情况 | 更稳的判断方式 |
|---|---|---|
| 「她回得很快，说明喜欢我」 | 秒回常等于当下有空、手机在手、或礼貌。闲时的人回得快，忙时的人回得慢，与感情无关 | 看她回**什么**：快而空的回复不如慢而实的回复 |
| 「发表情包/笑脸=暧昧」 | 表情包在很多人的日常表达里就是标点符号，中年用户尤其常用微笑当"收到" | 看是否配上只针对你的内容；单看表情极易误判 |
| 「'哈哈哈哈哈'越长越有意思」 | 长度常是打字习惯与语气礼貌；有人习惯性堆笑避免尴尬 | 看笑完之后有没有实质内容和反问 |
| 「她每条故事都回我=在关注我的生活动态」 | 她可能只是把故事当内容消费，看完就划走；对所有人一视同仁 | 看是否会主动提起你故事里的细节并问回来 |
| 「她肯出来见面=默认可以亲密」 | 见面只等于愿意见面。任何身体接触需要当下的、可撤回的同意 | 不推断；亲密话题在关系明确后再谈 |
| 「她给我发得比较露骨=同意发生性关系」 | 性暗示、调情与同意是三件事。暧昧语言不构成对具体行为的同意，同意也可随时撤回 | 需要明确、具体、当下的确认；含糊即视为未同意 |
| 「她回得慢就是不想理我」 | 常见原因是工作、育儿、睡眠、抑郁、社交耗电、手机不在身边 | 看两周趋势与内容质量，不看单次延迟 |
| 「她答应我不拒绝=喜欢我」 | 很多人（尤其面对强势、上级、经济或身份不对等者）会用"不拒绝"来降低风险 | 只看主动投入的行为，不看没有说"不" |
| 「她之前很热现在冷了，肯定有事」 | 可能是生活事件、也可能是原本的热是新鲜感 | 直接问一次，得到答案就接受，不反复试探 |
| 「我加了这么多投入，她总该有点感觉」 | 投入不产生对方的义务，容易演变成付出账本 | 互惠看对方是否也在投入，不看自己投入总量 |

**关于"读空气"这件事本身**：非语言线索在文字聊天里天然缺失。常被引用的"文字只占沟通的一小部分"这类结论来自特定实验条件（情绪与态度的判断任务），不能拿来推断"文字聊天读不出兴趣"或"她说话内容不重要"。在文字场景里，**内容＋行为**才是可用证据。

## 个体差异：同一行为的不同含义

**内向与社交焦虑**
- 回复慢、语音电话回避、见面前反复改期，可能是对被评价的恐惧，而不是没兴趣。
- 内向者在文字里往往更深、更长；不要把"线上很能说、线下很安静"当矛盾。
- 不要追问"你为什么不能打个电话"，可以换成"我们试试语音十分钟，不方便就继续打字"。

**神经多样性（自闭特质、ADHD 等）**
- 平铺直叙、不发表情包、不回故事，可能是表达风格；过长消息会被漏看，也可能因专注力分散而长时间不见。
- 对含糊暗示接收不到——所以**对这类对象更要说清楚**，不要用"你猜""你应该懂"制造误解。
- 反过来，"她很直接是不是就是对我有意思"也常错：直接可能只是她的沟通方式。
- 不做诊断，不用"你是不是有情况"当解释；以对方自己的描述为准。

**工作与生活节奏**
- 医护、轮班、育儿期、备考、异地项目期，回复窗口会整体后移且不规则。
- 判断标准：忙的时候她有没有一句"我这周特别紧，下周找你"这类**带未来指向的说明**。有说明通常是节奏问题，只有消失才是兴趣问题。

**文化与性别社会化**
- 很多人被教养要求"不主动、不表态"，尤其涉及婚恋话题；被动不等于低兴趣。
- 也有人被要求"对陌生人的接近保持礼貌"，因此她的热情可能是自保程序，不是好感（这一条最容易造成严重误判）。

**关系阶段**
- 刚认识两周的热度，与认识半年后的热度，不能用同一把尺。早期高频率常常只是新鲜感。

## 下一步该做什么 / 不该做什么

| 当前信号 | 该做 | 不该做 |
|---|---|---|
| 绿（持续两周以上） | 推进一层：加深话题、约一次具体时间的见面 | 突然表白或要求定义关系，把节奏拉满 |
| 黄 | 降一档推进强度，做一次内容型互动，观察两周 | 连发消息测试、故意冷淡逼她主动、找朋友代打探 |
| 红（只在需要时联系） | 直接问一次"我们是不是节奏不太合"，或安静退出 | 追问、指责、卖惨、用长文复盘自己的付出 |
| 红（反复取消） | 停止由你发起邀约；把主动权交回去一次 | 追加"那你说个时间"式的连环确认 |
| 明确拒绝 | 一句"好的，明白"，然后真的停止 | 换话题继续、隔两周再试、开小号 |
| 自己不确定 | 提一个低压力、可拒绝的具体邀约，用行为代替猜测 | 分析截图、找六个朋友复盘、上论坛问"这是什么意思" |

**最省时间的一步**：与其反复解读，不如发出一个**低压力、有具体时间、可拒绝**的邀约。回应行为（来了/不来但给替代时间/不含糊也不承诺）比十条消息更能说明问题。

## AI 判定规则

**输入要素**：互动时长与轮次、谁主动开启、回复内容是否具体、是否有反问与记住细节、邀约响应模式、对方是否明确说过不要、是否存在不对等（身份、经济、年龄、粉丝量）。

- **判绿**：多项绿信号持续两周以上，且无红信号。
  → 输出：建议推进（加深话题或提具体邀约），并提醒不要用高频确认破坏节奏。
- **判黄**：只答不问；慢回但实在；只在你发起时出现；无法判断趋势。
  → 输出：明确要求用户"降低推进强度并观察两周"；不生成加码话术；提示可能的个体差异（工作节奏、内向、表达风格）。
- **判红**：长期已读不回、只在需要时联系、反复取消不给替代、明确拒绝后仍有投入。
  → 输出：建议停止追加投入与退出；不提供"如何让她回心转意/如何逼她回应"的话术；说明"不拒绝"不等于同意。
- **风险联动**：对方只在涉及钱、投资、博彩、代购、转账、下载陌生 App 时出现 → 优先按诈骗信号处理并提示红线（risk-001），不要继续分析兴趣。
- **骚扰拦截**：若用户的"下一步"是换号添加、去其他平台找、蹲点、找朋友施压、公开评论区追问 → 直接拒绝并给安全与举报路径（scene-010 只适用于正常冷场，不适用于已明确拒绝的对象）。
- **禁止诊断**：不用 MBTI、星座、人格障碍名词给任何人下定论；个体差异只作为"需要确认"的理由，不作为结论。
- **表述要求**：给用户时先说"这条证据强度如何"，再说"所以建议的下一步"，避免让用户把 AI 的输出当成对方的真实想法。

## 边界

兴趣信号分级是**降低误判的工具**，不是给对方打分或做进度管理。它有三条硬边界：

1. 不能用来推断性同意。任何身体与性方面的接触都需要当下、具体、可撤回的确认，历史聊天热度不构成同意。
2. 不能用来合理化持续索取。判红之后继续加大投入，就是明知对方不给回应还推进。
3. 不能替代直接沟通。分级只负责帮你看清模式；真正重要的问题（是否想继续、想什么关系）要用一句可拒绝的直问去核对。
