# 升温节奏:小步试探-看反馈-调整

## 三阶段节奏
1. **刚加上**:朴素问候,不急着表现("Hi"+表情包即可)。
2. **聊过几次**:分享自己 + 从朋友圈找话题 + 请教她擅长的 + 勾好奇("发现你一个特点").
3. **有好感后**:才进入调侃/暧昧,且**把她的反馈当交通规则**——她接得住才继续,接不住退回普通聊天。

## 核心机制:验证-调整循环
聊天的核心是**建立信任**而非传递信息。用小范围试探观察反应:
- 反应积极 → 自然拉近话题距离(更私人一点);
- 反应冷淡 → 保持分寸退回。
这个"试探→看反馈→调整"的循环是升温的关键机制——一次只推进一小步。

## 话题分层递进(公共 → 私人)
工作/日常 → 生活方式/兴趣爱好 → 价值观/情感观 → 私密话题,逐层递进:
- 每次推进一小步,观察对方是否**也抛出私人信息**(互惠即同意深入);
- 对方只接不回(不给你任何私人信息)= 还没到下一步。

## 降档信号(必须会读)
- 对方回复变短/变慢 = 降档信号 → 回到轻松公共话题或体面收尾;
- 不连续试探、不纠缠;同一话题她没接,不硬掰回来。

## 节奏红线
- 查户口连环问(见 persona-005);
- 过度自我展示成"个人演讲";
- 过早暧昧(对方未释放好感信号时);
- 消息轰炸/秒回施压——频率本身就是节奏的一部分。
