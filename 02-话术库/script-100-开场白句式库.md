# 开场白句式库

> 原则:开场白只是"聊天启动器",让对方容易接话即可;朴素最安全,别寄予厚望。

## 刚加上(朴素模式)
1. "Hi / 哈喽 / 你好" + 一个打招呼表情包
2. 分享幽默内容 + 自己的一句点评

## 聊过几次(分享/勾好奇模式)
3. **分享自己**:"我今天收到个快递,商家竟然调皮地给我包装套包装,连着弄了 3 层"
4. **朋友圈切入**:"发现你个特点" → "啥?" → "看你朋友圈发现你是个吃货哦"
5. **请教她擅长的**:"你知道吉他的和弦怎么按吗?"(让她获得小小的价值满足感)
6. **勾起好奇**:"问你个问题"(只说一半)/"我发现了一个你跟别人不一样的特点"
7. "你朋友圈的照片好漂亮"(明知是套近乎,听着还是开心)
8. "我猜你是一个吃货"(猜测式提问引发好奇)
9. "哈哈,原来你是夜猫子"(深夜发朋友圈时,别漫无目的发"在干嘛")
10. "加了微信不说话是因为害羞吗"(对方加了你却不说话时)
11. "这首歌我也很喜欢听哦"(先看她的歌单/朋友圈音乐)

## 已有好感(轻调侃模式,她接得住才继续)
12. "和你说话你都不理我,你是不是不会打字呀"
13. "明天要穿得美美的来见我~"(已约见面前)

## 开场三模式(豆瓣)
**表情包套路 / 寻求帮忙 / 分享内容**——任何开场都落在"给她一个容易接的话"上。

## 禁忌
- "在吗""吃了吗""在干嘛"三件套(除非已熟悉);
- 一上来要照片、查户口式连环问;
- 连续发消息不等回复、一上来发长语音。
