# 性需求沟通

> 国际性医学学会(ISSM):伴侣性欲水平不同是**普遍现象,不是病理问题**。戈特曼研究所称之为"永久性差异"——目标不是消灭差异,而是共同管理它。

## 沟通时机与原则
1. **不在床上谈**:选平静、无压力的场合(散步、饭后),别在亲密前后谈敏感话题——那时任何话都容易被当成评价。
2. **去人格化差异**:"你最近不想要"≠"你不爱我了"。压力、睡眠、激素、健康都影响欲望,**先假设原因在处境,不在感情**。
3. **用"我"语句**:"我最近很想和你更亲近一些"而不是"你总是没兴趣"(后者是指责,触发防御)。
4. **聊感受不聊评分**:不比较、不打分、不引用"别人家"数据——比较是亲密话题的第一雷区。

## 打破"追求-回避"循环
- 常见僵局:一方越施压 → 另一方越退缩 → 施压方更焦虑 → 循环加剧。**双方都要为这个模式负责,而不是其中一个人"有病"**。
- 解法:施压方降低"必须"感(亲密不只有一种形式);回避方主动给出非压力的亲近信号(拥抱、依偎),让连接不断档。
- 扩展亲密定义:按摩、同浴、长吻都是连接;非性接触积累足够,性张力反而更容易回来。
- 戈特曼建议"无压力的亲密时间":约定一段时间只亲近不推进,移除表现焦虑。

## 谈癖好/新想法的阶梯(伴侣间)
1. 先聊"氛围与感受"("我喜欢和你……的时候"),再聊具体想法;
2. 用"读到/看到一种说法"做缓冲引入话题,观察对方反应;
3. 对方感兴趣 → 谈边界与安全词(见 intimacy-003);对方不感兴趣 → **"不"就是完整答案**,不追问、不反复提;
4. 差异长期无解且造成痛苦 → 找正规性治疗师/伴侣治疗(Gottman 方法、性医学门诊),而不是自耗。

## 红线
- 以拒绝亲密作为惩罚/筹码 = 冷暴力变体(tactic-006);
- 强迫、纠缠、拿"爱不爱"绑架对方接受任何性行为 = 性胁迫,法律与关系双重红线。
