# 家庭角色与分工期待

> 这一页记录用户对“婚后谁做什么、谁决定什么”的期待，以及自己实际能做到多少。它是协商的起点，不是评分表，更不是“好妻子/好丈夫”的标准答案。允许写“没想好”，也允许同居后再改。

## 一、维度定义

家庭角色与分工期待包含五块：

1. **家务**：做饭、清洁、洗衣、采购、维修、宠物照料，以及安排这些事的“隐形脑力”。
2. **育儿**：接送、辅导、陪玩、就医、与老师沟通。
3. **照顾父母**：日常探望、陪诊、经济支持、临终照护。
4. **财务决策**：日常开支、大额支出、投资、借贷由谁拍板。
5. **对外事务**：人情往来、节日安排、与双方家庭沟通。

每一项都要区分三层：**理想期待**（希望怎样）、**实际能力**（能做到多少）、**不可接受**（哪些安排会让用户长期委屈）。只看第一层，容易谈成空话。

## 二、常见取值

| 取值 | 具体表现 | 对沟通与建议的影响 |
|---|---|---|
| 传统分工 | 一方主要赚钱，一方主要家务与育儿 | 需明确主内劳动的价值、财务支配权与重返职场可能，避免无偿化 |
| 平等协商 | 按时间、能力、偏好分配，定期调整 | 必须落到任务清单，否则“平等”常落在一方身上 |
| 一方主内，不分性别 | 谁收入低或更愿意，谁主内 | 需谈社保、个人账户、职业中断成本，保留独立经济能力 |
| 双职工加外部帮手 | 请钟点工、托育、长辈帮忙 | 需谈外包费用、决策权，以及长辈介入的边界 |
| 高度独立 | 财务与家务各自负责，互助按需 | 适合边界清晰的人，但要防止“各过各的”导致关系空心化 |
| 尚未想清楚 | 没有明确偏好，看对方与实际情况 | 先做一周家务记录再谈，不急着承诺，也不被催着表态 |

## 三、对沟通、择偶与关系节奏的影响

**沟通方式。** 用“谁在什么时间做什么”替代“你应该多分担”。例如把“你从不做家务”改成“工作日做饭和倒垃圾能不能一人一项，周末一起做一次大扫除”。具体任务比道德指责更容易被接住，也更方便复盘。

**择偶判断。** 分工期待比抽象“三观”更日常。建议观察对方在原生家庭里是否被照顾惯了、是否会把安排家务当成“帮忙”、遇到脏活累活是否自然接手。观察可以，但不要用一次表现下结论。

**关系节奏。** 同居是分工的试运行，建议先约定一个月的试行期，每周花十五分钟复盘：哪些任务没人做、哪些做了但没被看见、哪些需要外包。订婚、备孕、接父母同住是三个需要重新分工的节点。

**财务决策。** 分工与钱权常绑在一起。谁管日常账、谁管大额、超过多少金额需要双方同意，建议写成简单规则。主内一方应有可自由支配的钱和独立账户，降低经济依赖风险。

## 四、与其他维度的组合规则

- **与 method-114 家务分工与情绪劳动**：本页记录期待，method-114 提供把期待变成清单与复盘流程的方法，两者配合使用。
- **与 user-012 财务边界、method-113**：分工包含“谁管钱”。先有预算与账户安排，再谈谁做主，避免“主内就等于没话语权”。
- **与 user-015 时间预算**：按双方真实可用时间分配，而不是按性别或“谁更细心”。通勤长的一方可以少做家务，但应承担其他任务。
- **与赡养老人**：照顾父母是独立任务，不应默认由“更闲”或“更会照顾人”的一方承担，可参考 persona-026。
- **与育儿安排**：谁接送、谁辅导、谁参加家长会，需与教育路线一起排，可参考 persona-018。
- **与 persona-018 育儿期**：有孩子后任务量陡增，建议在孕中期就重排分工，不等矛盾爆发。
- **冲突处理顺序**：先补上没人做的任务，再谈公平感；长期失衡且对方拒绝协商，才进入关系去留的讨论。

## 五、AI 调用示例

**示例一：一方要求主内**

用户自述：“对方希望我婚后辞职带孩子，我不太愿意，但又怕伤感情。”

建议调整：不评判传统或现代分工。列“辞职的代价”：收入中断、社保与公积金、职业连续性、决策权变化、重返职场难度；再列替代方案：产假与育儿假如何分配、托育、长辈短期帮忙、兼职或远程。把选择权交回用户，不用“独立女性就该怎样”施压，也不美化“为家庭牺牲”。

**示例二：说好平等，实际一人做**

用户自述：“我们一直说平等分工，但家务还是我全包，对方说自己工作更累。”

建议调整：先做一周任务清单，标出每项耗时与频次，用数据替代互相指责。按“时间可用量 + 偏好”重分，明确三项必须转移的任务和一项可以外包的任务（钟点工、洗碗机、保洁）。设每周十五分钟复盘，持续四周。若对方拒绝任何调整，讨论的是意愿问题，不再是技巧问题。

## 六、边界：不是标签

- 不评判“谁更应该”做家务或带孩子，不按性别分配角色。
- 不把主内劳动说成“没贡献”，也不把主外说成“免家务通行证”。
- 不把分工方式当爱的度量：愿意多做不等于更爱，要求公平也不等于计较。
- 不用“别人家都这样”压人；每个家庭的收入、时间、健康条件不同。
- 不鼓励用户为了维持关系放弃全部经济独立；涉及上交工资、查账、禁止工作，参考 risk-013。
- 用户说“没想好”时，不替用户选一个“正常”答案，给试验与复盘的余地。
