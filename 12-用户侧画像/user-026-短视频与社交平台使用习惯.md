# 短视频与社交平台使用习惯

> 这一页记录用户自己在短视频与社交平台上的使用方式，用来让 AI 的建议贴合"你在哪个场域、用什么语气、能接受多快的推进"。它不是对"刷视频的人"的评价，也不用于推断人品、智力或感情忠诚度。平台习惯可以随时改变，填一部分也可以。

## 一、字段说明

- **常用平台**：抖音 / 快手 / B 站 / 小红书 / 视频号 / 微博 / 豆瓣 / 知乎 / 播客 / 社交软件（探探、Soul、青藤、Bumble 等）/ 不用。可写主次，例如"主 B 站、次小红书"。
- **使用频率与时长**：几乎全天刷 / 每天 30 到 60 分钟 / 只在通勤或睡前 / 一周几次 / 只看不发。
- **内容偏好**：知识与技能、职场与行业、兴趣爱好（摄影、健身、游戏、宠物、手工）、生活记录与 vlog、情感与心理、同城与探店、搞笑、影视解说、学习备考。
- **是否公开露脸**：完全不出镜 / 偶尔侧脸或背影 / 只发物品与文字 / 从不发布内容（只看不发）。
- **发布频率与互动习惯**：会评论、会回复陌生人评论、只在熟人圈互动、只点赞不评论、开了"仅关注人可私信"、关闭私信。
- **是否接受私信（及方向）**：接受陌生人私信 / 只接受有来由的私信（咨询、同好、合作）/ 完全不接受 / 自己会主动私信别人 / 从不主动私信。
- **线上社交目的**：获取信息 / 找同好交流 / 记录生活 / 做内容或副业 / 认识潜在伴侣 / 单纯消遣。目的不同，可推进的空间完全不同。
- **可投入的时间段**：几点到几点通常在线、是否轮班、周末是否可用。
- **对线上认识人的态度**：可以发展成线下关系 / 只愿意当网友 / 看具体人 / 明确不接受。

## 二、常见取值组合

| 类型 | 典型填法 | 对建议的影响 |
|---|---|---|
| 重度观看、低暴露 | 全天刷 B 站＋小红书，只看不发，不开私信 | 建议以"内容型评论"起步，不假设 TA 会被陌生人私信接住；推进节奏偏慢 |
| 兴趣深耕型 | 每天固定看某垂类（摄影、健身、编程），会认真回评论 | 可从具体问题切入，话题延续性最好；不必刻意聊感情话题 |
| 创作者／副业型 | 自己每周发内容，主页写了"合作可私信" | 互动有明确门槛与来由即可；提醒把私人频道和工作频道分开 |
| 同城生活型 | 主要刷同城、探店、活动召集 | 线下邀约的合理化路径最多（活动、市集、课程）；安全动作照做 |
| 熟人圈型 | 只在朋友圈和群里互动，公开信息少 | 不要建议在公共评论区聊私人内容；转私聊要有来由 |
| 回避型使用 | 不装短视频 App，或只看不用 | 不要在建议里默认"发个视频看看彼此"；实时沟通需先问接受度 |
| 高需求低边界 | 大量私信陌生人、同时聊很多人 | 提醒节奏与专注度对对方的影响，以及多线并行要说清（诚实优先） |

## 三、对 AI 建议的影响

**语气与内容形态。** 平台决定了什么话"自然"。B 站/知乎偏具体信息与梗；小红书偏场景与经验细节；抖音/快手偏短、直接、口语；视频号偏熟人与家庭可见，公开互动更谨慎；豆瓣偏兴趣与长文本。同一句"我看完你的东西觉得有用"，在各平台的措辞长度和表情包使用都不同。

**推进节奏。** 用户在平台上是"高频在线"还是"一周几次"，直接影响合理的回复间隔预期。不要把"两小时没回"读成冷淡；也不要建议高频用户去要求低频用户实时回复（联系节奏见 user-009）。

**隐私与暴露度。** 露脸与否、是否发布同城定位，决定建议里能否出现"评论区聊""合照""打卡"等动作。公开露脸多的人，被熟人看到的概率也高，谈感情话题时要考虑可见范围（见 user-014）。

**私信可行性。** 若用户填写"不接受陌生人私信"，AI 不应给"私信切入"的话术，改为评论区或平台内活动；若用户填写"只接受有来由的私信"，任何私信建议都必须自带理由与退出口。

**识别诈骗（重点）。** 高频刷短视频、并且开始被陌生人主动私信的用户，遇到引流的概率更高。建议里要包含这几个固定提醒：
- 认识不久就带你投资、荐股、USDT、期货带单、博彩"漏洞"、内部申购：停止并拨 96110（见 risk-031）。
- 要求下载不明 App、共享屏幕、代充值、刷单做任务：视为收割路径。
- 迅速升温、几天内叫配偶称呼、要求转到别的平台私聊：情感引流的常见开局。
- 索要验证码、账号密码、手持身份证照片、私密影像：一律不给（见 risk-012、risk-016）。
- 判断标准是"要不要花钱、要不要交出凭据、要不要脱离平台"，而不是"聊得像不像真人"。

**当用户是接收方。** 若用户描述的是"有人在评论区/私信反复找我"，AI 先按被打扰处理并给停止、取证、举报的建议，不做"你是不是回复太慢"的分析。

## 四、组合规则

- **与 user-009 沟通能量**：平台使用时长不等于聊天意愿。深夜刷视频的人可能白天完全不看消息；联系频率以双方确认过的时段为准。
- **与 user-007 当前情感需求**：如果目的写的是"消遣""找同好"，AI 不把任何互动默认解释为择偶信号；如果目的是"认识潜在伴侣"，也要提醒对方未必同目的，不能从"她回我评论"倒推兴趣。
- **与 user-014 隐私与安全偏好**：本页记录平台行为，user-014 记录可披露的边界。露脸与否不改变"不发私密影像、不给住址单位"的默认规则。
- **与 risk-031 及其他 06 板块条目**：涉钱、涉投资、涉账号凭据的情况一律优先按风险处理，不再讨论聊天技巧。
- **与平台差异（method-105）**：不同平台的可达性与互动成本差别很大，具体跨平台策略以 method-105 为准；本页只记录用户自己的习惯。
- **多平台用户**：需注明"哪个平台用来做什么"，例如"B 站看内容、微信只和熟人"。AI 建议的转平台动作应以此为准，不假设"我微信比较方便"适用于对方。
- **变更**：换工作、搬家、进入或结束一段关系后，本页建议复核一次；平台设置与个人习惯都会漂移。

## 五、AI 调用示例

**示例一：线上转私聊的建议**

用户自述：每天刷 B 站和小红书约 1 小时，只看不发，不接受陌生人私信，但欢迎同好在评论区聊技术；目的是找同好。

建议调整：不给"私信开场"话术；给评论区里的具体内容型留言，并明确"对方只答不问就停在评论区"；不把回复解读为择偶信号；提醒不要因为想认识人而绕开自己设的私信边界（例如开小号看别人私信）。

**示例二：高频用户遇到主动私信**

用户自述：我做家居类短视频，每周更新，主页写了可合作私信；最近有人私信聊得很好，两天就提出见面并推荐一个"内部申购"。

建议调整：先按风险处理——涉钱即停，不因聊天热就降低判断（risk-031）；见面仍按公共场所、短时长、自主往返、告知朋友执行；给一句把话题拉回正轨的话术："聊内容和家居方案都可以，投资类我不参与，也不接这类推荐。"同时提醒把合作咨询与私人往来分开，避免"合作者"与"潜在伴侣"两条线混淆。

## 六、边界：这一页不做什么

- 不给用户贴"沉迷短视频""不上进"之类的判断；使用时长与人格无关。
- 不假设平台使用习惯能预测忠诚度、稳定性或性观念。
- 不建议任何形式的规避平台规则（拆字、谐音、图片藏号、绕开私信限制）。
- 不建议跨平台搜索或接触对方，也不建议用大号小号并行联系同一人（见 risk-015）。
- 不假设"线上活跃=愿意被搭讪"；公开表达内容不等于开放私人接触。
- 未成年人不做恋爱向建议；涉及未成年信号只保留安全与求助路径。
