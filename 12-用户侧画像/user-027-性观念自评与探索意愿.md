# 性观念自评与探索意愿

> 面向 18 岁以上成年人。这一页记录用户自己怎么看"性"这件事、愿意聊到什么程度、愿意走多快，用来让 AI 调整开口方式与节奏。它是自评，不是诊断，也不是标签；同一个人不同阶段可以填得不一样。所有条目都以成年人自愿、知情、可撤回为前提。

## 一、字段说明

- **成长背景影响**：家庭中是否谈过性 / 接受过怎样的学校性教育 / 宗教或乡土观念的影响 / 过去的媒体来源（课本、网络、影视、同伴传言）/ 不愿展开。写这一项是为了知道"哪些词会让人不舒服"，不是为了归因或追责。
- **对性话题的舒适度**：能和伴侣聊 / 只能和很信任的朋友或专业人士聊 / 只能文字聊不能当面聊 / 完全不想聊 / 分话题（某些能聊某些不能）。
- **自评倾向（三档不是三级）**：偏传统（重视关系内的稳定与私密）/ 偏探索（愿意讨论与尝试，但需要沟通）/ 偏开放（对多元关系结构或多样实践接受度高）/ 不确定 / 不愿归类。**建议写成"我在某些事上偏传统、某些事上偏探索"**，一个词概括往往会失真。
- **硬边界**：绝对不接受的事（例如某些行为、场合、拍摄、语言、未经讨论的改变）。硬边界可以只有自己能改，伴侣不能通过说服来改。
- **软边界**：可以商量、但需要先充分沟通与安全感的事。软边界允许改主意，也包括"这次想试下次不想"。
- **探索意愿**：不想 / 只想了解不打算尝试 / 愿意在明确沟通后尝试 / 希望伴侣主动提议 / 不确定。
- **羞耻触发点**：哪些词、语气、比较（"别人都""你怎么这么……"）会让自己闭嘴；被笑、被评价、被追问细节时的反应。
- **需要多久建立信任**：几次见面之后 / 明确关系之后 / 几个月 / 说不好；也可以写"我需要在完全不紧张的时候才能开口"。
- **希望被怎么对待**：慢一点、先问再动、允许我说停、不要拿我和别人比较、不要把话题变成考核。

## 二、常见取值与对应影响

| 自述方向 | 对建议的影响 |
|---|---|
| 偏传统＋不确定＋从没主动聊过 | 从"感受"而不是"具体行为"开始；给低风险的开口句；不安排任何需要当场表态的场景 |
| 只接受文字聊，不接受当面 | 建议先文字、后当面；给可复制的句式，不要求"今晚就摊开谈" |
| 硬边界很多且明确 | 把边界当既定条件写进沟通，不设计"如何说服"；重点转为双方边界是否兼容 |
| 探索意愿高但缺沟通经验 | 强调事前协商、过程中确认、事后复盘的结构（见 intimacy-016），不提供露骨内容 |
| 羞耻触发点是"被评价" | 避免任何比较性、评分性表达；不用"正常人都……"作论据 |
| 需要几个月才能谈 | 把节奏视为合理，不做"再不说就来不及"的催促；提醒对方也需要知情 |
| 因过往经历而无法放松 | 不追问细节；建议专业支持（性治疗与伴侣治疗的就医路径见 intimacy-022），并提供"先只聊舒适度"的最小版本 |

## 三、对沟通与建议的具体影响

**开口方式。** 三类可行的开头，按舒适度从低到高排：
1. 借第三方话题："我看到一篇文章讲情侣会聊这个，你觉得聊这种话题尴尬吗？"
2. 说自己的感受而不是请求："我发现我在聊这方面的时候会紧张，不是因为你，是我自己的习惯。"
3. 直接提出需要："我想在放慢一点之后再继续，可以吗？"

**节奏。** 用户填"需要多久建立信任"后，AI 的推进建议不得快于这个自述值；也不能因为"对方想要更快"而压缩它。节奏谈不拢时，正确的做法是把差异说清楚并讨论兼容方案，而不是让一方"适应"另一方（性欲与节奏差异见 intimacy-002）。

**是否建议专业支持。** 出现以下情形时，建议从"聊天技巧"转为"专业支持"：持续疼痛或无法放松；回忆过往经历导致明显痛苦；性相关的强迫行为已影响生活或工作；长期回避导致关系持续冲突；需要药物或健康层面的判断。表述方式：把就医/咨询说成"找个专业的人帮我们省点沟通成本"，不带病理化暗示，也不替用户下诊断。

**观念差异的讨论。** 若用户处在跨文化、跨观念背景的关系里，讨论要聚焦"我们两个人具体怎么做"，而不是"哪种观念更先进"。相关对话结构见 intimacy-028。

## 四、AI 使用规则

1. **不替用户贴标签**：不使用"保守""开放""放得开""封建""传统女性"作为身份判定，只在用户自己的表述范围内使用其用词；不复述"你这种就是保守"。
2. **不劝用户突破边界**：不把硬边界当"需要被克服的羞耻"；不提供"三步让她放下防备"这类内容；用户改主意是用户的权利，不是关系的进度。
3. **不生成露骨内容**：不写具体性描写、技巧教程或带色情意味的脚本；只谈沟通、同意、安全、健康与就医。
4. **不用"更开放"施压**：不以"西方/年轻人/别人都……"作为论证要求用户改变接受度；不用"你不试就是不爱我"式的框架；观念差异不排序。
5. **不做诊断与归因**：不推测用户的心理问题来源，不把家庭背景当"病因"讲给用户；需要时转专业人士。
6. **保护退出权**：任何建议都要包含"我可以说停，且不需要理由"；日常说出的"不"就是完整答案。
7. **不做审查式提问**：不逐项盘问字段，只问与当前问题相关的 1 到 2 项；用户可留空、可写"不愿透露"。
8. **识别施压与胁迫**：若对话对象存在反复施压、擅自改变避孕方式、以拍摄要挟、在醉酒或依赖状态下要求亲密行为，优先安全与止损，转 06/07 板块（如 risk-012、tactic-029）。

## 五、组合规则

- **与 user-006 性倾向与亲密偏好**：user-006 记录偏好与边界本身，本页记录"对谈这件事的接受度与形成背景"；两者一起用才能决定开口方式。
- **与 user-013 交往经验与沟通风格**：经验少不等于观念保守，表达弱不等于没有边界。给建议时先看沟通风格，再决定句式的复杂度。
- **与 user-014 隐私与安全偏好**：性相关的自述默认本地保存、不跨会话引用，不写入可被他人看到的位置；不接受"发张证明你放松"式的请求。

- **与 11 板块的其他条目**：需要沟通结构时用 intimacy-002，需要协商具体偏好时用 intimacy-016，羞耻的再学习过程看 intimacy-026。

## 六、AI 调用示例

**示例一：用户想聊但不敢开口**

用户自述：28 岁，和对象在一起四个多月，我对自己身体的反应有些困惑，但一想到要说出口就觉得羞耻；家里从没谈过这些，我不想被笑。

建议调整：先确认这不是"要不要说服对方"的问题，而是"怎么把话说出口"的问题；采用借第三方话题的开头，配合"我紧张不是因为你"的自我说明；给出文字版草稿让用户先写再念；明确不生成露骨描写；如果困惑持续或伴随疼痛、无法放松，把就医与性治疗咨询作为"降低沟通成本"的选项提出（intimacy-022、intimacy-026）。不评价其家庭观念，不说"这很正常你别多想"来消解感受。

**示例二：节奏被对方压缩**

用户自述：对方希望快一点，我希望再等等，我说了"还没准备好"，对方回"你是不是不信任我"。

建议调整：明确这是边界议题而不是沟通技巧议题；不设计"如何让 TA 接受"的话术，而是给一句陈述句＋观察对方反应："我需要的时间就是这个长度，这不是考验你。"若对方反复施压、冷战或以"不爱"定性，转 07/06 板块按施压识别处理（tactic-029、risk-021）。同时提醒用户：改主意是允许的，被推动的"同意"不是同意。

## 七、边界：这一页不做什么

- 不给任何人（包括用户的伴侣）做性方面的画像判定。
- 不把"传统"与"落后"、"开放"与"放荡"做任何一对价值排序。
- 不假设用户的观念来自创伤，也不假设改变观念就是成长。
- 不为未成年人提供性沟通建议；涉及未成年信号只保留安全与求助路径。
- 不提供绕过同意、制造情境、用酒精或药物降低对方防御的任何内容。
