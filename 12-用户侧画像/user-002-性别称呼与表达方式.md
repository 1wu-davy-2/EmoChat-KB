# 性别、称呼与表达方式

> 这一页只描述用户自己希望被怎样称呼、习惯怎样表达，不用来判断"某种性别应该怎样"。

## 字段与取值

- **性别认同**：男 / 女 / 非二元 / 其他 / 不愿透露。性别认同与出生登记性别可能不同，以用户自述为准。
- **称呼**：常用昵称、希望 AI 使用的称呼、正式场合称呼；可写"用名字即可"。
- **代词**：他 / 她 / TA / 英文代词 / 不限；中文口语里"你"通常已足够。
- **表达风格**（可多选）：直接、含蓄、幽默、理性、慢热。风格随场合变化很正常，不要求前后完全一致。
- **表达禁区**：不愿被叫的称呼，例如"兄弟""小姐姐""宝贝"，以及不愿被开的玩笑。

## 怎么询问

1. 先自报再问："我希望你直接叫我的名字；你希望我怎么称呼你？"
2. 给出低成本选项："叫名字、叫昵称，或者先用'你'都可以。"
3. 一次只问一项，不把性别、称呼、代词、恋爱史打包追问。
4. 不追问证件性别、身体细节、手术、激素使用等隐私；这些与聊天建议无关。
5. 对方纠正称呼时立刻改口，不解释"我没那个意思"，也不反复犯错。

## 表达风格适配

| 风格 | 建议语气 | 节奏 | 避免 |
|---|---|---|---|
| 直接 | 结论先行、少铺垫 | 一次说清，不反复试探 | 绕弯暗示后怪对方不懂 |
| 含蓄 | 给选择、留余地 | 用提问代替断言，逐步确认 | 逼对方立刻表态 |
| 幽默 | 可接梗、可自嘲 | 允许密集互动，也允许安静 | 拿对方痛处或外貌开玩笑 |
| 理性 | 给依据、列选项 | 条理清楚，先事实后感受 | "你就是想太多" |
| 慢热 | 小步、稳定、可预期 | 先文字后语音，再考虑见面 | 高频轰炸、突然表白 |

风格是偏好，不是能力高低。直接不等于粗鲁，含蓄不等于心机，慢热也不等于冷淡。

## 避免性别刻板印象

- 不因性别假设谁该主动、谁该矜持、谁该买单、谁该情绪稳定。
- 不用"男生都这样""女生都那样"作为建议依据；群体统计不能替代对具体人的了解。
- 不把性欲高低、沟通能力、经济能力与性别绑定。
- 不把"会撩""会撒娇"当成某种性别的义务。
- 非二元或不愿透露性别的用户：中文可用"TA""你""对方"，避免"兄弟/姐妹们"式默认称呼；不确定时直接用名字。
- 不因用户的性别表达不符合期待，就建议其"改得像一点"。

## 称呼的边界

- 昵称需要对方同意；关系未确认时，"宝贝""亲爱的"可能让对方不适。
- 不用贬低式称呼（"小笨蛋""傻白甜"）证明亲密；亲昵不能建立在矮化上。
- 公开场合的称呼以对方舒适为准；不愿公开的关系，不用亲密称呼试探。
- 对方不愿透露性别或代词时，不猜测、不套问、不向第三人打听。

## AI 适配规则

1. 默认使用"你 / 对方 / TA"，不默认性别，也不默认异性恋。
2. 用户填了称呼就优先使用；没填就用中性称呼，不自行发明昵称。
3. 把表达风格当偏好而非缺陷，不劝用户"改成更受欢迎的样子"。
4. 建议中不出现"男生应该主动""女生要矜持"这类句式。
5. 涉及第三人的称呼，以用户转述的对方自称为准；不确定就问，不替对方设定性别。

## 常见误用

- 把"直"当真诚，把"含蓄"当算计。
- 用性别解释所有行为：不回消息、不主动、不拒绝都被归因于"性别天性"。
- 替用户决定"你适合什么风格"，忽视用户自己的舒适度。
- 在群聊或公开场合使用用户不愿公开的称呼。

## 边界

- 表达方式可以协商，但不需要为迎合他人改变核心性格。
- 任何称呼都不能覆盖"不"；亲昵称呼不等于同意，也不等于关系确认。
- 若用户因性别表达遭遇歧视、威胁或暴力，优先考虑安全与求助（见 risk-021）。
- 画像用于调整建议，不用于给他人贴标签或施压。
