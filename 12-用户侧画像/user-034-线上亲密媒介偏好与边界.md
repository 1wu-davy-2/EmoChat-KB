# 线上亲密媒介偏好与边界

> 面向 18 岁以上成年人。这一页记录用户在线上亲密里“愿意用哪种媒介、愿意走到哪一步”，用来约束 AI 的建议方式，不是贴标签，也不是替用户决定。默认本地保存，敏感项可留空；AI 不催升级、不索要影像、不评价保守或开放。

## 一、字段说明

- **文字/语音/图片/视频舒适度**：分别记录，可写“文字可以、语音看情况、视频暂不接受”。
- **实时通话**：接受 / 只接受预约 / 只接受语音 / 只接受文字 / 暂不接受。
- **深夜通话**：接受 / 只接受周末 / 需提前约 / 不接受。
- **录音/录屏**：接受 / 只接受双方知情 / 不接受 / 不接受任何留存。
- **保存/回看**：可保存文字 / 可保存语音 / 不可保存 / 只保存自己的部分。
- **第三人/外放**：可外放 / 只在独处时 / 不接受他人在场 / 不接受被录音外传。
- **线上性沟通**：接受 / 只接受文字 / 只接受语音 / 暂不接受 / 完全不接受；都以可撤回为前提。
- **推进节奏**：先文字后语音 / 一周后再视频 / 见面后再考虑 / 由自己提出。
- **拒绝方式**：直接说“不” / 用“改天”缓冲 / 文字拒绝 / 需要 AI 帮写一句。
- **隐私边界**：背景是否露出住址、门牌、单位、证件、孩子；是否接受对方看到房间、工位。
- **设备与平台**：常用平台 / 不接受小众 App / 不接受屏幕共享 / 不接受新号 / 设备是否共用。
- **曾被泄露/被威胁**：无 / 曾被截图转发 / 曾被威胁 / 不愿透露；只用于安全约束。
- **底线**：绝对不接受的事，例如“不录屏”“不露脸”“不深夜通话”。

## 二、常见取值组合

| 类型 | 典型填法 | 对建议的影响 |
|---|---|---|
| 文字优先型 | 文字舒适、语音看情况、视频暂不接受 | 只给文字；不把视频当信任测试；可建议语音留言 |
| 语音舒适型 | 接受语音与预约通话、不接受录屏 | 可建议语音，但明确不保存；不默认录音 |
| 视频谨慎型 | 只接受短时视频、需预约、背景干净 | 给“短时、可随时关”的方案；不突然视频 |
| 实时开放但隐私严格 | 接受通话、不接受外放与第三人 | 提醒耳机、独处、背景遮挡；不共享屏幕 |
| 拒绝留存型 | 不接受录音/录屏/保存，接受即时通话 | 默认“说完即过”；不建议回看或录屏取证 |
| 曾泄露/被威胁 | 曾被截图或威胁，当前高度警觉 | 优先安全与取证；不建议新影像 |
| 线上性沟通拒绝 | 不接受任何线上性沟通，边界清晰 | 不劝、不试探；只给拒绝与退出话术 |

## 三、对建议的影响

- **是否建议语音/视频**：按舒适度给方案，不把升级当关系进度。只接受文字时，不设计“先发条语音试试”。
- **是否建议保存**：不接受留存时，不建议录屏、录音、收藏；提醒对方也不应擅自保存。接受保存时，提醒设备与云备份风险。
- **是否建议奔现**：媒介偏好不是见面许可；见面前完成一次用户能接受的实时核验，并按 risk-014 做安全计划。
- **是否建议报警/取证**：出现威胁、泄露、冒充、索财时，安全优先；取证用已有记录，不要求再发新内容。
- **不替用户升级媒介**：不因“关系该进一步了”建议视频、深夜通话、私密内容或见面；每一步由用户决定。
- **不把拒绝当问题**：拒绝视频、通话、保存都是完整答案；不追问理由，不暗示“你不够信任对方”。

## 四、不同偏好怎么谈：四步

1. **先说自己的舒适度**：用“我”开头。示例：“我文字聊比较放松，语音需要再熟悉一点。”
2. **给出可选项与退出方式**：一次只升一级，明确“不方便就停”。示例：“今晚可以语音十分钟吗？不方便就继续打字。”
3. **看对方的反应**：能接受“不”、不惩罚、不反复施压，才可继续；用“别人都这样”回应的，按施压识别。
4. **定期复核**：偏好会变；上次接受不代表这次接受，关系存在也不代表默认同意。

## 五、AI 使用规则

1. **不催升级**：不说“都聊这么久了，该视频了”；不设媒介升级时间表。
2. **不索要影像**：不要求用户发照片、语音、视频来“证明”，也不建议向对方索要。
3. **不评价保守/开放**：不用“保守”“放不开”描述用户；不用“别人都这样”作论据。
4. **安全优先**：出现威胁、泄露、冒充、跟踪、索财，先给安全与求助路径。
5. **拒绝是完整答案**：用户说“不”后，不追问理由，不提供“如何让对方接受”的话术。
6. **不假设同意**：一次语音不等于接受视频；一次通话不等于接受录制；关系存在不等于永久授权。
7. **未成年信号**：停止所有亲密与媒介建议，只保留安全与求助。
8. **最小收集**：不追问住址、单位、证件；用户不愿填的字段留空。

## 七、AI 调用示例

**示例一：用户只想文字，对方要求视频**

用户自述：我跟他聊了一个月，他一直让我开视频，说不见面就是不信他。我只想文字，最多语音。

建议调整：先确认这是媒介边界，不是“证明信任”；给一句边界话术：“我可以语音，但视频我现在不做，这跟信不信任你无关。”不设计“如何让他接受”的劝说；观察对方是否停止施压。若对方用冷暴力、羞辱或“别人都这样”升级，按 tactic-053 识别。可建议一次短语音作为用户自己愿意的选项，但不替用户决定。

**示例二：曾被截图威胁，对方要求保存语音**

用户自述：前任曾经截过我的聊天记录威胁我，现在新对象让我发语音给他收藏，我有点怕。

建议调整：先确认当前安全与是否仍有威胁；不建议发送可被留存的语音，也不建议录屏取证；给拒绝句：“语音我可以聊，但我不发可保存的版本。”提醒检查设备与云备份、关闭不必要的同步；若新对象因拒绝而施压，按 risk-037、tactic-054 处理。心理支持可提 12356。
