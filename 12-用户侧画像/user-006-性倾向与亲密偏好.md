# 性倾向与亲密偏好

> 面向 18 岁以上成年人。这一页只记录用户对亲密关系的偏好与边界，用于让建议更贴合，不用于给用户或对方下诊断。所有偏好都以成年人自愿、知情、可撤回为前提。

## 可选字段

| 字段 | 常见取值 | 说明 |
|---|---|---|
| 性欲水平 | 低 / 中 / 高 / 波动大 / 不确定 | 受压力、睡眠、药物、健康影响，不是固定分数 |
| 情感连接需求 | 必须有情感连接 / 可有可无 / 更看重身体吸引 / 不确定 | 没有哪种更高级 |
| BDSM / kink | 好奇 / 有经验 / 不感兴趣 / 不愿透露 | 只谈边界与安全，不涉及具体实践 |
| 关系结构 | 单偶 / 非单偶 / 不确定 | 关键是双方是否知情同意 |
| 硬边界 | 绝对不接受的事 | 例如某些行为、场合、拍摄 |
| 软边界 | 可以商量、需要先沟通的事 | 允许改变主意 |
| 安全词 / 停止信号 | 词、手势、颜色 | 日常的"停""不行"永远有效 |
| 性健康 | STI 检测频率、避孕偏好、防护习惯 | 见 intimacy-008 |

## 偏好的四种常见维度

- **性欲高低与波动**：高性欲不等于随便，低性欲不等于不爱。差异是普遍现象，重点是协商而不是评判（见 intimacy-002）。
- **情感连接需求**：有人需要先有信任才有欲望，有人可以分开；两种都正常，但要说清楚，避免用"爱不爱"解释欲望差异。
- **kink 兴趣**：好奇、有经验、不感兴趣都是合法选项。实践以 SSC/RACK 为框架，事前协商、持续同意、随时可停（见 intimacy-003）；偏好本身不是病，只有当它造成持续痛苦或伤害时才需要专业帮助（见 intimacy-004）。
- **单偶 / 非单偶**：单偶不是保守，非单偶也不是放纵。非单偶的核心是**知情同意**：所有相关方知道并同意，有明确协议与定期沟通；不能拿"开放"掩盖隐瞒。

## 怎么谈

用四句话把边界说清楚：

1. "我想要的亲近方式是……"
2. "我不接受的是……"
3. "我说停的时候，请立刻停，不需要理由。"
4. "结束后我们花几分钟聊一下感受和下次调整。"

对方不感兴趣时，"不"就是完整答案；不追问、不反复提、不拿关系存续施压。用户自己也可以随时改主意，改主意不是欺骗。

## 安全与健康

- 安全词要事先约定；无法说话时约定手势。安全词触发后先停下确认，不"再坚持一下"。
- 避孕方式由双方共同决定；擅自改变避孕方式（如中途不使用）属于边界侵犯，不是"气氛问题"。
- 定期做性健康检查；有症状或担忧时去正规医院，不靠搜索自我诊断（见 intimacy-008、intimacy-010）。
- 私密影像必须明确同意；未经同意拍摄、保存或传播可能违法（见 risk-012、risk-016）。
- 醉酒、昏迷、睡眠、被威胁或经济依赖状态下的"同意"无效；持续施压属于性胁迫（见 tactic-029）。

## 常见风险

- 以"开放关系"为名隐瞒其他伴侣，实际是欺骗。
- 以"你不是爱我吗"逼迫对方接受 kink 或不采取防护。
- 把对方的边界当"需要被调教"，反复试探。
- 用性欲高低、kink 偏好给对方贴"变态""冷淡"标签。
- 把偏好当诊断，自行判断对方有心理问题。

## AI 使用规则

1. 只问与当前问题相关的偏好，不逐项盘问；用户可以不填、可以只填一部分。
2. 不生成露骨性描写，不提供具体性技巧；需要时只谈沟通、同意、安全与就医。
3. 不把偏好当诊断，不评价"正常/不正常"；持续痛苦或功能困扰建议就医（intimacy-010）。
4. 遇到施压、偷拍、传播、擅自改变避孕方式等，优先止损与取证，转 06/07 板块。
5. 画像用于调整建议，不用于给他人贴标签或施压。
