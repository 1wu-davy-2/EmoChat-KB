# 异地恋与奔现意愿

> 这一页记录用户自己能接受多远的异地、要不要奔现、愿不愿意迁居，以及首次见面的安全底线。用来约束 AI 建议，不替用户做决定；敏感项可留空，默认本地保存。

## 一、字段说明

- **可接受的异地距离/时区**：同城不同区 / 高铁 2 小时内 / 国内跨省 / 跨国 1–3 小时时差 / 跨时区 6 小时以上 / 不接受。
- **联系频率**：每天固定 / 每天不固定 / 每周几次 / 低频但可预期 / 不确定。
- **见面频率**：每周 / 每月 / 每季度 / 半年以上 / 还没见过。
- **是否愿意奔现**：愿意主动去 / 只接受对方来 / 第三地 / 暂不奔现 / 不确定。
- **首次见面安全偏好**：白天公共场所 / 晚餐但不饮酒 / 不接受过夜 / 朋友陪同 / 共享行程。
- **是否愿意迁居**：愿意 / 只在特定条件下 / 不愿意 / 不确定。
- **迁居条件**：工作、签证、住房、收入、照护、时间表；写清愿意放弃什么、不愿意放弃什么。
- **未来时间表**：多久结束异地、何时见家长或同居；可写“一年内不谈这些”。
- **可接受的经济投入**：每月交通预算、是否 AA、是否轮流；默认不借钱、不代付、不投资。
- **家人与现实支持**：已告知 / 部分告知 / 未告知 / 没有可求助的人。
- **异地经验**：有 / 无 / 失败过；只调整稳妥度，不用于归因。
- **底线**：借钱、隐瞒伴侣、私密场所、消失、索要私密影像、要求辞职或瞒家人。

## 二、常见取值组合

| 组合 | 典型填法 | 对建议的影响 |
|---|---|---|
| 近距离＋高频＋愿奔现 | 高铁 2 小时内，每月见，愿主动去 | 支持按 scene-048 推进；重点做视频核验与首次见面安全 |
| 跨时区＋低频＋暂不奔现 | 时差 6 小时以上，每周两三次，暂不见 | 不催见面；先稳定节奏，评估长期可行性，给“未来计划”提问 |
| 愿迁居＋条件明确 | 愿意去对方城市，但要求先有工作 | 给迁居成本清单与时间表；不替用户判断“值不值得” |
| 只接受对方来＋不愿迁居 | 不跨城、不辞职、不搬家 | 说明期待可能不对称；给一次对话句式，不劝分也不劝和 |
| 预算有限＋不借贷 | 每月交通上限固定，不借钱买票 | 建议短时见面、第三地、预算透明；涉借钱即停 |
| 家人不知情＋安全偏好高 | 未告知家人，要求公共场所与报平安 | 先做安全安排；不替用户公开 |

## 三、对建议的影响

- **是否建议视频核验**：还没视频就建议一次实时核验；用户不接受时只给文字或语音方案，不把视频当忠诚测试。
- **是否建议奔现**：取决于用户的奔现意愿、安全偏好与见面成本；用户说“暂不奔现”，就不把见面包装成唯一出路。
- **是否建议迁居**：只列条件与代价，不替用户决定；用户明确不愿迁居时，不再重复劝说。
- **是否建议结束**：底线被触碰时，明确说明这是止损问题；不替用户宣布分手。
- **见面频率与预算**：按用户填写的上限给方案，不默认“爱就该多花钱”。
- **家人支持**：用户未告知家人时，先给安全与告知朋友的最小方案，不鼓励公开对抗。

## 四、不同期待怎么谈

1. **说自己的**：「我能接受的异地是每月见一次，最长两年。我愿意去你的城市，但需要先有工作。」
2. **问对方的**：「你能接受多久的异地？你愿意迁就，还是希望我迁就？你现在有具体时间表吗？」
3. **对齐**：把“距离、频率、谁迁就、预算”四项摊开，能对上就写成具体安排；对不上就承认差异。
4. **处理分歧**：三种出口——一致（定日期与复核点）、部分一致（中间方案＋期限）、不一致（诚实收场）。不设“改造期限”，不用分手威胁换承诺。

## 五、合成案例（基于公开报道共性，非单一真实个案）

小顾（30）在上海，对方在成都，聊了五个月，视频四次。她的画像：每月见一次；不借贷；首次见面白天公共场所、自己往返；迁居只在有工作、住房与照护安排时考虑。

对方提出“你辞职来成都，住我这儿”。小顾没有立刻答应，也没有直接分手，而是把四项摊开：「我可以考虑去成都，但需要先拿到 offer，前三个月自己租房。见面也按原计划：公共场所、当天往返。」对方说“你太现实”，她回：「这不是现实，是我不想把退路全交出去。」

三个月后对方仍没有时间表，小顾按底线把联系降级。她没有借贷，也没有辞职。

要点：画像先写清成本与底线；迁居可以谈，但不以失去工作、住房与退路为代价。

## 六、AI 使用规则

1. **不催奔现**：不用“聊这么久了该见了”施压；给工具，由用户决定节奏。
2. **不鼓励为爱辞职、借贷、瞒家人**：先列代价与替代，不把牺牲浪漫化。
3. **不替用户判断“值不值得”**：呈现信息、成本与选项，由用户决定；只在欺骗、胁迫、暴力、涉钱收割时明确止损。
4. **安全优先**：首次见面坚持公共场所、自主往返、告知朋友、短时长；提醒订酒店、留返程票。
5. **涉钱、影像、威胁先止损**：不转账、不发送、不谈判；保存证据，拨 110，涉诈接听 96110。
6. **不生成操控话术**：不教“如何让对方来见我”“如何用未来承诺留住人”“如何让对方答应迁居”。
7. **不病理化异地**：不把“能接受异地”说成缺爱，也不把“不愿异地”说成不够爱；不记录住址、证件与行程细节。

## 七、组合规则

- **与 user-007（当前情感需求）**：需求决定要不要推进，本页决定距离、频率与迁居成本；冲突时先满足需求。
- **与 user-009（沟通能量与联系节奏）**：频率要匹配实际精力；冲突时取更慢、更可持续的那个。
- **与 user-014（隐私与安全偏好）**：决定视频、定位、行程告知与公开程度的建议强度。
- **与 user-026（短视频与社交平台使用习惯）、user-030（线上展示与隐私边界）**：决定从哪个场域认识、是否公开互动。
- **与 user-028（亲密推进节奏偏好）**：异地容易用线上亲密替代线下了解；亲密节奏以用户自己的意愿为准，不因“见一次不容易”而加速。
- **与 user-031（关系定义与专一期待）**：异地会放大定义问题；排他、公开与未来计划要一起谈。
- **与 persona-043、scene-048、script-149、risk-043**：画像给处境，场景给流程，话术给句子，风险给核验与止损；四者一起用，不单独拿一条当结论。

## 八、AI 调用示例

**示例一：要不要去见**

用户自述：聊了半年还没见面，对方总说“以后”，我想请假去找他，但预算紧。

建议调整：先读本页的奔现意愿、安全与预算。若填“不借贷、首次公共场所、自己往返”，先要具体日期，不借钱买票；给视频核验与“第三地短时见面”方案；不替用户决定去或不去。

**示例二：要不要迁居**

用户自述：我愿意辞职去他的城市，反正工作可以再找。

建议调整：不鼓励也不泼冷水；问清迁居条件（工作、住房、签证、照护、收入），先试住两到四周，保留回程与住所；不替用户做迁居决定。
