# 财产债务与婚前透明

> 这一页帮用户梳理自己的资产、负债与现金流，并决定在什么时点、以什么方式告诉伴侣。透明不等于把账号密码交出去，也不等于必须合并财产；它的核心是“重大事实不被隐瞒”。具体法律问题请咨询 12348 或执业律师。

## 一、维度定义

财产债务与婚前透明包含四块：

1. **资产**：存款、理财、房产、车辆、股权、公积金，按“有无”和“档位”记录即可。
2. **负债**：房贷、车贷、消费贷、信用卡分期、网贷、创业借款、对外担保。
3. **现金流**：每月收入、固定支出、还款额、可支配余额。
4. **安排意愿**：共同账户、AA、分别管理、婚前协议、房产署名、大额支出决策阈值。

需要区分“我的婚前财产”与“婚后共同承担的部分”。前者不必全部公开细节，后者必须说清，因为伴侣会实际承担后果。

## 二、常见取值

| 取值 | 具体表现 | 对沟通与建议的影响 |
|---|---|---|
| 无负债、有应急金 | 有几个月生活费的储备，无高息欠款 | 财务压力小，重点转向共同目标与消费观是否一致 |
| 有房贷或车贷 | 长期月供，资产与负债并存 | 需谈首付来源、署名、谁还贷、增值如何认定，避免只谈“房子写谁” |
| 有消费贷或信用卡分期 | 月供占收入一定比例，利率中等 | 看还款占比与利率，不羞辱消费选择；优先处理高息部分 |
| 有网贷或多头借贷 | 多平台借款、以贷养贷、催收压力 | 先止损与整理债务清单，必要时咨询法律援助；不帮用户编理由隐瞒 |
| 创业负债或对外担保 | 经营借款、个人连带责任、亲友担保 | 明确“家庭是否兜底”，担保风险通常高于普通借款，需格外谨慎 |
| 部分披露或暂不愿披露 | 只说了大概，或明确不想谈细节 | 尊重节奏，但重大债务应在结婚或共同买房前说明；不替用户隐瞒 |

## 三、对沟通、择偶与关系节奏的影响

**沟通方式。** 披露用“四段式”：事实（我有一笔什么负债、余额区间）、影响（每月还多少、还要多久）、计划（我怎么还、是否需要调整婚礼或买房）、请求（我需要你知道，并希望我们一起决定边界）。不用“怕你多想所以没说”开场，那会让对方把重点放在隐瞒上。

**择偶判断。** 负债本身不说明人品，消费贷可能来自疾病或失业，创业负债可能来自尝试。真正需要评估的是：是否如实、是否有还款计划、是否愿意设上限、是否把风险转嫁给伴侣。隐瞒大额债务、要求伴侣担保、催促共同贷款，都是需要停下来谈的信号。

**关系节奏。** 建议在三个节点前完成披露：确定要结婚、共同买房、计划生育。太早不必交代全部细节，太晚则失去选择空间。婚前协议是可选工具，谈它不代表不信任，而是把最坏情况说清楚。

**日常安排。** 共同账户、部分共同、各自独立都可以，关键是规则一致：每月各出多少、哪些算共同开支、超过多少金额需要双方同意、礼金与年终奖怎么算。规则写下来，比“到时候再说”省很多争吵。

## 四、与其他维度的组合规则

- **与 user-012 消费观与财务边界**：本页管“存量与债务”，user-012 管“日常怎么花”，两页一起看才完整。
- **与 method-113 金钱观与共同财务沟通**：本页提供事实，method-113 提供对话框架与分歧处理方式。
- **与 risk-013 经济控制**：若对方要求上交工资、查账、禁止工作、以钱换顺从，先按风险处理，不当作普通财务分歧。
- **与 scene-019 婚前谈判**：房产、彩礼、婚礼出资、债务承担可放在同一张桌上谈，避免逐项突袭。
- **与原生家庭负担**：为父母借贷、为弟妹担保，属于重大现金流事项，应主动说明，可参考 script-110。
- **与婚礼预算**：不为婚礼借高息贷；婚宴尾款与礼金归属要提前说清，可参考 scene-019。
- **冲突处理**：先分清“事实问题”（欠多少、利率多少）与“信任问题”（为什么现在才说），分开处理。

## 五、AI 调用示例

**示例一：不知道怎么坦白网贷**

用户自述：“我有八万网贷，一直没敢跟对象说，现在要谈婚论嫁了。”

建议调整：不帮用户编造理由，也不先指责。让用户先做一张债务表：平台类型、余额、利率、月供、预计还清时间；再评估月供占收入比例，优先处理高息部分，必要时咨询正规法律援助或金融消费者保护渠道。告知时用“事实—影响—计划—请求”，并接受对方需要时间消化。若对方因此重新评估关系，这是对方的选择，不是用户可以被要挟的把柄。

**示例二：房产加名的压力**

用户自述：“对方说婚前必须把房子加上名字，不然就是不爱。”

建议调整：不替用户答应或拒绝。说明加名涉及产权与贷款安排，属于法律与财务决定，建议双方带着具体方案咨询专业人士，并写下出资、还贷、分割的书面约定。把“不加名就是不爱”翻译成“你需要安全感”，再讨论其他可给安全感的方式（共同储蓄、婚后共同购房、明确居住权）。若对方持续用威胁或羞辱推进，提示这是施压模式。

## 六、边界：不是标签

- 不鼓励隐瞒重大债务、转移财产、虚假离婚或让伴侣替自己背债。
- 不替用户做法律判断；财产归属、债务承担、协议效力以律师意见与合同为准。
- 不索要银行卡号、支付密码、借贷平台账号；不引导用户上传账单或征信截图。
- 不把负债当人品标签，也不把“有钱”当可靠证明。
- 婚前协议不是不信任的证明；是否签署由双方自愿，不能胁迫。
- 经济控制、以债务相威胁、限制人身自由，属于安全议题，优先求助 110、12338、12348。
