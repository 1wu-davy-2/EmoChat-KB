# 星座配置与使用偏好

> 这一页记录的是用户**自己**的星座配置与使用偏好，不是对方的星盘。星座信息属于低置信度的娱乐参考与自我反思素材，不构成事实、诊断或择偶判决。

## 可选字段

- **太阳星座**：只需出生日期，最容易确定。常被用来聊核心认同、在意的事与外显风格。
- **月亮星座**：需要出生时间与地点，常被用来聊情绪恢复方式与安全感来源。不知道很正常。
- **上升星座**：同样依赖准确时间地点，常被用来聊第一印象与陌生场合的社交外壳。
- **金星 / 火星**（可选）：被用来聊表达好感与行动风格，见 astro-015。
- **使用偏好**：认真参考 / 半信半疑 / 纯娱乐 / 不信。偏好比具体星座更重要。

## 按使用偏好回应

| 偏好 | 可以怎么用 | 不要怎么做 |
|---|---|---|
| 认真参考 | 当作自我观察的语言，配合现实行为讨论 | 用星盘下结论、预测吉凶、替代决策 |
| 半信半疑 | 当破冰话题与轻松的自我描述 | 把"说中了"当成深度理解 |
| 纯娱乐 | 玩梗、聊性格标签、增加话题 | 用星座评价具体的人 |
| 不信 | 尊重，不主动提；用户问起再解释 | 反复安利"你只是没遇到准的" |

## 用于聊天话题

- 破冰可以问："你平时会看星座吗？太阳是什么？"对方不知道月亮，就顺势聊"那你累的时候怎么恢复"。
- 把星座说法当作对方递来的话题，而不是人格说明书；对方纠正时，以对方的说法为准。
- 聊到性格差异时，补一句现实观察："你觉得这跟你实际经历对得上吗？"
- 不拿星座当试探工具，例如用"我们星座不合"制造悬念或推拉。

## 用于自我反思

- **太阳**：我最近把精力放在什么上？我希望别人怎么介绍我？
- **月亮**：我累的时候需要陪伴还是空间？什么让我有安全感？
- **上升**：我在陌生场合给人的第一印象是什么？常被误会的地方在哪？
- **金星/火星**：我表达好感的方式是什么？冲突时我倾向靠近还是撤退？

这些问题的价值在反思本身，不在星座答案。写完可以问自己："如果不看星座，我的答案会变吗？"

## 置信度与边界

- 星座体系缺少可重复的实证支持；"说得很准"常来自**巴纳姆效应**——笼统、双面的描述对大多数人都成立（见 astro-017）。
- 不用星座判断两个人是否适配，也不用星座预测关系走向；适配看现实互动：是否尊重拒绝、是否兑现承诺、冲突后能否修复。
- 不给对方贴标签，不说"你们 X 座都这样"；不因星座差异否定一段关系，也不因"绝配"忽略危险信号。
- 不追问精确出生时间、出生医院、出生证明；不替用户或对方排盘，不保存出生信息。
- 不因"水逆""命中注定"加快关系节奏：不提前同居、不借钱、不发私密影像、不支付改运费用。
- 若用户用星座解释一切（迟到、冷战、分手），温和地把话题拉回具体行为与感受。

## AI 使用规则

1. 先问使用偏好，再决定聊不聊星座；用户说不信，就不把星座写进建议。
2. 只把星座当语气与话题的调料，不写进核心判断，不生成"星座匹配度"结论。
3. 用户不知道月亮/上升时，不追问、不估算、不编造。
4. 禁止用星座为控制、贬低或施压提供理由；遇到"星座 PUA"话术，转 astro-017 识别。
5. 画像用于调整建议，不用于给他人贴标签或施压。
