# 职业规划与工作强度

> 这一页记录用户的职业类型、作息、强度与未来一到三年的变动计划，用来校准联系节奏、约会安排与长期规划。职业只说明时间与精力如何分配，不说明一个人是否可靠、是否值得托付。

## 一、维度定义

职业规划与工作强度包含四项：

1. **作息类型**：固定日班、轮班、夜班、随时待命、时间自主。
2. **强度与恢复**：每周加班时长、通勤时长、下班后是否还有工作消息、休息日能否真正休息。
3. **稳定性与变动**：未来一年是否可能换城市、换行业、降薪、失业、创业。
4. **关系可投入度**：每周可用于约会、通话、处理共同事务的整块时间。

“忙”是主观描述，建议换算成小时与时段。例如“工作日晚上十点后才有空，周末一天可约”，比“最近特别忙”更能帮到双方。

## 二、常见取值

| 取值 | 具体表现 | 对沟通与建议的影响 |
|---|---|---|
| 朝九晚五、作息固定 | 工作日白天上班，晚上与周末相对稳定 | 适合固定约会日；但“有空”不等于“随时有空”，仍需预留自己的恢复时间 |
| 轮班、倒班、夜班 | 班表周期性变化，白天需要补觉 | 联系要围绕班表设计；不用回复速度判断在乎程度，约定“下班后固定一段”更可行 |
| 高强度长期加班 | 工作日被工作占满，周末常被压缩 | 约会质量重于频次；冲突易在疲惫时爆发，需约定“低电量时先暂停” |
| 自由职业、远程、项目制 | 时间看似自由，工作与生活边界模糊 | 需要主动划出工作区与离线时段，否则约会时人在一起、注意力不在 |
| 创业、个体经营 | 现金流与情绪波动大，决策周期长 | 长期不确定性高，财务与时间都要留缓冲；不把“忙”当无限豁免 |
| 求学、备考、转行过渡 | 阶段性低收入、高压力，时间表随考试或毕业变化 | 建议按学期或考试节点排计划，避免在冲刺期谈重大决定 |

## 三、对沟通、择偶与关系节奏的影响

**沟通方式。** 先问“你哪天几点比较能说话”，再定联系方式。对方在上班、补觉、开会时，不连发消息、不要求秒回。用户自己忙时，也应给一句可预期的说明：“今天到九点，十点后回你”，比消失后再解释更省情绪。

**择偶判断。** 职业本身不是筛选条件，真正需要评估的是：双方的空闲时段是否重叠、是否能接受长期异地或长期不稳定、遇到职业变动时是否愿意共同调整。把“职业体面”当匹配标准，容易忽略真实的相处成本。

**关系节奏。** 高压期适合低频率、高质量的联系：固定一次长谈，平时用简短留言维持连接。轮班与异地组合时，建议共享班表或日历，把“下一次见面”写进日程。日常维护的方法可参考 method-111。

**职业变动。** 换城市、降薪、失业、创业都会改变关系的时间与金钱预算。建议在变动发生前告知，而不是事后解释；告知时带上“影响范围”和“打算”，减少对方的不安全感。

## 四、与其他维度的组合规则

- **与 user-015 时间预算**：本页给“为什么没时间”，user-015 给“还剩多少时间”。两页一起看，才能排出可行的约会频率。
- **与 user-009 沟通能量**：内向者在高强度工作后需要独处恢复，低能量不等于低兴趣；不要用“以前你话很多”施压。
- **与 user-012 财务边界**：创业、自由职业、转行期收入波动大，约会预算与共同开支要留缓冲，不以消费水平判断诚意。
- **与赡养老人**：长期加班或异地工作的人，难以承担日常照护，需提前讨论替代方案，可参考 persona-026。
- **与定居迁移决策**：职业机会是迁移决策的核心变量，不能用“为爱走天涯”覆盖就业现实。
- **冲突处理**：把“你根本不在乎我”翻译成“这周我们只吃了两顿饭，我需要一个固定的晚上”。先谈时间，再谈态度。

## 五、AI 调用示例

**示例一：回复慢被当成不爱**

用户自述：“我是护士，三班倒，对方总说我回消息慢是不在乎，我解释了很多次都没用。”

建议调整：不建议用户继续用“我真的很忙”解释，改成可验证的安排：共享班表、约定下班后 20 分钟通话、忙时发一条固定模板（“在班上，几点回”）。帮用户把讨论从“态度”转到“约定是否被遵守”。同时提醒：如果对方持续用回复速度惩罚用户，属于边界问题，可参考 script-103。

**示例二：辞职创业的冲突**

用户自述：“我想辞职创业，伴侣担心收入不稳定，劝我别去。”

建议调整：不劝退也不鼓吹。做三栏表：现金流（能撑几个月）、时间（每周投入多少、何时不可用）、退路（失败后回到原行业或兼职的可能）。设 6 个月评估点与家庭预算上限，把伴侣的担心转成具体条款，例如“前六个月不动用共同储蓄”。让决定可讨论、可回退。

## 六、边界：不是标签

- 不把职业当人品标签：轮班不等于不顾家，创业不等于不靠谱，体制内不等于保守。
- 不因职业推断收入、学历、阶层、忠诚度或婚恋价值。
- 不鼓励用“我忙”长期回避沟通、家务与共同决策；忙可以是事实，也需要补偿机制。
- 不把“支持对方事业”等同于无限让渡自己的时间与需求。
- 用户不愿说具体单位、职位时，只记录作息与强度即可，不追问可识别信息。
- 涉及过劳、抑郁、职业倦怠时，建议寻求专业帮助，不把情绪问题归因于“抗压能力差”。
