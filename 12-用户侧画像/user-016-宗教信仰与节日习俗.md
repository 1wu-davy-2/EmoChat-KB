# 宗教信仰与节日习俗

> 这一页只记录用户自己实际的信仰与仪式安排，以及这些安排对日常生活的影响。它不是信仰审查表，也不用于判断一段关系“能不能成”。填写可粗可细，可以只写“家里有些讲究”，不必交代教派、场所或身份细节。

## 一、维度定义

宗教信仰与节日习俗，指用户在饮食、时间安排、仪式、婚丧嫁娶、子女教育等方面实际遵循的规范。它包括三件常被混在一起的事：

1. **信仰归属**：有宗教归属、无宗教归属、家庭文化传统、仍在探索。
2. **实践强度**：是否固定礼拜、斋戒、祷告、读经，是否严格遵守饮食禁忌。
3. **家庭与传统**：本人实践与父母、家族要求可能不同，需要分开记录。

对 AI 来说，有用的不是“信什么”，而是“哪些时间不能用、哪些食物不能吃、哪些仪式必须到场、将来孩子怎么安排”。信仰归属属于敏感信息，只记录用户主动说出的部分。

## 二、常见取值

| 取值 | 具体表现 | 对沟通与建议的影响 |
|---|---|---|
| 无信仰、无固定民俗 | 不过宗教节日，春节等按法定假期安排 | 约会与节日排期自由度高，但仍需尊重对方家庭的习惯 |
| 无宗教归属、保留家庭民俗 | 祭祖、清明、春节、地方庙会等，重仪式不重教义 | 不要把民俗当“迷信”调侃；节日安排要问清“必须到场的是哪几天” |
| 有明确信仰、实践稳定 | 固定礼拜、每日功课、斋戒、饮食禁忌明确 | 约会避开礼拜与功课时段；餐厅、出行、节日都需提前确认 |
| 有信仰、实践弹性 | 重要节日参与，日常不严格 | 不要替用户判断“够不够虔诚”，以本人自述的尺度为准 |
| 跨信仰或混合家庭 | 双方家庭信仰不同，或本人改宗、双重背景 | 婚仪、饮食、子女教育最易冲突，需逐项谈，不用“宗教冲突”一概而论 |
| 探索中或不愿透露 | 正在了解、尚未决定，或不想说明 | 不追问、不劝进也不劝退；建议里保留“如果你愿意的话”这种余地 |

## 三、对沟通、择偶与关系节奏的影响

**沟通方式。** 询问时问安排，不问身份：“你家里过节有什么固定安排？”“有没有哪些东西你不吃？”比“你信什么教”更容易得到真实回答，也不显得像审问。对方主动提到信仰时，回应事实与尊重即可，不急着评价。

**择偶判断。** 信仰差异能否共存，取决于实践冲突的大小，而不是宗教名称。饮食能否同桌、节日去谁家、婚仪按哪套流程、孩子是否接受宗教教育，这四件事谈得拢，差异就可管理；谈不拢，名称相同也可能冲突。

**关系节奏。** 礼拜、斋期、宗教节日会占掉整块时间，也可能限制见面方式。重要节日要提前排期，不把“那天不能陪你”直接理解为冷淡。跨信仰伴侣在见家长、订婚、备婚阶段压力最大，流程可参考 scene-013 与 scene-019。

**家庭沟通。** 父母对婚仪与孙辈教育的要求，常比当事人更硬。建议把“本人意愿”和“家庭要求”分栏写，先确认用户自己能接受什么，再讨论如何向家里解释。

## 四、与其他维度的组合规则

- **与 user-011 婚育意愿**：婚仪形式、子女宗教教育、节日归属是三项高冲突议题，建议在订婚前提早谈，不拖到备婚。
- **与 user-015 时间预算**：把礼拜、节日、斋期折算成每周或每年占用的小时数，再判断“能不能接受”，比抽象表态可靠。
- **与地域民俗**：地方民俗与宗教实践常混在一起，例如某些地区的婚丧流程，不要用一个维度推断另一个。
- **与家庭分工（method-114）**：宗教传统可能带来性别分工期待，但要以当事人自述为准，不按信仰替用户安排角色。
- **与 user-014 隐私安全**：信仰属敏感信息，不记录教派名称、聚会地点、宗教身份证明；共用设备时提醒用户可见性。
- **冲突处理顺序**：先处理可观察的安排（吃饭、时间、仪式），再谈价值观；不要用“你不尊重我的信仰”概括具体分歧。

## 五、AI 调用示例

**示例一：不知道怎么开口**

用户自述：“我家饮食上有些讲究，对方家里什么都不忌，我第一次去吃饭很紧张，不知道怎么提。”

建议调整：先肯定“提前说”是负责的做法；帮用户准备一句具体、不解释教义的说明，例如“我有些东西不吃，不用为我特别准备，我自己夹能吃的就好”；再列三个需要对齐的场景（日常吃饭、节日、将来婚仪）。不替用户判断这段关系合不合，也不把差异描述成障碍。

**示例二：感觉被信仰挤占**

用户自述：“对方每周固定时间去礼拜，我觉得自己被排在后面。”

建议调整：不评价信仰本身，把“被排在后面”翻译成具体需求：哪段时间需要陪伴、能否调整到礼拜之外、重要日子能否优先。给一次协商的结构：事实（每周几小时）—感受（被忽略）—请求（固定一段两人时间）—可让步项。避免建议“让对方少去几次”，那会变成要求放弃信仰。

## 六、边界：不是标签

- 不劝改宗，不贬低任何信仰，也不把“无信仰”说成没底线；反过来同样成立。
- 不引用教义替用户裁决对错；涉及教义细节，建议咨询其宗教场所的正式人员。
- 不把信教等同于迷信、落后或容易受控；只有当出现人身控制、财产剥夺、隔离亲友时，才按风险议题处理。
- 不记录教派、活动地点、宗教身份等可识别信息；用户说“不想细说”时，停止追问。
- 不把“信仰不同”当分手的万能理由；多数冲突落在具体安排上，谈安排比谈标签有用。
