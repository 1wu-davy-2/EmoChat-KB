# 赡养老人与原生家庭负担

> 这一页记录用户对双方父母养老的真实安排，以及原生家庭可能带来的经济与照护压力。它是提前对齐用的，不是“家庭条件审查”。负担重不等于不能进入关系，隐瞒到婚后才暴露才更伤人。

## 一、维度定义

赡养与原生家庭负担包含三层：

1. **经济支持**：是否固定给父母钱、金额或比例、是否有一次性大额支出（医疗、装修、还债）。
2. **时间与照护**：探望频率、陪诊、日常起居、失能后的长期照护。
3. **决策与分担**：医疗方案谁决定、兄弟姐妹如何分工、父母本人意愿放在什么位置。

此外还有几类常被回避的负担：原生家庭债务、需要长期扶养的弟妹、父母离异或再婚后的多方责任。这些不需要第一次约会就说，但在考虑结婚、共同买房、生育前应当透明。

## 二、常见取值

| 取值 | 具体表现 | 对沟通与建议的影响 |
|---|---|---|
| 父母自立，暂不需支持 | 有退休金或积蓄，身体尚可 | 压力小，但仍需预留突发医疗与照护的应急方案 |
| 固定经济支持 | 每月给固定金额，或承担某项开支 | 建议在家庭预算中单列“孝亲支出”，避免被视为可随意削减的零花 |
| 就近照护 | 同城或邻近，常跑医院、常送饭 | 时间被切碎，约会与休息易被打断，需约定可预期的陪诊日 |
| 同住照护 | 父母同住或即将同住 | 居住选择、隐私边界、家务分工都会被改变，需提前谈规则 |
| 兄弟姐妹分工 | 出钱与出力分开，或轮流照护 | 需写清谁出钱、谁出力、谁决策，避免一方长期透支后爆发 |
| 原生家庭负担较重 | 父母债务、长期病患、需扶养的弟妹 | 关键是设上限与透明，不是断绝关系，也不是无限兜底 |

## 三、对沟通、择偶与关系节奏的影响

**沟通方式。** 谈赡养时用“三件事”结构：钱（每月多少、给到什么时候）、时间（每周几小时、谁陪诊）、决策（医疗方案谁拍板）。避免用“我爸妈不容易”作为唯一理由，也避免用“你家是无底洞”概括对方家庭。

**择偶判断。** 需要评估的不是“家里有没有负担”，而是负担是否透明、是否有上限、是否由多重角色共同承担。一个人愿意照顾父母是责任感，但若以牺牲伴侣基本生活为代价且拒绝讨论，就是需要正视的结构性问题。

**关系节奏。** 父母生病、退休、丧偶是三个高压力节点，关系常在这些时候暴露分工问题。建议提前约定“紧急情况下谁请假、谁出钱、谁与医生沟通”，不要等事发当晚才吵。

**公平感。** 兄弟姐妹之间按能力与时间分工，比按“谁最孝顺”更可持续。长期照护的一方容易积累委屈，出钱的一方也可能觉得被理所当然。建议记账、定期家庭会议，把隐形付出说出来。

## 四、与其他维度的组合规则

- **与 user-012 财务边界**：孝亲支出应作为预算科目，与约会、储蓄、教育并列，而不是“剩下的才给”。
- **与定居距离**：同城、异地、跨国决定照护方式是日常跑腿还是远程协调，迁移决策要把这一项算进去。
- **与家务分工（method-114）**：照顾父母是独立任务，不默认由“更闲”“更细心”的一方承担。
- **与婚礼预算**：彩礼、婚礼与父母医疗支出可能同期发生，需排优先级，不靠借贷硬撑，可参考 scene-019。
- **与婚前财务披露（method-113）**：原生家庭债务是否影响小家庭信用与现金流，应在婚前说明。
- **与 persona-026 慢性病残障与照护者**：长期照护需要喘息服务与外部支持，不能只靠伴侣的体谅。
- **冲突处理**：先分清“必要照护”与“无限兜底”，再谈比例；不要用“不孝”堵住对方的合理担忧。

## 五、AI 调用示例

**示例一：孝亲支出引发不满**

用户自述：“我每月给父母三千，女友觉得太多，说以后还要买房。”

建议调整：不评判金额高低。把孝亲支出写进月度预算，标出占收入比例，并列出未来三年的大额目标（首付、婚礼、生育）。给两种可谈方案：固定额度加年终一次性支持，或按收入比例浮动。重点是把“偷偷给”变成“公开列支”，把“你不孝”与“你不顾小家”这两种指责都拿掉。

**示例二：兄弟姐妹不出力**

用户自述：“我爸住院，我哥基本不管，都是我在跑，我很累也很气。”

建议调整：先列照护需求清单：每天需要几小时、哪些必须家属到场、费用多少、医生沟通谁负责。再约一次家庭会议，按时间与能力分工，形成简单书面记录。肯定用户已做的部分，同时提醒长期单扛会耗竭。若涉及医疗决策分歧或费用纠纷，建议咨询法律援助，不替用户判定谁不孝。

## 六、边界：不是标签

- 不把家庭负担当成婚恋减分项，也不用“扶弟魔”“凤凰男”等标签概括用户或对方。
- 不把“孝顺”道德化，也不把“设上限”说成冷血。必要照护与无限索取要分开。
- 不鼓励与原生家庭断绝关系，也不鼓励为原生家庭牺牲小家庭的基本生活与安全。
- 不替用户判断医疗方案；尊重父母本人的意愿与知情同意，具体听主治医生。
- 不记录父母病历、身份证号、住址等敏感信息；只记照护需求与预算档位。
- 若伴随经济控制、家暴、以断绝关系相威胁，优先安全，参考 risk-013 与 risk-021。
