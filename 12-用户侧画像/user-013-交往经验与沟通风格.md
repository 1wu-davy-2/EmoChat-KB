# 交往经验与沟通风格

> 这一页记录用户“怎么表达、怎么冲突、喜欢什么节奏”，用来调整话术密度和推进速度，不用于评价用户“会不会谈恋爱”。默认本地保存，可留空、可随时修改。

## 一、字段说明

- **交往经验**：无 / 一到两段 / 多段 / 长期单身。经验多少不代表能力高低，也不代表价值。
- **主动程度**：主动发起 / 以回应为主 / 看对方 / 几乎不主动。主动是一种选择，不是义务。
- **表达方式**：直接 / 委婉 / 更擅长书面 / 看场合。直接不等于没礼貌，委婉也不等于不真诚。
- **幽默风格**：冷幽默 / 自嘲 / 夸张 / 少用幽默。幽默是润滑剂，不是遮羞布；不用来贬低对方。
- **冲突风格**：当场解决 / 需要冷静期 / 倾向回避 / 更愿意写下来。回避型需要练习“暂停后回来”。
- **偏好的爱的表达**：肯定言语 / 陪伴时间 / 礼物 / 服务行动 / 身体接触。自己常给的和最想收到的可能不同。
- **节奏偏好**：慢热 / 中等 / 快。与对方的节奏不同很常见，需要协商而不是猜测。
- **暧昧期耐受度**：喜欢明确 / 可以暧昧一段时间 / 不喜欢不确定。可与 user-007 的当前需求配合看。

## 二、选项与记录方式

- 每项选一个主选项，加上一句例子。例如：“冲突风格：需要冷静期；一般会说‘我需要半小时，之后一定回来谈’。”
- 经验字段只填概括，不填前任姓名、职业、城市等可识别信息。
- “不确定”可以保留；风格会随对象和场景变化，不必强行给自己定型。
- 建议在进入新关系、发生重大冲突后复盘一次，看看哪些描述仍然准确。
- 用行为描述代替标签：写“被追问时会沉默”，不写“回避型人格”。
- 本地保存即可；如使用共享设备，建议关闭预览或加密。

## 三、对 AI 建议的影响

- **话术密度**：书面偏好或内向的用户，给短句、留白和可复制的一段话，不塞连续追问；直接型用户可给更明确的邀约句，同时提醒场合与语气。
- **推进速度**：慢热用户降低邀约频率，先建立稳定联系；快节奏用户增加“确认对方意愿”的提醒，避免把速度当默契。
- **冲突建议**：回避型给“暂停加回归时间”的模板，例如“我需要一小时，晚上九点我们继续”；当场型提醒先降情绪再谈内容。
- **表达方式**：委婉型给缓冲句（“我可能想多了，但我想确认一下”）；直接型给“事实—感受—请求”的结构，减少攻击感。
- **爱的表达**：按用户最想收到的方式设计小行动，而不是按用户习惯给的方式堆量；也提醒问对方“你怎么感受到被在意”。
- **经验差异**：经验少时给具体流程与例句，降低“必须会撩”的压力；经验多时不假设用户不需要学习新对象的需求。
- **不贴标签**：不使用“恋爱脑”“海王”“直男”“作”等词评价用户或对方。

## 四、需要核验

- 自评可能偏低或偏高；用最近三次真实互动的表现来校准，而不是凭印象。
- 一次冲突中的表现不代表固定风格；压力、睡眠、酒精都会改变表达。
- 经验多不等于沟通能力强，经验少也不等于没有判断力。
- 慢热与“没兴趣”外观相似：看是否有稳定回应、是否愿意见面，而不是只看热度。
- 对方的风格需要单独了解，不能用用户的画像去推断对方。
- 风格可以调整，但不必伪装成另一个人；长期扮演会消耗关系。

## 五、隐私与边界

- 默认本地保存；交往史只填概括；可留空、可删除、可随时修改。
- 不记录前任的可识别信息，不上传聊天截图与合照。
- 画像只描述用户自己，不用于给伴侣贴标签，也不做“恋爱能力评分”。
- 不向第三方展示；不用于广告或匹配推荐。
- 涉及跟踪、骚扰、隐私要挟，优先保存证据并报警（110），法律问题拨 12348。

## 六、与 user-009 的分工

user-009 管“能量与频率”：社交电量、媒介偏好、联系节奏、冲突后的恢复方式。本篇管“经验与风格”：怎么表达、怎么冲突、喜欢什么推进速度、如何接收爱意。调用时先读 009 定联系频率，再读 013 定句式密度与节奏；两者冲突时，以用户当下状态为准，并允许随时改。
