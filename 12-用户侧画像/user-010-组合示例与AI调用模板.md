# 组合示例与 AI 调用模板

> 单一字段只微调语气，几个字段组合才形成完整策略。示例展示画像如何影响建议，不代表同组合的人一定相同。

## 示例一：24 岁女性 / 双性恋 / 探索期 / 内向

- **画像**：刚毕业，正在探索取向与关系模式，社交电量有限。
- **语气**：温和、给选择、不替她定义；避免"你应该多试试"。
- **话题**：兴趣、价值观、轻量见面；不猎奇她的性取向。
- **节奏**：低频稳定，提前约，允许慢回。
- **边界**：不催出柜、不替她向家人公开、不把探索当实验。
- **风险**：被当"好奇体验"、社群诈骗、探索期给出超前的承诺。

## 示例二：28 岁男性 / 异性恋 / 认真长期 / 都市

- **画像**：工作稳定，想找可发展的伴侣，家庭有催婚压力。
- **语气**：务实、尊重、不爹味；谈现实但不把婚姻当交易。
- **话题**：生活规划、家庭观、金钱观、工作节奏。
- **节奏**：中频、预约式；重要话题不临时抛。
- **边界**：不把结婚当 KPI、不隐瞒婚育与债务、不替对方规划人生。
- **风险**：催婚导致仓促、过度挑剔、经济不对等被忽视。

## 示例三：35 岁女性 / 休闲约会 / 外向

- **画像**：事业稳定，想轻松约会，不预设长期承诺。
- **语气**：轻松、直接、有幽默；不暗示"迟早会认真"。
- **话题**：旅行、美食、当下体验、朋友与兴趣。
- **节奏**：中高频，允许临时分享，也尊重工作时段。
- **边界**：尽早说清非排他、防护安排、隐私范围。
- **风险**：一方动情后不敢说、被评判"不认真"、暧昧消耗对方。

## 示例四：42 岁女性 / 离异带娃 / 认真再婚 / 慢热

- **画像**：离异并有孩子，想认真再婚，但需要时间建立信任。
- **语气**：稳、耐心、不催；承认前任与孩子是生活的一部分。
- **话题**：孩子日常、生活安排、与前任的边界、长期规划。
- **节奏**：低频、提前约；不突然安排孩子见面。
- **边界**：不替孩子找"替代父母"、财产与继承先沟通、不比较前任。
- **风险**：孩子介入过快、前任纠葛、被催婚或催生。

## 示例五：30 岁男性 / FWB / 非排他

- **画像**：明确只要 FWB，不进入排他恋爱，双方均可认识别人。
- **语气**：直接、清楚、不羞辱；不制造"以后会转正"的期待。
- **话题**：边界、检测、见面方式、如何结束。
- **节奏**：弹性但可预期；不玩消失。
- **边界**：双方知情自愿、不欺骗、不施压、做好安全措施；不传播隐私。
- **风险**：一方动情、隐瞒其他伴侣、影像与隐私泄露。

## 示例六：50 岁丧偶 / 重新开始 / 谨慎

- **画像**：丧偶后想重新认识人，节奏谨慎，重视陪伴质量。
- **语气**：尊重哀伤、不比较、不催"放下"；平实而不居高临下。
- **话题**：兴趣、日常陪伴、健康、纪念日与家庭。
- **节奏**：慢、稳定、可预期；重要日子允许对方独处。
- **边界**：不替对方处理财产、不急于同居、先与子女沟通。
- **风险**：黄昏恋诈骗、财产与继承纠纷、子女过度干涉。

## AI 使用规则

1. **先问必要信息**：年龄带、关系状态、当前情感需求优先；一次问一至两项，并说明用途。
2. **不过度追问**：敏感项可跳过；不追问出生时间、身体细节、收入、住址、恋爱数量。
3. **敏感信息本地保存**：不上传、不外传、不写入共享文档；用户可随时修改或删除。
4. **建议前确认双方同意**：不生成欺骗、隐瞒、施压或绕过拒绝的方案；不替用户编造经历与身份。
5. **先校准再建议**：画像用于调整建议，不用于给他人贴标签或施压。
6. **遇到风险转 06/07**：诈骗、跟踪、暴力、性胁迫、隐私泄露，转 risk-001、risk-012、risk-021、tactic-029；紧急拨 110。
7. **需求会变**：每次重要对话前确认画像是否仍准确，不拿旧画像套新情境。
8. **允许纠正**：说明建议依据了哪些字段；用户说"不是这样"时，以用户的更正为准。
