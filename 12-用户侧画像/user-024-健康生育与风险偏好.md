# 健康生育与风险偏好

> 这一页帮用户梳理与婚育相关的健康事实、检查计划与告知边界。它不替代医生，也不评价“该不该生”。所有医学判断以正规医疗机构为准；AI 只帮用户把问题问清楚、把话说明白。

## 一、维度定义

健康生育与风险偏好包含五块：

1. **检查状态**：婚检、孕前检查是否做过，是否有需要复查的项目。
2. **生育相关情况**：是否已知生育困难、是否在治疗、是否有流产或高风险妊娠史。
3. **家族史**：遗传病、先天性疾病、早发慢病等，是否需要遗传咨询。
4. **长期健康状况**：慢病、残障、精神健康问题，是否影响日常生活与照护安排。
5. **风险偏好与告知边界**：愿意接受多大程度的医疗不确定性，哪些信息只告诉伴侣、哪些暂不告诉任何人。

“风险偏好”不是胆大胆小，而是对不确定性的接受度：有人愿意尝试多轮治疗，有人更早考虑领养或丁克，都是合法且值得尊重的选择。

## 二、常见取值

| 取值 | 具体表现 | 对沟通与建议的影响 |
|---|---|---|
| 已完成检查，无特殊情况 | 婚检或孕前检查做过，医生未提示重点风险 | 把检查当常规健康管理，不拿来审查对方；结果仍属隐私 |
| 计划检查或尚未检查 | 知道有这项，但还没安排 | 不催促、不把“没检查”等同于不负责；给出时间窗口与正规渠道即可 |
| 已知生育困难或正在治疗 | 备孕未果、正在就诊、考虑辅助生殖 | 避免“是不是你的问题”式归因；治疗周期会影响时间、情绪与预算 |
| 有遗传病家族史或携带者 | 家族中有遗传病，或筛查提示携带 | 建议遗传咨询，说明的是概率与选项，不替用户决定生或不生 |
| 有慢病或残障，需长期管理 | 需要用药、复诊、无障碍安排或照护支持 | 关系里要谈实际支持与分工，不用“拖累”叙事；残障不是减分项 |
| 有高风险妊娠史或复发性流产 | 曾有妊娠并发症、流产、早产等经历 | 以产科评估为准；伴侣的支持要具体，避免“再试一次”式催促 |

## 三、对沟通、择偶与关系节奏的影响

**沟通方式。** 告知用“事实—影响—我需要什么”：事实是医学诊断或检查结果，影响是治疗、时间、费用、身体限制，需要是“陪我复诊”“暂时不告诉父母”“先不讨论生育”。不用一次说完所有细节，但要避免用模糊说法让对方误判。

**择偶判断。** 健康情况本身不是筛选条件，真正需要评估的是：双方对不确定性的接受度是否接近、是否愿意共同面对治疗周期、是否在照护分工上诚实。把“能不能生”当唯一标准，会忽略伴侣作为人的其他部分，也会给当事人巨大压力。

**关系节奏。** 婚检、备孕、治疗是三个需要重新排期的节点。治疗期间约会质量可能下降，建议提前说明“哪段时间精力低”，并保留小的连接方式。涉及辅助生殖的费用与成功率，以正规医院的评估为准，不轻信“包成功”的宣传。

**隐私边界。** 检查结果先属于本人。是否告诉伴侣、告诉到什么程度、是否告诉双方父母，由本人决定。伴侣知情不等于全家知情；AI 不应替用户扩散，也不应建议用隐瞒来维持关系。

## 四、与其他维度的组合规则

- **与 user-011 婚育意愿**：要不要孩子、时间线由 user-011 记录；本页补充“身体条件与风险接受度”，两者不互相替代。
- **与 user-012 财务边界**：治疗与辅助生殖费用可能较高，需单列预算，不挪用应急金、不借贷赌成功率。
- **与 user-014 隐私安全**：病历、检查报告、用药信息属高敏感数据，不写入共享文档、不发截图。
- **与 intimacy-008 避孕与性健康检查**：避孕方式与性健康检查属日常健康管理，可与本页交叉参考。
- **与 intimacy-013 流产产后与生育相关性健康**：流产后的身体与情绪恢复需要时间，不催“尽快再怀”。
- **与 persona-026 慢性病残障与照护者**：长期健康问题需要照护分工与喘息支持，不能只靠伴侣体谅。
- **冲突处理**：先分清医学问题与关系问题；医学问题听医生，关系问题谈需求与边界。

## 五、AI 调用示例

**示例一：检查结果要不要告知**

用户自述：“婚检查出我是携带者，医生说一般没事，但我不知道该不该告诉对方。”

建议调整：先建议用户找遗传咨询或主治医生确认三件事：对本人健康的影响、对生育的影响、伴侣是否需要检测。把“一般没事”这种模糊说法换成可转述的准确表述。然后帮用户准备告知句：“我检查出携带，医生建议你也做个检测，这不影响我现在的生活。”不替用户决定说或不说，也不替用户判断关系走向。若用户选择暂不告知，提醒重大生育相关信息在备婚前应重新评估。

**示例二：备孕压力与归因**

用户自述：“我们试了一年没怀上，婆婆总暗示是我的问题，我很难受。”

建议调整：先接住情绪，明确“未孕不等于某一方的问题”，建议双方一起到正规生殖医学科检查，而不是只查一方。给用户一句边界话术：“我们在按医生安排检查，结果出来会一起商量，暂时不想被催。”不承诺成功率，不推荐偏方或“包怀”机构。若伴侣在压力下站到长辈一边，讨论的是伴侣支持问题，不只是医学问题。

## 六、边界：不是标签

- 不替用户做医学决定，不判断“该不该生”“该不该治”，不承诺成功率。
- 不推荐具体医院、医生、偏方或“包成功”机构；就医选择以正规医疗机构与本人意愿为准。
- 不把生育能力等同于个人价值，不用“不能生”作为贬低或分手理由的合理化。
- 不询问与当前问题无关的病史；不记录病历号、身份证号、具体诊断细节。
- 残障、慢病、精神健康问题不是婚恋减分项；需要的是实际支持与无障碍安排。
- 检查结果、遗传信息属高敏感隐私，未经本人同意不向伴侣家庭或第三方转述。
