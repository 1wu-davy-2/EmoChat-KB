# 私密影像态度与数字留存习惯

> 面向 18 岁以上成年人。这一页记录用户对私密影像的态度、发送与留存习惯，用来让 AI 调整建议，不是评判，也不是“发过就活该”的依据。默认本地保存，敏感项可留空；AI 不鼓励发送、不索要、不评价、不责备。

## 一、字段说明

- **是否发过/考虑过/绝不发**：发过 / 考虑中 / 绝不发 / 不愿讨论；任何取值都不影响获得安全建议。
- **发送对象**：固定伴侣 / 暧昧对象 / 网恋对象 / 从未发送 / 不愿透露。
- **是否保存对方影像**：保存 / 不保存 / 对方知情 / 不知情；未经同意的保存是边界问题。
- **设备与云备份**：本地 / 自动云备份 / 关闭同步 / 加密相册 / 与家人共用 / 不清楚。
- **共享相册/隐藏相册**：使用共享 / 只用隐藏 / 两者都用 / 都不用；共享范围是否清楚。
- **录屏/截图**：接受 / 只接受双方知情 / 不接受 / 不接受任何留存。
- **要求对方删除**：已要求并确认 / 已要求未确认 / 不要求 / 不知道怎么开口。
- **分手后处理**：删除 / 保留 / 要求对方删除 / 换设备 / 需要安全退出方案。
- **曾被泄露/威胁**：无 / 曾被截图转发 / 曾被威胁 / 曾被索财 / 不愿透露。
- **可求助的人**：朋友 / 家人 / 其他可信者 / 专业支持 / 暂时没有。
- **底线**：绝对不接受的事，例如“不拍脸”“不录屏”“不发可保存版本”。

## 二、常见取值组合

| 类型 | 典型填法 | 对建议的影响 |
|---|---|---|
| 绝不发送型 | 绝不发、不保存对方影像、关闭云同步 | 不劝、不试探；只给拒绝与边界话术；不把“不发”当不信任 |
| 考虑中但焦虑 | 考虑过、担心泄露、与家人共用设备 | 先讲不可撤回性与设备风险；不建议“先发一张试试” |
| 发过并已要求删除 | 发过、已要求删除、对方口头答应 | 提醒口头答应不等于已删除；给确认删除与留证建议 |
| 保存对方影像型 | 保存、使用隐藏相册、未与对方确认 | 提醒未经同意的保存是边界问题；建议停止扩散 |
| 共享相册型 | 使用共享相册、邀请过多人、范围不清 | 检查成员与权限；提醒云链接可能被转发 |
| 曾泄露/被威胁 | 曾被截图转发、被威胁或索财 | 优先安全与取证；不建议新影像；给 110/12377/96110 |
| 分手清理型 | 分手后删除、换设备、要求对方删除 | 给分步清理清单；涉及威胁按 risk-037 处理 |

## 三、对建议的影响

- **是否给“拒绝发送/删除/取证/报警”话术**：按用户所处阶段给不同话术；绝不发的人只需拒绝句。
- **绝不发的人不被反复劝说**：不把“绝不发”当需要克服的羞耻，不提供“怎样慢慢接受”的步骤。
- **曾泄露的人优先安全与取证**：先确认是否仍有威胁、已传播、涉钱财；取证用已有记录，不再发新内容。
- **不建议“发一张证明信任”**：以影像证明爱、信任、忠诚、诚意的建议都排除；信任不需要抵押品。
- **不假设“发过就是同意保存/传播”**：发送同意只针对当时对象与范围；保存、展示、转发都需新的同意。
- **影响设备与留存建议**：使用共享相册、云备份、共用设备时，先检查权限与同步，再谈“删除”。
- **影响分手收尾**：要求对方删除时，给确认方式与留证建议；不鼓励私下谈判或单独见面。

## 四、不同习惯怎么谈：四步

1. **先确认安全**：有无威胁、传播、索财；有则先走安全与求助，不先问“你当初为什么发”。
2. **用用户自己的词**：说“绝不发”就记“绝不发”，不改写成“保守”；不替用户下结论。
3. **给选项而不是劝说**：拒绝、删除、确认删除、取证、报警、心理支持，条件与代价说清，由用户选。
4. **允许不讨论**：不愿透露时留空，不追问细节；换关系或过一段时间再复核。

## 五、AI 使用规则

1. **不鼓励发送**：不以“信任”“纪念”“别人都发”为论据；不生成、不润色、不评估影像内容。
2. **不索要**：不要求用户上传、描述或证明发过什么；不要求对方影像。
3. **不评价**：不说“发过就是随便”“不发就是保守”；不把影像经历当人格标签。
4. **不假设同意**：发过不等于同意保存、展示、转发；关系存在不等于永久授权。
5. **安全优先**：出现威胁、泄露、索财、跟踪，先给 110、12377、96110、平台举报与 12356。
6. **不责备**：不追问“为什么不拒绝”“为什么拍”；责任在未经同意保存、传播、威胁的一方。
7. **不提供操作方法**：不写如何拍摄、隐藏、传播、规避审核或恢复已删内容；只写拒绝、删除确认、取证与求助。
8. **未成年信号**：停止所有影像建议，只保留安全与求助；立即告知监护人并报警。

## 七、AI 调用示例

**示例一：绝不发，但被说“不发就是不爱”**

用户自述：我从不发私密照片，对象说不发就是不够信任，我有点动摇。

建议调整：先确认用户是否仍坚持“绝不发”；不劝“发一张试试”；给边界话术：“我不发这类内容，这跟信任你无关，以后也不用再提。”提醒：被推动的“同意”不是同意；若对方持续施压、冷暴力或威胁，按 tactic-053、risk-016 处理。不替用户判断关系去留。

**示例二：发过，现在担心云备份和前任**

用户自述：我以前给前任发过照片，手机相册有云备份，现在分手了，我怕他没删，也怕云里还有。

建议调整：先确认是否有威胁或传播迹象；有则按 risk-037 取证、平台举报、拨 110。没有则给分步清理：检查云备份与共享相册、关闭自动同步、删除本地与云端副本、更换共享链接与密码、检查旧设备；提醒“删除自己的副本”不等于“对方已删除”，可礼貌要求确认删除，但不单独见面、不转账。若被威胁，停止谈判并报警。
