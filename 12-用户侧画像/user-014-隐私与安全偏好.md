# 隐私与安全偏好

> 这一页记录用户在关系公开、影像、定位与数据留存上的边界，用来避免 AI 给出“默认公开”“默认视频”的建议。默认本地保存，敏感项可以只写“不透露”。

## 一、字段说明

- **关系公开程度**：完全公开 / 只对朋友公开 / 只对家人公开 / 完全不公开。不同圈子可以不同。
- **性取向与关系状态公开**：已出柜 / 部分出柜 / 未出柜 / 不适用。出柜状态是动态的，且分对象。
- **照片与定位**：可发正脸 / 只发不露脸 / 不发；是否允许带定位、是否允许打卡、是否允许对方发布合照。
- **社交媒体互动**：可 @、可评论、可互关 / 保持零互动。公开互动可能被同事、家人看到。
- **语音与视频**：接受 / 只接受语音 / 只接受文字 / 需先约时间。不接受视频不等于不信任。
- **紧急联系人**：可选填一位，用于线下见面安全提醒；不需要填真实姓名，可写“朋友 A”。
- **聊天记录**：本地保存 / 定期删除 / 不保存 / 只保存要点。
- **AI 记忆**：允许记住敏感信息 / 只记非敏感 / 本次会话后不保留。涉及健康、性取向、住址的内容默认不记。

## 二、选项与记录方式

- 每项选一个主选项；可加“对谁”限定，例如“对朋友公开，对同事不公开”。
- 敏感项可整体留空，或只写“有边界，暂不细说”；AI 不追问。
- 建议用“是/否/看情况”加一句备注，避免长篇叙述。
- 出柜状态建议标注“对家人/对同事/对朋友”三个维度，不用一个词概括。
- 紧急联系人只需一个称呼与联系方式的存在性，不必填完整号码。
- 每半年或在换工作、搬家、进入新关系后复核一次。

## 三、对 AI 建议的影响

- **公开程度低**：不建议在对方社交圈公开互动、不安排高曝光场所、不主动提出见家长；提醒合照与定位可能暴露关系。
- **未出柜**：不替用户向家人出柜，不设计“公开惊喜”；提醒共同好友、截图、算法推荐带来的外泄风险。
- **影像边界**：不索要私密影像，不建议发送；提醒一旦发出无法完全撤回，参考 risk-012。
- **视频偏好**：不接受视频时只给文字或语音方案，不把“开视频”当信任测试。
- **安全提醒**：首次线下见面建议告知紧急联系人、选公共场所、自行往返，参考 risk-014。
- **记忆设置**：不允许记忆时，不跨会话引用敏感信息；建议用户定期清理本地记录与缓存。
- **求助路径**：遭遇影像要挟、跟踪、骚扰，保存证据并拨 110；法律问题拨 12348；接到 96110 请接听，报警仍拨 110。

## 四、需要核验

- 出柜状态可能随家庭、工作环境变化；旧记录可能已失效，引用前先确认。
- “公开”与“安全”不总是一致：某些公开会带来职场或家庭风险，需按用户实际情况判断。
- 照片一旦发出，删除只能减少扩散，不能保证彻底消失；截图与转发不受原发布者控制。
- 对方的公开边界可能与本方不同，需分别确认，不能以一方意愿代替双方。
- 紧急联系人信息可能过期；AI 只做提醒，不代为联系，除非用户明确要求且情况紧急。
- 平台隐私设置会变，具体以应用内说明为准，不假设“仅好友可见”绝对安全。

## 五、隐私与边界

- 默认本地保存，最小化收集；不记录身份证号、住址、单位、车牌等可识别信息。
- 可留空、可删除、可导出、可随时修改；撤回后不再引用。
- 不把性取向、出柜状态当风险标签或“问题”，只作为建议约束条件。
- 不向第三方展示，不用于广告；共享设备上建议关闭通知预览。
- 不替用户做公开决定，也不在用户未同意时生成可识别其身份的内容。
- 涉及未成年人、性胁迫、影像敲诈，优先安全与报警，必要时转 12338、12348。
