# 生活方式、消费观与财务边界

> 这一页用于让用户说清自己的消费习惯与财务底线，帮助 AI 给出不尴尬、不超预算的约会与边界建议。默认本地保存，金额可填区间，可全部留空。

## 一、字段说明

- **消费风格**：节省 / 平衡 / 享受 / 波动大。风格没有优劣，节省不是抠，享受也不是拜金。
- **收入带**：可选区间（如“够用略有结余”“月光”“有较大压力”），不需要具体数字。
- **储蓄与债务**：有无应急金、是否有高息负债、是否在为买房或教育储蓄。只记“有无”和压力程度即可。
- **约会预算**：单次可接受范围、每月上限；可写“看情况”，但要有一个不心疼的上限。
- **付费方式偏好**：AA / 轮流 / 一方承担 / 按场景。没有唯一正确答案，关键是双方预期一致。
- **借贷与担保底线**：是否借钱给伴侣、是否为对方贷款担保、是否共同贷款。建议默认“不借超出可承受损失的钱、不做担保”。
- **彩礼、婚礼、房产态度**：接受 / 不接受 / 可协商 / 看对方家庭；金额与形式属家庭协商，不是统一标准。
- **共同账户**：完全合并 / 部分共同 / 各自独立。与 user-011 的金钱观字段互补即可，不重复填。

## 二、选项与记录方式

- 金额优先填区间或档位，例如“单次约会 100 至 300 元”“每月不超过收入的十分之一”，不填精确工资。
- 每个字段可加一句备注：“愿意为旅行花钱，但不愿为奢侈品买单。”
- 不确定的项目标“未想好”，AI 不应替用户设定一个数字。
- 涉及债务只记类型与压力，不记账号、密码、借贷平台名称。
- 建议在关系推进（同居、订婚、共同买房）前复核一次，因为此时财务边界最容易被模糊。
- 记录自己的底线即可，不写“对方必须付钱”“对方不能管钱”这类对他人要求。

## 三、对 AI 建议的影响

- **约会推荐**：按预算给低压力方案（散步、家常菜、免费展览、公园），预算低不等于敷衍；不推荐明显超出上限的餐厅或礼物。
- **付费建议**：给“轮流请”“大额 AA、小额互请”等可执行方案，不评判谁该付；避免把付费方式与性别绑定。
- **边界提醒**：用户提到伴侣借钱、要求担保、共同贷款时，先提示风险与书面约定，建议咨询 12348；不替用户答应。
- **经济控制识别**：对方要求上交工资、查账、禁止工作、以钱换顺从，属于风险信号，参考 risk-013，给安全与求助路径。
- **消费冲突**：把“你太抠/你太败家”翻译成具体分歧（储蓄比例、单次上限、礼物预期），给协商句而不是道德评价。
- **不盘问收入**：用户不愿填时，用“预算档位”继续工作，不反复追问。

## 四、需要核验

- 收入、债务、家庭负担会变化；引用前确认字段是否过期。
- 彩礼、婚礼、房产在不同地区与家庭差异很大，不能按单一标准判断“合理”或“过分”。
- AA 不是唯一健康模式，一方承担也不必然等于控制；要看是否自愿、是否可持续、是否有隐性交换。
- “愿意为你花钱”不等于爱，“不愿超支”也不等于不爱；避免用消费证明感情。
- 共同贷款、担保的法律后果较重，具体以合同与法律咨询为准，AI 不做法律结论。
- 对方的经济状况属于对方隐私，用户不应通过查账、翻手机获取。

## 五、隐私与边界

- 默认本地保存；金额可只填档位；可留空、可删除、可随时修改。
- 不收集银行卡号、支付密码、借贷账号；不引导用户上传账单截图。
- 画像只描述用户自己，不用于给伴侣贴“抠门/拜金”标签，也不做“经济匹配分”。
- 不向第三方展示，不用于广告推送；共享设备上建议关闭敏感字段的预览。
- 涉及经济控制、家暴或债务胁迫，优先安全：可拨 110、12338，法律问题拨 12348。
