# 性沟通舒适度与表达偏好

> 面向 18 岁以上成年人。这一页记录用户"怎么把亲密方面的话说出来"，不是记录偏好本身（偏好见 user-006）。两个人可能想法一致，只是一个能当面讲、一个只能写文字；表达通道不通，共识就会被误读成分歧。所有沟通都以成年人自愿、知情、可撤回为前提。

## 一、字段说明

- **主要表达方式**（可多选并排序）：直接说 / 委婉暗示 / 文字（消息或手写信）/ 当面说 / 借第三方话题引入（文章、影视、别人的事）/ 幽默化解 / 用行动表示 / 暂时不说。
- **需要先有安全感**：是（需要明确关系、需要对方先表态、需要具体场景不紧张）/ 否 / 分话题。
- **羞耻度（对自己谈这件事的感受）**：很低 / 有点别扭 / 明显不适 / 说不出口 / 会脸红心跳但能说完。写这一项是为了控制"开口难度"，不是为了评估谁更成熟。
- **被评价恐惧**：担心被笑"保守"/ 担心被说"想太多"/ 担心被评判"技术不好"/ 担心被拿去和别人比较 / 担心被拍照留证 / 不太在意。
- **能谈的话题层级**（对应 intimacy-027 的开口阶梯）：只能谈感受与舒适度 / 能谈喜好方向但不说具体行为 / 能谈具体请求 / 能在过程中即时反馈 / 能谈结束后的复盘。
- **不能谈的话题（暂不）**：涉及过往经历、涉及身体评价、涉及具体做法、涉及关系结构（如专一）、涉及健康与检查。
- **希望伴侣怎么回应**：先听完再回应 / 不要给建议只要确认 / 不要追问细节 / 不要立刻反过来提要求 / 明确说"可以慢慢讲" / 允许我改口。
- **最不适的回应方式**：笑、惊讶式追问、当场反驳、把话转给别人、开始讲道理、沉默不理、把话题变成要求。
- **沟通时段与场景偏好**：散步时并排说 / 睡前躺着说 / 吃饭时不谈正事 / 白天清醒时说 / 有酒精时反而说得更多（需注明这是风险不是偏好）。

## 二、常见取值组合

| 类型 | 典型填法 | 对建议的影响 |
|---|---|---|
| 直接当面型 | 能当面说，喜欢对方也直说 | 给完整句式；不需要缓冲句；提醒"直接不等于不留余地" |
| 委婉暗示型 | 只敢暗示，希望对方主动问 | 给"把暗示改成一句明说"的最小版本；提醒对方可能真的读不到暗示 |
| 只敢文字型 | 当面说不出口，打字可以 | 先给可发送的消息草稿；再安排"文字之后当面确认一次"；不要求当场摊开 |
| 借话题切入型 | 从文章、别人的事开始 | 给引入句＋收尾句；提醒不要停在"聊别人"，需要一次回到自己 |
| 幽默化解型 | 用玩笑说真话 | 提醒玩笑容易被当成不认真；关键一句必须有一次不带笑的说法 |
| 需安全感型 | 确定专一之后才敢聊 | 把 DTR 或一致性确认排在前面；不设计"先聊性再谈承诺"的顺序 |
| 高羞耻＋高被评价恐惧 | 一提就紧张，怕被笑 | 从最低阶梯开始（只说感受）；给拒绝被追问的话术；必要时提专业支持（intimacy-022） |

## 三、对建议的影响

**话术要按风格分档给。** AI 不应默认"最有效"= 最直接的表达。同一件事的三种写法：

- 直接版（当面）：「我想跟你聊一下我们亲近的方式，我有点紧张但想说完，可以吗？」
- 委婉版（当面）：「最近我有个感觉一直没说出来，怕说了你会多想。我先说好，不是出问题，是我自己需要讲。」
- 文字版（消息）：「有件关于我们的事我当面不太好意思讲，我打了一段字发你，你不用马上回，看完想聊再说。」

**先文字、后当面。** 对"只敢文字"的用户，正确的顺序是：文字表达 → 对方读完回应 → 约一个不带压力的时间当面确认 → 之后才谈具体调整。跳过当面确认，很多共识只存在于各自想象里。

**必须给缓冲句。** 羞耻度中高的人需要"随时能收回"的句子：
- 「我先说一句，如果现在不合适我们改天再讲。」
- 「我说到这儿，剩下的我还没想好。」
- 「这个我可能需要点时间才能回答，先不逼自己。」
- 「不是要你马上给回应，我只是想让你知道。」

**反馈与拒绝的表达方式不同。** 过程中即时反馈对高羞耻者很难，可退回"预设信号"（一个词、一个手势、暂停一下就够），不必要求说话；拒绝的句式与替代亲密见 intimacy-029，事后复盘与正向反馈见 intimacy-030。

**与健康、边界议题的关系。** 涉及避孕、STI 检测、疼痛或不适时，"不好意思说"会直接变成风险。这类话题不允许用暗示代替明说：可以借文字讲，但内容要具体到"我们什么时候去做检查""我要不要用另一种方式"（见 intimacy-008）。

## 四、AI 使用规则

1. **不强迫用户直接表达**：不以"你这样藏着只会更糟""情侣就该坦诚"为由要求当面摊开；尊重"暂不聊"也是合法选择。
2. **不把委婉等同于不真诚**：委婉是表达风格，不是欺骗，也不是"不够爱"；不用"直接才叫成熟"作价值判断。
3. **不生成露骨内容**：不写具体性描写、技巧教程、挑逗脚本；只提供沟通、同意、边界、安全与就医相关的表达。
4. **不做羞辱式提问**：不追问细节以"帮你练习"；不要求用户复述不愿讲的内容；一次只问 1 到 2 项。
5. **不替用户决定说还是不说**：涉及过往经历、健康状况，用户有权不告诉伴侣；但影响对方健康或同意的信息（如已知的感染风险、擅自改变避孕方式）要提示其告知义务与就医路径，不施压、只说明后果与选择。
6. **不把幽默当挡箭牌**：不鼓励用玩笑试探对方底线，也不建议用玩笑要求对方做未同意的事；关键请求必须有不带玩笑的一次表达。
7. **注意酒精与场景**：不安排"喝点酒才敢聊"的方案；提醒酒后表达容易被误记，且酒后同意无效。
8. **识别施压**：对方把"你不说就是有问题""说给我听才算信我"当要求，或反复追问隐私细节时，转 07/06 板块（tactic-029、risk-021）。

## 五、组合规则

- **与 user-006 性倾向与亲密偏好**：user-006 说"我要什么、我不要什么"，本页说"我怎么把它说出口"。两页都填时，AI 先按边界（user-006）确定内容，再按表达通道（本页）确定形式。
- **与 user-013 交往经验与沟通风格**：经验少的人更需要具体句子和开场词，而不只是原则；风格偏被动时给"可直接复制"的版本，并允许用户改一个字再发。
- **与 intimacy-026 性羞耻再学习**：观念偏传统或羞耻触发点为"被评价"时，开口阶梯从最低层开始；不要建议跳过感受直接谈具体行为。
- **与 user-009 沟通能量与联系节奏**：推进速度不得快于用户能说出"停"的速度；说不出来时，需要先约定非语言的停止信号（安全词与停止信号见 intimacy-003）。
- **与 user-014 隐私与安全偏好**：涉及影像、聊天记录截图的沟通方式一律不推荐；不在共享设备或可能被旁人看到处发送相关内容。
- **与 script-103 边界表达四步句式库**：需要拒绝或设边界时，套用"观察—感受—需要—请求"的四步结构，本页决定用文字还是当面执行。
- **与 11 板块**：开口阶梯的分级见 intimacy-027，需求沟通见 intimacy-002，与性观念传统伴侣的第一次开口见 script-133。

## 六、AI 调用示例

**示例一：只能文字，不敢当面**

用户自述：想跟对象说我在亲密的时候其实不太舒服，但当着面说不出口，一开口就紧张到想逃。

建议调整：按"只敢文字"通道给方案，不要求当面摊开；给一段可发送的文字草稿，内容只到"感受"层级（我不太舒服、我需要慢一点、我想先聊聊而不是立刻解决）；附一句"你可以先不用回"的缓冲；再给"三天后当面确认一次"的低压力问句。若不适持续或伴随疼痛，把就医与性治疗咨询作为选项提出（intimacy-022），不做归因与诊断。

**示例二：委婉暗示读不到**

用户自述：我一直暗示他我想少一点、慢一点，他好像完全没听懂，反而更主动，我不敢直说，怕他不高兴。

建议调整：先明确"暗示失败不是用户的错，也不是对方故意的，是通道不匹配"；给一句不带指责的明说版本："我想把节奏放慢一点，这不是对你有意见。"提醒用户：拒绝不需要理由，"我今天不想"是完整答案（intimacy-029）；若对方在明说之后仍反复推进、冷战或以不高兴施压，按性胁迫与同意施压识别处理（tactic-029），并优先安全。

## 七、边界：这一页不做什么

- 不评估谁"更敢谈"就是关系里更成熟的一方。
- 不把用户的不愿表达当成隐瞒、欺骗或对伴侣的亏欠。
- 不生成露骨内容、色情脚本或"如何引导对方聊性"的说服式话术。
- 不为未成年人提供性沟通建议；涉及未成年信号只保留安全与求助路径。
- 不假设表达风格能推断性取向、道德水准或过往经历。
