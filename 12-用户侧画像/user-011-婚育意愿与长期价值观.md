# 婚育意愿与长期价值观

> 这一页记录的是用户自己的意愿，不是对伴侣的评判表。字段可以留空、可以只填大概、可以随时改；默认本地保存，不上传、不展示给他人。

## 一、字段说明

- **婚姻形式**：结婚 / 不婚 / 同居不领证 / 不确定 / 已登记。不婚不等于排斥亲密关系，同居也不等于“将就”。
- **生育意愿**：想要 / 不想要 / 想要但条件未满足 / 领养 / 辅助生殖 / 不确定。想不想要孩子与喜不喜欢孩子是两件事。
- **时间线**：一年内 / 两到三年 / 不设期限 / 不确定。时间线是沟通工具，不是承诺书。
- **信仰与仪式**：无 / 有（宗教、民俗、素食、节日禁忌等）。只记对日常生活有影响的部分。
- **居住安排**：常住城市、是否接受异地、是否接受与父母同住或就近居住。
- **父母照护**：双方父母养老、疾病照护、经济支持的责任预期。
- **家务与金钱观**：分工偏好、是否合并账户、大额支出如何决策。可与 user-012 互补，不必重复填。
- **底线与可协商项**：哪些是“没有就不行”，哪些是“可以谈”。这是最有用的字段。

## 二、选项与记录方式

- 每项先选一个主选项，再用一句话备注。例如：“生育：不确定；如果对方非常想要，我愿意认真谈，但不接受被催。”
- 不确定是合法答案，不要为了填满而编一个。空白比虚假信息更有用。
- 可标“暂不透露”，AI 不应反复追问，也不应把空白解释成默认值。
- 建议每三到六个月复核一次，尤其是进入同居、订婚、备婚、备孕阶段时。
- 记录格式建议：字段 / 选项 / 备注 / 更新日期。只写自己的意愿，不写“对方应该怎样”。
- 本地保存即可；如果使用云同步，先确认是否包含敏感内容，并设置访问权限。

## 三、对 AI 建议的影响

- **不劝婚、不劝生**：不把结婚生育当关系成功的默认终点；不把“不婚不育”当需要修复的问题。
- **匹配提示**：当用户与对方在婚育上明显冲突时，提示“这是价值观差异，不是谁有毛病”，给早谈、具体、可退出的沟通框架，不替用户筛选或下结论。
- **话术调整**：对明确不婚的用户，不安排“见家长催婚”“订婚流程”类建议；对想要孩子的用户，在长期关系话题中加入时间线、身体与财务准备的讨论。
- **场景取舍**：备婚、备孕相关内容只在用户主动提及时展开；不主动推送“该要孩子了”的提醒。
- **冲突处理**：当对方家庭施压，先给边界句与伴侣分工建议（由原生子女出面沟通），不鼓励用户独自对抗。
- **不做推断**：不用婚育意愿推断性别角色、收入能力或感情认真程度。

## 四、需要核验

- 意愿会随年龄、经济、健康、关系状态变化；AI 引用前先确认“这条还准确吗”。
- “想要孩子”不等于“现在要”；“不想要”不等于讨厌孩子，也不等于未来不会改变。
- 辅助生殖涉及医学指征、法律与费用，需咨询正规医院；不承诺成功率，不推荐具体机构。
- 领养有法定条件与流程，具体咨询 12348 或民政部门，不凭网络帖子操作。
- 信仰条目只记录实际实践（饮食、节日、仪式），不按标签推断政治立场或生活习惯。
- 异地、与父母同住等安排，可能只是阶段性方案，不等于永久承诺。

## 五、隐私与边界

- 默认本地保存，最小化收集；不填身份证号、具体住址、工作单位等可识别信息。
- 可留空、可删除、可导出、可随时修改；撤回后 AI 不应继续引用旧值。
- 画像只描述用户自己，不用于给伴侣贴标签（如“对方就是不想负责”），也不做匹配评分。
- 不向第三方展示，不用于广告或信用评估；涉及家庭暴力时，敏感字段不应出现在共享设备上。
- 若用户尚未向家人公开关系或生育计划，AI 的建议要避免“帮你通知家人”式操作。
