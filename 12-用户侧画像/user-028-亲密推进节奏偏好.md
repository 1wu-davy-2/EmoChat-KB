# 亲密推进节奏偏好（慢热/中等/快速）

> 这一页记录用户自己希望的推进速度：多久见面、多久聊一次、身体接触走多快、要不要先有承诺。它用来约束 AI 给的节奏建议，避免"第三天就表白""聊两周就该见面"这类一刀切。慢、中、快没有优劣，也没有"正常值"；唯一的标准是本人舒适且能说出口。

## 一、字段说明

- **从认识到见面的期望时长**：1 周内 / 2 到 4 周 / 1 到 3 个月 / 更久 / 取决于对方 / 只在有共同事务或活动场合见。
- **聊天频率与形式**：每天多次 / 每天一次 / 两三天一次 / 一周几次 / 只在有事时联系；偏好文字 / 语音 / 视频 / 见面；是否需要"每天互道晚安"这类固定仪式。
- **回复时间预期**：秒回会让我安心 / 半天内都正常 / 我不看消息所以别指望快 / 忙的时候几天不回也正常。
- **身体亲密节奏**：见面就可以牵手 / 需要几次见面后 / 明确关系之后 / 更慢且不设时间点；对亲吻、过夜、性行为的各自前提（可写"需要确定专一之后"）。
- **是否需要专一承诺才能继续投入**：必须先谈清楚 / 边走边看 / 不需要形式承诺但需要一致性 / 不确定。
- **情感表达的开放度与场合**：能当面说喜欢 / 只能文字说 / 不愿公开表达 / 需要对方先说。
- **对异地的接受度**：完全不接受 / 短期（1 到 3 个月）可 / 长期可但要定期见面 / 只要能维持就接受 / 我自己就在考虑迁移。
- **对纯线上关系的接受度**：可以长期只线上 / 最多 1 个月不见面 / 不接受线上认识的人 / 线上只是入口，最终要线下。
- **独处与亲密的时间配比**：需要每天 2 小时独处 / 周末要留一天给自己 / 尽量多在一起 / 看阶段。
- **关系节点的可接受跨度**：多久谈"我们算什么"、多久谈见家长、多久谈同居、多久谈婚育（可写"三个月内不谈婚育"）。

## 二、常见取值组合

| 类型 | 典型填法 | 对建议的影响 |
|---|---|---|
| 慢热型 | 1 到 3 个月才见面；两三天聊一次；需明确关系才有身体亲密 | 不给催促式话术；邀约以低压力、短时长、活动型为主；把"我需要时间"写成可说的话 |
| 中等型 | 2 到 4 周见面；每天一次聊天；3 次见面后再谈定义 | 按 scene-007 的"埋线→模糊→确定"三步推进，跟进节奏正常 |
| 快速型 | 1 周内见面；高频聊天；身体接触自然发生 | 提醒"快不等于不确认边界"；把同意与防护讲在前面，不默认对方同速 |
| 线上优先型 | 长期接受线上；对见面有顾虑（住址、社交焦虑、安全） | 不施压线下；提供视频/语音替代与"线上也可以谈清楚"的路径，安全动作保留 |
| 异地可接受型 | 接受短期异地，但要每月见面 | 建议在关系早期就把见面频率与成本说清，不做无限期承诺 |
| 低频联系但高投入 | 我不怎么看消息，但认定后很认真 | 提醒对方容易误读为冷淡；建议给出"我回得慢但不是不想聊"的说明句 |
| 节奏不稳定 | 状态好时快，压力大时想消失 | 不把它当"不真诚"；建议把周期与工作/健康压力一起讲给对方 |

## 三、对建议的影响

**决定话术的强度。** 同一句"我想多见见你"，对慢热用户像压力，对快速用户像不够。AI 应把邀约的具体度、频次和情绪浓度按本页取值调档，而不是统一套用高唤起表白（表白句式见 script-011）。

**决定推进动作的顺序。** 慢热用户优先做"低承诺、高确定性"的动作：短时长公开场合见面、固定但不过量的联系频率、先聊具体内容再聊关系。快速用户则要补上被忽略的确认环节：是否专一、身体接触的前提、防护与健康。

**决定"对方不回消息"的解释。** 用户自己的频率不等于对方的频率。AI 在解释冷淡/已读不回时，必须同时参考 user-009 沟通能量与对方实际的平台使用习惯（按其在线时段与回复频率观察，不做品性推断），不默认"不回=不喜欢"（见 scene-010 的冷场判断）。

**决定何时谈关系定义。** 本页的"关系节点跨度"直接决定 AI 是否支持现在就谈 DTR；用户填"三个月内不谈定义"时，AI 不应主动建议提前摊牌，除非出现必须澄清的具体场景。

**决定是否建议见面。** 用户对见面的接受度低时，AI 应给视频/语音/共同活动的替代路径，并把"不见面也可以把话讲清楚"作为合法选项，同时保留线下安全提醒（见 risk-014）。

## 四、与对方节奏不匹配时怎么谈

三步，不跳步：

1. **先确认差异而不是纠正差异。**
   「我发现你希望每周见两三次，我这边一次就够了才缓得过来。我先说这个不是拒绝你，是我们频率不一样。」
2. **说自己的需要，并给出可交换的方案。**
   「我需要工作日晚上留给自己；作为交换，周末我可以完整空出来。你那边能不能接受？」
3. **谈一个可复核的中间值，而不是一方彻底让步。**
   「我们先按两周见一次走，一个月后各自说一次感受，如果都别扭再改。」

不匹配的处理原则：

- 差异可以是节奏问题，也可能是不兼容问题。连续几次协商后仍需要一方长期压缩自己，就该按期待不合处理，而不是"再努力一点"。
- 不用"正常人都是这样"论证自己的节奏，也不用"我就是这样"拒绝一切调整。
- 不用消失、冷战、故意延迟回复来"教育"对方节奏（这类操控性做法见 tactic-003）。
- 身体亲密的前提不能因为"对方更快"而临时放弃；被推动的加速不是自愿（持续同意见 intimacy-007）。
- 对方是性观念传统、慢热的人时，参考 persona-035 的沟通方式：把话题从"具体行为"退回到"感受与安全感"，不当面逼表态，允许文字沟通。

## 五、AI 使用规则

1. **不催**：不给"再不定关系就被别人抢走""错过这个就没了"式的时间压力；不虚构稀缺性。
2. **不替用户设定"正常节奏"**：不说"聊两周应该见面了""三个月必须确认关系"；只用用户自述值作为节奏基准。
3. **不把慢热当问题**：不推断慢热源于创伤、回避型依恋或家庭问题，也不建议"克服一下"。
4. **不美化快**：不因"双方都有感觉"而跳过边界、同意、防护与钱的议题；也不建议刚认识就同居、借贷、共同投资。
5. **不越权设定对方的节奏**：不假设对方"其实也想快点"，只教用户如何问；不生成"如何让对方接受更快节奏"的话术。
6. **变更要复述**：用户改了偏好就按新值给建议，不引用旧值评判（"你上次不是说要慢吗"）。
7. **压力期允许减速**：工作、健康、家庭变故期间联系频率下降是正常调整，不作为冷淡证据。

## 六、组合规则

- **与 user-007 当前情感需求**：需求决定"要不要推进"，本页决定"多快推进"。若当前需求是陪伴或减压而非择偶，AI 不应给推进节奏建议。
- **与 user-009 沟通能量与联系节奏**：聊天频率偏好受精力类型影响；内向者的高频文字往来会透支，这不代表兴趣下降。两页冲突时，以"可持续的方式"为准。
- **与 user-013 交往经验与沟通风格**：经验少的人更需要明确的句子而非暗示；沟通风格偏被动时，AI 要给可直接复制的话术而不只是原则。
- **与 user-006 性倾向与亲密偏好**：身体亲密节奏不能快于用户的信任建立时长；两页冲突时，以更慢的一方为准。
- **与 intimacy-027 性话题开口阶梯**：节奏谈得再清楚，说不出口也无效；给建议时同步提供缓冲句与文字版表达。
- **与 scene-007**：邀约三步法与"被拒后怎么接"是执行层；本页提供何时启动邀约的判断层。
- **与 persona-035**：对方慢热时，本页的"我的节奏"要加上"对方的节奏"，两个自述值一起用来判断是否兼容。

## 七、AI 调用示例

**示例一：被要求加速**

用户自述：认识 10 天，对方每天找我七八次并想周末见面，我有点跟不上，但我怕直接说会被认为没诚意。

建议调整：以用户自述节奏（2 到 4 周见面、每天一次）为基准，不改变它；给一句陈述＋交换的话术："我很愿意继续聊，只是我习惯一天一两次深聊而不是全程在线；周六我可以见一面，两小时以内可以吗？"提醒用户：说明节奏不是拒绝，且不需要道歉。若对方因此冷暴力或指责"你不认真"，按不兼容与施压识别处理，不建议用户临时提速。

**示例二：自己快、对方慢**

用户自述：我认识一周就想见面，对方说想再聊聊，感觉被拖着。

建议调整：先确认对方的"慢"是节奏还是婉拒——给一个低压力问句（"你是希望我们节奏慢一点，还是暂时不想见面？"）；不生成"说服对方见面"的话术；按 scene-007 回到模糊邀约与内容互动，并设定自己的停止线（例如"两轮实质往来后仍无进展，就收住"）。同时提醒不要用消失或和别人暧昧来施压。
