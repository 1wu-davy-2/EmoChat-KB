# 操控:媒介升级施压与线上亲密加速

> 本条只用于识别与 AI 案例分析，不是操作指南。操控路径以第三人称描述，坏话术样本仅用于识别，不要照说；不提供说服方法。

## 一、一句话定义

把“文字→语音→视频→私密内容→见面”包装成信任或爱的证明，用快于关系本身的升级速度制造既成事实：你还没想清楚，就已经“走到这一步了”。

## 二、仅用于识别，不是操作指南

### 前置条件

- **对方已建立好感或依赖**：高频陪伴、深夜长聊，让你把“聊得来”当成“可信任”。
- **你在意关系或怕失去**：拒绝被说成“破坏气氛”“会让他走”。
- **你不确定边界**：不知道哪一步算太快，也不好意思问“我们到哪了”。
- **对方掌握节奏**：何时升温、何时消失，都由对方决定。

### 阶段路线图

| 阶段 | 操控方会…… | 常见话术（仅用于识别） |
|---|---|---|
| 试探 | 用低门槛互动测试你是否配合：换平台、发语音、深夜聊 | “加个微信吧，这里不方便” |
| 专属化 | 给你唯一感 | “我从来没跟别人说过这些” |
| 门槛降低 | 把让步说成“很小的事”，再逐步加码 | “就一分钟”“别人都这样” |
| 既成事实 | 把已发生的升级当作关系已确定 | “都到这一步了” |
| 索取/控制 | 索取影像、密码、定位、金钱或保密承诺 | “你不许告诉别人” |
| 惩罚/召回 | 拒绝后冷暴力、羞辱、威胁，再以“最后一次”召回 | “你敢走我就发出去” |

## 三、识别用坏话术样本（仅用于识别，不要照说）

| 样本 | 阶段 | 它在做什么 |
|---|---|---|
| “先语音吧，打字太冷” | 试探 | 把媒介升级说成沟通质量 |
| “就一分钟” | 门槛降低 | 把持续暴露压缩成一次性小让步 |
| “别人都这样” | 门槛降低 | 用从众替代你的意愿 |
| “你不发就是不爱我” | 索取 | 把影像变成爱的考核 |
| “我都给你看了” | 索取 | 用互惠制造亏欠 |
| “都到这一步了” | 既成事实 | 把过去让步当成本次授权 |
| “你不做就是保守” | 索取 | 把拒绝说成观念落后 |
| “你不许告诉别人” | 控制 | 切断外部校验 |
| “你敢走我就发出去” | 惩罚 | 以影像为筹码，已近敲诈 |

## 四、识别信号

1. **速度远快于了解**：几天内就要语音、视频、私密内容或见面，却几乎不问你的生活。
2. **每次拒绝后升级**：换理由、换媒介、加情绪，而不是停下。
3. **用“证明”替代“了解”**：把升级说成“证明信任”。
4. **要求保密**：“先别告诉朋友”，切断外部参照。
5. **拒绝核验**：不肯回拨、不肯公开场景见面、不肯确认身份。
6. **只在自己方便时出现**：深夜、酒后、出差间隙。
7. **拒绝后冷暴力、羞辱或威胁**：消失、说你“玩不起”，再道歉、示好。

## 五、与健康媒介升级的分水岭

| 维度 | 健康升级 | 施压式加速 |
|---|---|---|
| 发起 | 双方都可提出，也可不提 | 一方定节奏，另一方被动跟 |
| 拒绝 | 停止，关系照常 | 被评价、冷落、威胁 |
| 节奏与撤回 | 可谈、可只升一级、可暂停、可撤回 | 每次都要“再进一步”，“你都答应了” |

健康升级：一方问“下次要不要语音？不方便就继续打字”，另一方说“现在不想”，话题照常。**升级不是信任考试，拒绝也不等于关系失败。**

## 六、受害方应对

1. **停**：不做新决定，不补发、不证明；先说“我需要想一下”。
2. **挂断/退出**：通话可挂断，视频可关掉，见面可离开，无需理由。
3. **保留证据**：保存聊天、通话记录、账号 ID、时间、威胁原话；不为取证继续配合，不二次转发。
4. **告诉可信的人**：一位朋友或家人知道，打破“只有我们两个知道”。
5. **举报与求助**：平台举报要求删除、封禁、留证；影像威胁、敲诈、未成年、线下跟踪拨 110，网络内容拨 12377，涉转账拨 96110，心理支持 12356。
6. **四不**：不谈判、不补发、不转账、不单独见面。“见面就删”“转钱就删”都不作数。

## 七、合成案例

### 案例 1：三天从文字到“只开一秒的视频”（合成案例，基于公开报道共性，非单一真实个案）

小 A 与对方认识三天，对方每天深夜长聊。第四天要语音，第五天要视频，说“就开一秒，证明你是真的”。小 A 打开后，对方镜头黑屏。第六天对方发来模糊截图，称“留了点纪念”，要小 A 发私密照片“交换”，否则“发给你同事”。小 A 停止回复，保存聊天与账号，告诉朋友，平台举报并拨 110。

识别点：升级远快于了解；对方镜头不可核验；用“纪念”制造筹码；拒绝后直接威胁。处置：不补发、不转账、不单独见面；影像威胁按 risk-016、risk-037。

### 案例 2：“都到这一步了”的线下加速（合成案例，基于公开报道共性，非单一真实个案）

小 B 与对方聊了两周，第一次见面被安排看电影、吃饭、去对方住处“坐一会儿”。小 B 说想回家，对方说“都到这一步了，你这样很扫兴”“别人第一次见面都这样”。小 B 坚持离开，对方冷处理两天，第三天道歉并约“最后一次见面说清楚”。小 B 没有赴约，把行程告诉了朋友。

识别点：连续动线降低离开机会；把拒绝说成扫兴；道歉后立刻“最后一次”召回。处置：离开优先于讲道理；不单独赴约；道歉不取消边界。

## 八、AI 判定规则（R1–R6）

**R1 高危：未成年、影像威胁或敲诈**
触发：涉未成年；影像威胁；索财。处置：停止互动；不转账、不补发、不谈判；保存证据；拨 110，网络内容拨 12377，涉转账拨 96110；涉未成年告知监护人。

**R2 高危：索取影像、要求保密、拒绝核验**
触发：认识不久即索要影像；“不许告诉别人”；拒绝视频、语音或见面核验。处置：明确拒绝；保留记录；平台举报；按 risk-016、risk-044 评估。

**R3 中高危：加速施压但未威胁**
触发：每次拒绝后换理由重提，用“别人都这样”施压。处置：给一次边界句，停止解释；看拒绝后是否停止；重复则退出。

**R4 中危：边界不一致**
触发：双方节奏不同，但对方能接受“不”，无惩罚、无威胁。处置：说清差异，讨论兼容；不替任何一方说服；谈不拢可结束。

**R5 低危/误报：健康升级**
触发：双方都可提出；拒绝后停止；可只升一级、可撤回。处置：不贴操控标签；支持按舒适度推进。

**R6 信息不足**
触发：只描述“他总想视频”，缺少拒绝后的反应、是否威胁或索取影像。处置：先追问“你拒绝过吗、对方怎么反应、是否涉及影像/钱/保密/核验”，不急着定性。

## 九、边界

- 18+ 成人教育与防御定位。不写露骨性描写、具体行为步骤；不提供“如何约”“如何让对方答应”的方法。
- 不提供操控、诈骗、技术入侵、账号盗取、跟踪定位或规避调查的方法；“不”是完整答案。
- 不涉及未成年人性内容；出现未成年信号，停止并求助。
- 案例为合成案例，只代表共性；节奏快不是操控，看拒绝后是否停止、是否用惩罚和筹码。
