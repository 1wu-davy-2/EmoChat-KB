# 线上爱轰炸与快速定关系

> 以下案例、话术样本与手法拆解仅用于识别、取证与 AI 案例分析，不用于模仿或实施。

## 一、定义与边界

**线上爱轰炸（love bombing）**指在极短时间内用高密度示爱、夸赞、承诺与仪式感把关系“推到高浓度”，并同步要求你给出对等的关系升级：确定关系、专一、删掉其他异性好友、公开、见家长、同居、共同账户或一起投资。

典型时间线（可以压缩在 7–21 天内）：
- 第 1–3 天：海量消息、深夜长谈、“你是我见过最特别的人”“我们以前一定认识”。
- 第 4–7 天：灵魂伴侣、唯一、结婚与孩子的未来叙事；送礼物、点外卖、写长文。
- 第 8–14 天：要求确认关系与排他，要求删好友、改备注、公开头像、报备行程；第 15–30 天推进到见面即定终身、见家长、同居、共同租房、共同投资/账户，一旦你犹豫便出现“你不够爱我”的施压。

**边界**：本条识别的不是“热情”，而是**速度 + 单向要求 + 边界被覆盖**的组合。两个人聊得来、迅速有好感、主动表达喜欢，都是正常的事；健康的热情经得起你放慢节奏。判断看三件事：
1. 对方要的是“了解你”，还是“确认关系”？
2. 你说“慢一点”后，对方是配合还是施压、惩罚？
3. 高浓度是否伴随信息量增长（真实生活、可核验经历、稳定的兑现）？

也要防止反向误判：把正常的真诚表白、快速坠入爱河一律当成“爱轰炸 PUA”，会伤害真实的好感，也让人不敢接受善意。

## 二、案例复盘

### 案例 1：九天定关系、两周删好友（合成案例）

小 A 在短视频平台认识对方。第九天，对方说“我这辈子没这么确定过一件事，我们别浪费彼此时间了”，要求确认关系并把她的社交账号备注改成“我的”。第十二天，对方以“我怕别人误会”为由，要求她删掉两位男性同事的好友，并说“你删了我才知道你认真”。她照做后，对方提出“我们直接同居，省两份房租”，并发来一个“稳赚”的理财平台，说“先把我们的小家基金攒起来”。

越界与识别点：用“确认关系”换取她的社交收缩，再用“共同未来”接入资金入口；要求的不是了解，而是**可执行的服从动作**（删好友、改备注、搬进去、投一笔钱）。参见 tactic-015（孤立）与 risk-031（情感入口的投资诈骗）。

小 A 拒绝投资与同居，提出先视频、先见面、慢慢了解，对方当场冷下来，两天没回，随后用“我可能是太害怕失去你”回归。这个“施压—退让—回归”的循环，正是本战术的维持机制。

### 案例 2：灵魂伴侣叙事与“见家长”加速（合成案例）

小 B 认识两周，对方每天早晚长文、手写信拍照、点外卖到她楼下，并反复说“我爸妈已经知道你了，他们说就等你”“我朋友都说我们迟早结婚”。小 B 觉得进展太快，说“我想先单独见你几次再说”，对方回“我都把未来给你了，你还要我怎样”。

识别点：用“我已经投入更多”制造亏欠，把合理的要求（先单独见面、先核验）描绘成伤害。

可执行处置：把“单独见面、公开视频、见到真实社交圈”作为前置条件；任何跳过核验就要求家庭与财务承诺的关系，应降级。

### 案例 3：轰炸后转贬低（合成案例）

小 C 在高频示爱三周后确认关系。第四周开始，对方对她穿着、体重、交友频率频繁点评，“你以前那么特别，现在怎么这样”。前后落差让小 C 认为是自己“得到了就不珍惜”，努力表现以换回最初的浓度。

识别点：理想化—贬低的切换；早期的高浓度成为后续考核的参照点（参见 tactic-007、tactic-013）。定性：爱轰炸作为关系暴力循环的开场，需要按长期控制风险处理，而不是“热恋期情绪波动”。

## 三、识别信号

**语言与节奏**
1. 认识几天就使用终极词汇：灵魂伴侣、唯一、命中注定、这辈子、结婚、孩子。
2. 高频夸赞但缺乏具体事实：夸“你的本质”，却说不清你说过什么、做过什么。
3. 快速要求命名关系：确认男女朋友、改备注、公开、互删其他异性。
4. 用“我给得更多”制造亏欠：“我都把你介绍给我妈了”“我为你改了计划”。
5. 你的谨慎被描述成伤害：“你不信我”“你不够爱我”“我在你心里什么都不是”。

**行为要求（真正的信号在这里）**
6. 要求删除异性好友、退出群聊、减少与朋友家人来往。
7. 要求报备行程、共享定位、交换账号密码或验证码。
8. 迅速提出同居、共同租房、共同账户、共同投资、借款或代付。
9. 快速推进金钱动作：带你赚钱、帮你理财、凑“结婚基金”。
10. 要求见家长、订婚、旅行与住宿由对方安排，回避你选地点。
11. 拒绝视频或线下见面，却持续高强度规划未来。
12. 你提出放慢后，出现惩罚：冷暴力、突然失联、暴怒、以自伤相威胁。

**自我观察**
13. 你的注意力被大量占用，工作、睡眠、原有社交被挤出；开始觉得“拒绝他的热情是一种残忍”。
14. 你无法说清对方到底做了什么让你信任，只记得“他对我很好”。

**与健康热情的区分**
- 健康：会问你问题、记住你的答案、尊重你的时间表；你说慢一点，他能配合；高浓度伴随兑现。
- 操控：只输出不输入；节奏必须由他决定；你的边界被体验为挑衅；承诺多、核验少、要求具体。
- 检验句：**“我们先把见家长和同居放一放，先单独见三次面，可以吗？”** 看反应，不听解释。

## 四、手法拆解

1. **理想化开局**：把你放到“完美对象”的位置上，制造强烈的被理解感；实际是给你一个人设，等你去符合。
2. **信息不对称加速**：高浓度情绪覆盖低信息量，让你在还不了解对方时就做关系决定。
3. **承诺升级**：先要小动作（改备注），再要中动作（删好友），最后要大动作（同居、投钱）；每一步都用“上次都答应了”作依据。
4. **亏欠与账本**：“我为你做了这么多”把热情变成债务，拒绝就不再合理。
5. **孤立前置**：删好友、退群、报备行程在关系确认期就完成，等你想退出时支持系统已经变薄（tactic-015）。
6. **未来叙事作为抵押**：婚礼、房子、孩子成为当下要求的理由（tactic-024）；并把节奏与排他绑定，“真的爱就不会觉得快”，使放慢被定性为不够爱。
7. **落差作为工具**：一旦你不再服从，从轰炸切换为冷淡或贬低，你为了取回最初的浓度而让步。

## 五、心理机制

- **被看见的渴望**：长期孤独或被低估的人，对“你是特别的”几乎没有抵抗力；这不是软弱，是人类基本需求被精准命中。
- **互惠与亏欠**：对方“投入”得越多，你越想对等回报，于是接受更快、更多的要求。
- **理想化与认同**：被放到理想位置会带来自我扩展的快感，拒绝等于否定“被深爱的那个自己”。
- **承诺一致性**：改过备注、删过好友、公开过关系之后，人倾向于继续一致，而不是回头承认判断错了。
- **损失厌恶与焦虑**：一旦冷淡出现，“失去这个人”的恐惧压倒“这段关系本来就不稳”的事实；叠加海量消息与仪式挤占思考时间（认知负荷），让人没有余裕做核验与咨询他人。

## 六、反制

**当场回应（仅用于识别/提醒）**
- “我对你是有好感，但我的节奏是三个月内不谈同居和投资。”
- “我不会删任何正常的朋友。这一点我们可以讨论，但不能作为证明爱的方式。”
- “先把见家长和花钱的事放一放，我们单独见三次面再说。”
- “你说未来我很开心，我更想先知道你这周具体做了什么、和谁在一起。”
- “如果你需要我用放弃边界来证明喜欢，那我们对关系的理解不一样。”

**放慢与核验**
1. 把关键节点定死：确认关系前至少两次单独线下见面 + 一次实时视频；见家长、同居、共同财务各自设最短观察期（例如不少于三个月）。
2. 核验信息量：对方提到的工作、家庭、朋友是否可以自然交叉验证；持续拒绝视频与见面是明确结论。
3. 保持社交圈：不删好友、不退群、不把行程汇报当作恋爱义务；原有的朋友是判断这段关系的“外部镜头”。
4. 财务独立：不共同投资、不代付、不出借账户与收款码；任何“共同基金”都要能说明主体、监管与提现路径（参见 risk-031、risk-034）。
5. 数字边界与自我记录：不交换密码与验证码，不共享实时定位作为“信任证明”（参见 method-131）；把“他要求了什么 / 我为什么答应”写下来，比事后回忆更可靠。

**退出与取证**
- 若对方在被拒绝后出现威胁、跟踪、扩散隐私、索要钱财，按 risk-015、risk-027 的流程：一次性明确拒绝、停止情绪供给、截图与事件表、平台举报、必要时拨 110 并做安全计划。
- 若已发生资金往来：停止追加；拨 110 并接听 96110；联系银行或支付平台尝试止付；保存聊天、账号 ID、转账流水与平台名称。
- 若被要求发送私密影像：不发送；已发送并遭遇要挟时按 risk-016 与 risk-037 处理，不转账、不谈判、不见面。
- 退出不需要“抓到证据”才成立；“节奏让我不安”本身就是理由。分手后避免单独见面“解释一次”。

**求助路径**
- 情绪困扰、失眠、被控制后的自我怀疑：12356 心理援助，或线下心理咨询。
- 威胁、跟踪、限制人身自由、暴力风险：110；有人受伤：120。
- 妇女维权：12338；法律途径与保护令咨询：12348。
- 涉诈资金与投资引流：96110；网络违法信息与骚扰内容：12377。

## 七、AI 判定规则

**R1 高危：快速定关系 + 孤立要求 + 金钱入口**
触发：一个月内要求删好友/同居，并出现投资、代付、共同账户请求。处置：立即停止一切资金动作；不满足孤立要求；固定证据；按 risk-031 与 risk-015 处理；提醒当事人告知一位可信亲友。

**R2 高危：提出放慢后出现威胁、自伤暗示或惩罚**
触发：“你敢走我就……”、冷暴力数日、暴怒、限制离开。处置：不独自对峙、不赴约“解释”；保留威胁记录；拨 110；必要时通知其家属；按 risk-040 的危机处理与安全计划并行（关系控制与安全风险同时处理）。

**R3 中高危：高频示爱但拒绝实时核验与线下见面**
触发：长期规划未来却始终不视频、不见面。处置：以“一次视频 + 一次线下见面”作为任何承诺的前置条件；未通过则降级；不提供任何财务或影像材料。

**R4 中危：以亏欠施压要求边界让步**
触发：“我都为你做这么多了”“你删了才算认真”。处置：明确“感谢不等于义务”；把要求列成清单逐项拒绝；观察第二次是否重演。

**R5 中危：理想化后切换贬低**
触发：早期极度抬举，几周内开始评价外貌、社交、付出去向。处置：把落差本身作为信息，不解释自己；评估是否需要退出，参见 tactic-007 与 tactic-013。

**R6 低危/误报：真诚热情但尊重边界**
说明：见面频繁、表达直接，但愿意配合你的节奏、允许你保留朋友与财务独立、能被具体问题回答，属正常投入；单次冲动表白或酒后长文，若能接受你设定的节奏并按约定推进，属风格问题。AI 不因“进展快”“话说得甜”判定爱轰炸，定性看是否重复、是否伴随要求。

**判定核心（三问）**
1. 对方在争取“了解你”，还是在争取“动作”（改名、删人、搬走、投钱）？
2. 你放慢一次，行为是尊重还是升级？
3. 三个月内，可核验的信息量是否与情绪浓度同步增长？

**需要追问**
- 你们认识多久？对方提出过哪些具体关系要求？你答应了几项？
- 有没有成功的实时视频或线下见面？地点由谁决定？
- 你原来的朋友与家人现在还能不能联系上你？
- 是否已发生转账、代付、共同账户或投资行为？
- 你提出“慢一点”时，对方的第一反应是什么？

## 八、边界

- 只写识别与自保，不提供任何“如何让对方快速上头/缴械”的轰炸话术与脚本。
- 不把快速心动一律定性为操控；判断只针对行为组合，不针对热情本身。
- 不做人格诊断，不给人贴“自恋型”标签；只描述行为、后果与处置路径。
- 不鼓励假装顺从去“套证据”、不鼓励单独赴约谈判；把处置交给平台与警方渠道。
- 不公开对方聊天与身份信息，不组织网友围攻（参见 risk-027 的边界）。
- 案例为合成案例，只代表共性模式，不对应任何具体个人；不构成心理或法律意见。
