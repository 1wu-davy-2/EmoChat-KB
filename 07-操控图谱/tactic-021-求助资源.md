# 求助资源清单(中国大陆)

| 渠道 | 联系方式 | 适用 |
|---|---|---|
| 全国统一心理援助热线 | **12356**(24 小时) | 情绪危机、心理困扰 |
| 希望24热线 | **400-161-9995**(24 小时;学生专线拨通后按 1) | 自杀危机、重度情绪困扰 |
| 全国妇联妇女维权热线 | **12338** | 遭受情感/家庭暴力、权益受侵害 |
| 共青团青少年服务热线 | **12355** | 青少年情感与心理求助 |
| 报警 | **110** | 人身威胁、敲诈(裸照威胁)、跟踪、暴力 |
| 精神科/心理科门诊 | 当地三甲医院 | 抑郁、焦虑、创伤后应激(专业干预越早越好) |
| 心理咨询 | 正规平台/机构(甄别"情感导师"资质——多数 PUA 相关投诉源于无资质机构) | 关系创伤修复、认知重构 |
| 公益与法律 | 妇联、12348 法律援助热线 | 涉虐待、诈骗、隐私侵犯;保留聊天记录、转账凭证、就诊记录作为证据 |

## 两个特定处境的处理
- **对方以自杀威胁阻止我离开**:立即联系对方家人与可求助机构,告知其风险,然后离开。你不是专业的危机干预者,也不要独自承担任何人的生死决定。
- **我自己出现自伤念头**:请立刻拨打 400-161-9995 或 12356,或前往最近医院急诊。你的生命优先于任何关系。

> 男性受害者提醒:男性报告率与求助率更低,但渠道同样开放;放下"面子"求助是止损的第一步。
