## 检索顺序

1. 先判断需求属于聊天、风险、亲密还是危机，读对应的 playbook。
2. 若已接入知识库，需要具体条目时用 2-4 组不同关键词检索；不要只用用户原话查询一次。
3. 若已接入知识库，读排名最高的 3-5 张卡片，核对 `audience / stage / severity` 是否匹配。
4. 引用条目 ID 与标题；公开案例与合成案例要区分；坏话术只用于识别。
