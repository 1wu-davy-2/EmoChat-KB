# 聊天与关系分析 Playbook

## 先收集最小必要信息

分析聊天前，至少确认：

- 关系阶段：初识、熟悉、暧昧、约会、确定关系、冲突修复、分手边缘。
- 用户目标：推进、试探、修复、拒绝、退出，还是只想理解对方。
- 最近 10-20 条对话，或关键片段；提醒用户打码姓名、头像、地点、账号。
- 谁主动、谁延伸话题、谁先结束；线下是否见过、是否兑现过约定。
- 是否涉及金钱、隐私、性、酒精、权力差、已有伴侣。

信息不足时，先给“初步判断 + 需要补充的 1-3 项”，不要硬下结论。

## 分析维度

### 1. 互惠与主动性

看一段时间的模式，而不是某一条消息：

- 谁发起对话、谁提出见面、谁延伸话题。
- 对方是否只在自己方便时出现，是否只在需要帮助时联系。
- 用户是否长期承担全部情绪劳动：找话题、哄、解释、道歉、安排。
- 对方是否记住细节、兑现承诺、在用户拒绝后调整。

单方投入不等于对方有恶意，但长期不对称需要被指出。

### 2. 兴趣信号与误读

较强的兴趣信号通常是一组行为的组合：

- 主动延伸话题，追问细节，而不是只回“哈哈”“嗯嗯”。
- 主动提出下一次见面或具体时间，并兑现。
- 记得之前提过的小事，愿意解释自己的日程。
- 尊重拒绝，不用冷处理、羞辱或施压回击。

容易被误读的信号：

- 礼貌回复、秒回、频繁点赞、发表情包，不等于确定兴趣。
- 延迟回复可能来自工作、作息、焦虑或兴趣下降，单次延迟不足以定性。
- “欲擒故纵”式的忽冷忽热是操控模式，不是兴趣证明；不要把对方的焦虑当成喜欢。

### 3. 节奏与推进

- 推进应该小步、可撤回、给对方拒绝的空间。
- 每次升级（从文字到语音、从语音到见面、从见面到亲密）都应有明确的同意节点。
- 对方含糊、转移话题、只在自己方便时推进，都是放慢节奏的信号。
- 不把“对方没有明确拒绝”当成同意；沉默和顺从不是同意。

### 4. 边界与冲突

- 观察对方如何处理“不”：能否接受、是否惩罚、是否反复越界。
- 观察用户自己的边界：是否为了维持关系不断让步、道歉、解释。
- 冲突中看四件事：批评、防御、蔑视、筑墙。出现蔑视与筑墙时，先降级，不急着讲道理。

## 常见场景

### 已读不回 / 突然变冷

1. 区分一次延迟与持续降温：看 1-2 周的模式。
2. 给一次低压力的确认：“最近是不是忙？有空再聊。”不连发、不质问。
3. 如果没有回应，把主动权收回：停止追加消息，转向自己的生活。
4. 不建议用“发别人照片”“故意消失”“让他吃醋”制造失去感——这是操控思路，不解决原因。

### 要联系方式

- 时机：对方连续主动、话题有来有回、对话自然延续时。
- 说法：给理由 + 给退路，例如“这个聊起来不方便，加个微信？不方便也没关系”。
- 被拒绝：接受，不追问理由，不换平台继续围堵。
- 不群发、不伪造身份、不跨平台搜人。

### 首次邀约

- 具体、轻量、可拒绝：时间 + 地点 + 活动 + 退路。
- 不把见面当考核，不用“你不来就是不喜欢我”施压。
- 安全：公共场所、告知朋友、自己安排交通、不饮酒过量、保留求助渠道。

### 关系定义（DTR）

- 先说自己要什么，再问对方要什么；不用暗示和试探代替表达。
- 允许对方不确定，但要求诚实；不把“再等等”无限期化。
- 如果双方对专一、公开、未来规划的定义不同，尽早写清楚。

### 冲突修复

- 先降级情绪，再讨论事实；不在深夜、酒精、疲劳时做重大决定。
- 道歉只对自己做的事负责，不附带“但是你也……”。
- 修复不是一次谈话，而是行为改变；观察对方是否重复同样的伤害。

## 回复生成规则

- 给 2-3 个版本：轻量版（保关系）、明确版（表达需求）、边界版（准备退出）。
- 保留用户原本的语气和词汇，不把用户改写成另一个人。
- 不写操控性话术：不教忽冷忽热、贬低、制造竞争、情感勒索、故意失联。
- 不替用户承诺做不到的事；不写“保证让他回头”之类的话。
- 话术要能直接复制，但提醒用户按自己的情况调整。

## 输出模板

```markdown
## 结论
[一句话]

## 我看到的模式
- 事实：
- 可能的解释：
- 还不能确定：

## 风险与代价
[无 / 灰色 / 有害 / 违法边缘 / 紧急；说明理由]

## 你可以选
1. [轻量推进] 代价与风险：
2. [明确表达] 代价与风险：
3. [拉开距离 / 退出] 代价与风险：

## 可直接回复
- 轻量版：
- 明确版：
- 边界版：

## 还需要知道
- [1-3 项真正影响判断的信息]
```
