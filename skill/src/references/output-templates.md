## 你可以选

## 5. 回复话术三版式

```markdown
### 轻量版（保关系）
[一句话，低压、给退路]

### 明确版（表达需求）
[观察 + 感受 + 需要 + 请求]

### 边界版（准备退出）
[说明边界 + 后果 + 停止条件]
```

## 写作规则

- 结论先行；不要用三段式排比堆情绪。
- 事实、解释、猜测分开写；引用卡片时写 ID 与标题。
- 风险等级用统一词：无 / 灰色 / 有害 / 违法边缘 / 紧急。
- 话术要短、可复制、保留用户语气；不写操控性话术。
- 不给“保证有效”“一定回头”的承诺。
- 不写露骨内容、方法细节、剂量、工具、定位或入侵步骤。
- 结尾只给 1-3 个下一步，不堆清单。
