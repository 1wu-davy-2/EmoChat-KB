# 公开框架版说明

本技能包是 EmoChat 的分析框架版，供个人安装、学习与原样分享。

## 包含

- `SKILL.md`：触发条件、工作流、输出格式与硬边界
- `references/playbook-*.md`：聊天、风险、亲密、危机四类分析流程
- `references/output-templates.md`、`safety-boundaries.md`、`kb-integration.md`
- `scripts/emochat_search.py`：可选检索脚本（仅在用户自备同结构知识库时使用）
- `adapters/`：Claude Code、Qoder、Codex、AGENTS.md 与单文件提示包

## 不包含

- EmoChat-KB 的 589 条知识库正文、案例、话术、卡片标题或卡片索引
- 任何真实个人数据、私密影像或未公开案例

## 允许

- 个人安装、使用、原样分享本包。
- 在保留本说明与作者署名的情况下，将本包用于个人学习与风险识别。

## 禁止

- 将本包内容用于商业服务、付费课程、咨询、会员服务或广告。
- 将本包用于训练、微调、评估、数据集构建，或纳入面向第三方的 RAG/向量数据库服务。
- 修改后以作者名义发布，或移除本说明与署名。
- 将 EmoChat-KB 的知识库正文加入本包再分发。

## 免责声明

本包只提供一般性的沟通与风险识别框架，不构成医疗、心理、法律或性健康建议。紧急情况请联系当地急救、警方或专业机构。
