# 场景：异地与线上 FWB 的协议与风险

> 面向成年人。距离与屏幕不会降低关系的要求，只会让模糊更贵。本文谈协议、首次见面安全与退出，不提供“如何约”“如何让对方飞过来”的方法。

## 一、定义：不算数的关系，最容易被含糊对待

异地或线上 FWB，指见面频率很低、或主要靠线上维持的休闲关系。它可以是文字、语音、图片、视频，也可以一年见两三次。它不因为见面少就“不算数”：时间、情绪、钱、隐私与健康风险都是真的。

线上还有一个特点：**可保存**。一句话、一张图、一段语音，发出去就不再只属于当下。

## 二、与一般 FWB、异地恋的区别

- **scene-044（一般 FWB）**：同城或邻近，见面相对容易，协议重点是排他、防护、频率、结束。
- **scene-012（异地恋）**：有恋爱承诺与未来规划（何时结束异地、见家长），难点是维持与不确定。
- **本篇**：休闲关系 + 距离/线上。承诺更少、默认值更少，所以要谈得**更具体**：时区、路费、谁飞、住哪、影像存不存、多久见一次。

## 三、前置条件

双方成年；各自单身或伴侣状态透明；排他与多伴侣告知说清；检测安排；线上内容的类型与保存边界；旅行费用怎么承担；首次见面的安全安排；退出与删除方式。任何一项对方不愿谈，本身就是信息。

## 四、协议清单

| 项目 | 要谈的具体内容 | 常见漏洞 |
|---|---|---|
| 联系频率与时区 | 每天还是每周、几点后不打扰、忙时怎么说明 | 用“随时在线”证明在意，最后变成互相消耗 |
| 线上亲密类型 | 文字、语音、图片、视频分别可以到哪一步 | 把“可以聊”当成“可以发” |
| 保存与录制 | 看完即删、能否截图、能否留存、能否回看 | “只我自己看”无法验证 |
| 排他 | 只和彼此，还是各自保留其他人 | 没谈过就当排他，或反过来 |
| 其他伴侣告知 | 有新增伴侣是否提前说、说到什么程度 | 用“异地不算”跳过告知 |
| 见面前检测 | 多久检一次、结果怎么互换、谁预约 | 用“我很干净”替代报告 |
| 交通与住宿 | 谁飞、机票谁出、住哪、取消怎么算 | 一方长期承担，或“来了就住我家” |
| 首次见面安排 | 公共场所、时长、返程、紧急联系人 | 要求过夜、要求关机、要求别告诉人 |
| 结束与删除 | 谁提、停联多久、影像与聊天怎么处理 | 只删本地，云端与转发副本还在 |

## 五、阶段路线图

| 阶段 | 任务 | 节点 |
|---|---|---|
| 线上建立 | 核对身份、年龄、伴侣状态、见面可行性 | 能视频、能说清何时见面 |
| 线上亲密 | 分别确认类型、保存、录制、撤回 | 任一方可随时降级 |
| 首次见面 | 检测、公共场所、自己往返、告知朋友 | 不临时改变住宿与行程 |
| 维持 | 固定频率、费用规则、定期复核 | 每两三个月看一次 |
| 结束 | 明确说、停联、删除与告知 | 不留“下次一定”的尾巴 |

## 六、首次见面：安全优先于浪漫

- 见面前各自检测，结果互换；不互换就不进入亲密。
- 第一次在公共场所，白天或傍晚，控制在几小时。
- 自己订票、自己往返，保留返程票；不坐对方指定的车。
- 告诉一位朋友：见谁、在哪、几点回、对方联系方式。
- 不要求过夜，也不接受“来了就必须住我家”。
- 不饮酒过量；饮料不离手；感觉不对就结束，不用解释。
- 临时改变地点、要求关机、要求别告诉任何人：任一条出现，直接离开。

## 七、风险

理想化；永远只线上、不见面；用“等我忙完这阵”拖延未来；隐藏伴侣；浪漫诈骗；影像勒索；以“见面”为名的旅行胁迫；借钱买票；用“你来证明爱我”测试服从。距离让这些更难核实，也让退出更贵。

## 八、操控方常见路径（仅用于识别，不是操作指南）

- 永远不视频，却要求对方先飞过来，理由是“我不上镜”“镜头坏了”。
- “先发张照片证明信任”，拿到影像后开始加码。
- “机票钱先借我，见面就还”，之后不断出现新的费用。
- “别告诉朋友，他们会误解我们”，把隔离说成保护。
- “见面必须住我家，不然就是不信任”。
- “下次一定去见你”，用无限延期的未来换当下的投入。

识别看三点：能否核实身份与行程；钱是否单向流动；见面条件是否只对一方不利。

## 九、合成案例

> 合成案例（基于公开报道共性，非单一真实个案）。只代表常见模式，不对应具体个人。

**案例 1：三个月的“镜头坏了”**

小 Y（29）与对方相处三个月，对方从不视频，理由是“镜头坏了”，却要她飞过去、住他家。小 Y 说：“我可以去，但我要先视频，住酒店，自己订票。”对方生气：“你不信任我。”

小 Y 没争辩，把行程改成“先视频、再决定”。对方继续推脱，两天后说“算了，你别来了”。她停止联系，保留记录，没有转账、没有出行。

要点：视频与住宿安排是安全条件，不是信任测试；对方因安全条件而撤回邀请，说明邀请本身有问题。

**案例 2：“机票钱先借我”**

小 D（31）约好见面，临行前对方说钱包被偷，借 3000 元买票，承诺见面还。小 D 转了第一笔，对方又要“改签费”，又要私密照片“证明不是玩他”。

小 D 停在这里：不再转账、不发照片，保存聊天与转账记录，向平台举报，拨 96110 与 110。钱没追回，但损失没有扩大。

要点：单向要钱 + 索要影像是典型组合；付款不会换来见面；“再付一次就出发”不是承诺。

## 十、AI 判定规则（R1–R6）

**R1 高危：影像、胁迫与未成年人。** 以影像威胁；以见面为名限制自由；要求汇款或代付；涉及未成年人；跟踪、暴力。停止联系，不转账、不出行；留证；拨 110，涉诈同步 96110；影像转 risk-016、risk-037。

**R2 高危：结构性隐瞒与单向索取。** 有伴侣不告知；反复借钱买票；要求住对方家且不许告诉任何人；拒绝任何核实却要求先投入。明确拒绝，不给周旋方案，建议退出（risk-043、risk-014）。

**R3 中危：只线上不见面与无限延期。** 长期不视频、不见面；用“等我忙完”拖未来；排他与告知含糊。给一次明确的时间表与复核点；到期无行动按信息处理。

**R4 中危：线上边界不一致。** 一方保存或录制而另一方不知情；对“线上算不算越界”理解不同；公开程度不一致。把线上纳入协议，分别说清可以／不可以／需要先问（intimacy-036）。

**R5 低危。** 成年、身份可核实、伴侣状态透明、有见面计划、费用与退出有约定。给检测与复核提醒。

**R6 信息不足。** 追问年龄、身份能否核实、伴侣状态、是否视频过、谁承担费用、见面住哪、是否有人索要影像或借钱。缺项按中危处理。

## 十一、边界

仅面向成年人。不写露骨内容与具体步骤，不提供“如何让对方答应见面”“如何说服对方视频”“如何隐瞒伴侣”的方法。不提供跟踪定位、技术入侵或规避调查的方案。涉及未成年人、胁迫、诈骗：停止并求助。不病理化异地线上关系，也不美化欺骗与隐私侵犯。案例为合成案例。
