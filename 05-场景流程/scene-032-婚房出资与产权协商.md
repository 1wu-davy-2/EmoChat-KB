# 场景:婚房出资与产权协商

## 适用情境

准备结婚,双方或双方父母要出钱买房;或者已经买了,正在讨论加名、份额、还贷与装修。婚房是大多数家庭最大的一笔支出,也是最容易把感情谈成账本的地方。

先立三条原则:

1. **出资、登记、居住是三件事**,不要混成一句"房子写谁名"。
2. **口头说清楚不算清楚**,大额出资要留书面与转账记录。
3. **本文只讲沟通框架与常见误区,不构成法律意见**。产权认定、分割比例、父母出资性质,各地裁判口径不同且规则有更新,务必咨询律师或 12348。

## 一、先分开三件事

- **出资**:谁出了多少,什么时间出的,钱从哪个账户转到哪里。
- **登记**:产权登记在谁名下,是单独所有、共同共有还是按份共有。
- **居住**:谁住、父母是否同住、装修谁定、物业水电谁付。

很多争执是因为一方在谈出资,另一方在谈安全感,第三个人在谈"这是我家的钱"。先把三件事分桌谈,才谈得下去。

## 二、出资结构表

买房前把这张表填完,双方各留一份:

| 项目 | 金额 | 出资人 | 出资时间 | 凭证 |
|---|---|---|---|---|
| 首付款 | | | | 银行流水、收据 |
| 定金 | | | | 转账记录、认购书 |
| 税费与中介费 | | | | 发票 |
| 装修 | | | | 合同、发票、转账 |
| 家电家具 | | | | 订单、转账 |
| 月供 | | | | 还款记录 |
| 父母出资 | | | | 借条或赠与说明 |

填表时会发现一些平时没注意的事:谁的钱先到、谁的钱是借的、装修款有没有凭证、月供从谁的卡扣。这些细节在关系好时是小事,在关系破裂时是全部。

## 三、加名与份额

### 常见安排

- **一方婚前全款,登记在出资方名下**:通常认定为婚前个人财产。加名属于赠与行为,加了之后产权性质会变化。
- **一方首付,婚后共同还贷,登记在首付方名下**:离婚时房屋一般归登记方,共同还贷部分及对应增值由登记方补偿另一方。补偿计算涉及还贷金额、婚龄、房价变动,由法院综合认定。
- **双方共同出资,登记双方名下**:可以约定共同共有,也可以约定按份共有并写明比例。登记为共同共有,不等于分割时一定五五。
- **父母出资**:性质是赠与还是借款、赠与给一方还是双方,对结果影响很大。有没有书面说明、转账备注、借条,是关键。

### 加名的现实约束

- 贷款未还清时加名,通常需要银行同意并办理抵押变更,不是去登记中心就能办。
- 加名可能涉及税费,各地政策不同,先问当地不动产登记中心。
- 加名是重大财产处分,不在争吵、威胁、婚礼前夜的压力下做决定。

### 份额约定

如果选择按份共有,写清比例与依据(出资比例、还贷比例、装修折价),并保留对应的转账凭证。只写比例不留证据,日后仍可能争议。

## 四、婚前财产与出资证明

### 该留的凭证

- 银行流水与转账记录,备注写"购房首付""装修款""还贷"。
- 购房合同、认购书、发票、契税完税凭证。
- 装修合同、报价单、付款记录、材料清单。
- 父母出资的借条、赠与说明、聊天记录。
- 月供扣款账户记录,明确是谁的账户在还。
- 双方关于出资与产权的书面约定或聊天记录。

### 婚前协议与财产公证

婚前协议可以约定婚前财产归属、婚后收入分配、债务承担。它不是"不信任",是把最坏情况提前说清。协议需要双方自愿、内容合法,建议由律师起草或审核,必要时办理公证。不要从网上下载模板直接签,条款可能不适用本地规则。

## 五、父母出资的性质

这是争议高发区,先问四个问题:

1. 这笔钱是**赠与**还是**借款**?
2. 如果是赠与,是赠给**自己子女**还是**双方**?
3. 有没有**书面说明**、转账备注、借条?
4. 出资是否附带条件(同住、养老、孩子姓氏、装修风格)?

处理建议:

- 出资前由出资方父母、子女、伴侣三方坐下来谈,把性质说清,写一页纸。
- 借款就写借条,写明金额、用途、还款安排;赠与就写赠与说明,写明给谁。
- 不接受"先不写,以后再说"。以后往往就是吵架的时候。
- 父母出资不自动等于父母拥有居住权或决策权;如果附带同住安排,单独写清期限与边界,参考 scene-020。

司法实践对父母出资的认定在不同情形下有所不同,规则也有更新。以上只是沟通建议,具体定性请咨询律师。

## 六、分手或离婚时的处理原则

- **先协商,再调解,最后诉讼**。协商时以出资表与凭证为基础,不凭记忆报价。
- **不擅自换锁、赶人、断供、变卖家电**。断供会影响双方征信,换锁可能引发治安问题。
- **不隐匿财产**。转移、隐匿共同财产在诉讼中可能承担不利后果。
- **补偿计算有公式也有裁量**。共同还贷及增值补偿、装修折价、父母出资返还,都需要证据与法律判断,不自行定价。
- **调解渠道**:人民调解委员会、妇联(12338)、法院诉前调解。法律咨询拨 12348。
- **涉及暴力或威胁**,先保证安全,拨 110,再谈财产。

## 七、谈判话术

### 温和档

- 「我们先把各自能出多少、父母能帮多少列出来,再看总价够不够。」
- 「房子写谁名我不急着定,我想先知道首付和月供怎么分。」
- 「装修的钱我来出,能不能在份额里体现一下?我们写清楚,免得以后说不清。」
- 「我爸妈的钱是借的,我爸妈希望写个借条,这不是针对你。」

### 直接档

- 「首付你家出大头,我家出装修,我希望能按出资约定份额。」
- 「加名可以,但贷款没还清,银行那边要先同意,我们去问清楚流程。」
- 「如果这套房只写你名,婚后我还贷的部分需要有书面约定。」
- 「我不接受'先结婚再说'。钱的事婚前不谈清,婚后一定吵。」

### 止损档

- 「这个问题我们谈了三轮都没有共识,先暂停买房,不签任何认购书。」
- 「如果一定要我家出钱又不能留任何凭证,这套房我们不买。」
- 「我可以接受少占份额,但不能接受出了钱却没有任何记录。」

## 八、常见误区

- **"写我名就是我的"**:登记是重要依据,但不是唯一依据,出资与约定同样关键。
- **"共同共有就是一人一半"**:分割时会考虑出资、婚龄、子女、过错等因素。
- **"加名就是走个流程"**:涉及贷款、税费、赠与,需要提前问清。
- **"父母的钱不用还"**:没有约定时,借款与赠与可能各说各话。
- **"装修不算出资"**:装修、家电也是投入,但折价与举证难度更高,更要留凭证。
- **"先领证再买房,反正一样"**:领证时间、付款时间、登记时间的先后,会影响认定。
- **"签了协议就是伤感情"**:不谈清才更容易在分手时撕破脸。
- **"分手就断供,反正我不住了"**:征信受损的是还款人,可能影响双方。

## 九、书面记录的要素

不提供法律文书模板,但一页纸的记录至少应包含:

- 双方身份信息与日期。
- 每笔出资的金额、时间、付款账户、收款账户。
- 资金性质:赠与、借款、共同出资。
- 产权登记安排与份额约定。
- 还贷责任与月供分担。
- 装修与家电的出资与折价方式。
- 分歧解决方式(协商、调解、诉讼)。
- 双方签字。

涉及重大金额,建议由律师起草或审核。聊天记录、转账备注可以作为辅助证据,但不能替代正式约定。

## 十、边界提示

- 婚房谈判的目标是"双方都能承受且说得清",不是"谁赢"。
- 不以加名作为爱不爱的测试,也不以拒绝加名证明独立。
- 不逼迫对方在婚礼前夜、怀孕期间、情绪崩溃时做财产决定。
- 不把对方父母的钱当成理所当然,也不接受"出钱就要控制"。
- 本文不构成法律意见,具体案件请咨询律师或 12348。
