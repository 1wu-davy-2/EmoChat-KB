# 分手挽回与体面退出

## 先做可能性评估
**高可能(值得尝试)**:
- 分手原因是环境/时机(异地、忙、压力)而非性格不合;
- 她分手后还有主动联系行为;
- 关系超过 3 个月,有真实情感积累。

**低可能(通常不建议)**:
- 她明确说"不合适""不喜欢你了""喜欢别人了";
- 因出轨或严重信任破裂分手;
- 她已快速开始新关系;
- 分手是因为你的行为让她感到不安全/被伤害。

**低可能时**:最好的挽回是"体面离开"——展示接受、不纠缠、继续生活。这是唯一可能让她日后重新评估的路。

## 挽回时间线
**第 1-14 天 绝对冷静期**:不联系、不出现、不通过共同朋友传话、不发情绪消息;唯一要做的是让自己变好(运动、社交、有意义的事)。

**第 15-30 天 试探性联系**:一条轻松无压力的消息(不提分手、不谈感情);她回了就保持轻松,不表明来意;没回就再等 2 周。

**时机成熟后:不是告白,而是见面**——"我刚好在附近,要不要一起吃个饭?"(不是"我们谈谈");见面目标是让她重新感受吸引力,不是解释、道歉、争论分手原因。

## 挽回中最常见的错误
| 错误行为 | 为什么错 |
|----------|---------|
| 反复表白感情 | 确认你处于弱势,坐实"分手是对的" |
| 送礼/请客 | 讨好强化"你在乎她多于她在乎你"的认知 |
| 问"你还有没有感情" | 逼她说出"没有",等于强迫她复述分手理由 |
| 通过朋友打探 | 暴露你在持续关注,消除悬念 |
| 发情绪化长文 | 高需求感的最强信号 |

## 对话样本
**她:我觉得我们不合适,我们分手吧。**
→ "好。"
为什么:任何挽留都是弱势信号;平静接受制造真实的"失去感",是极少数可能让她重新评估的路径(仅适用于你并无大错、评估为高可能的情况;若分手因你的伤害行为,先真诚道歉一次、然后给她空间)。

## 亲密边界(关系恢复后同样适用)
关系重建不代表自动同意进一步亲密。对方说不、犹豫、沉默或退缩时,先停止相关动作;不因"她没推开"就认为可以继续;以后是否继续,以**双方新的、明确且自愿的表达**为准。

## 何时放弃挽回
评估为低可能、或冷静期+两次试探均无回应 → 转入止损与自我修复(见 risk-009 沉没成本自救)。挽回的尽头是体面,不是执念。
