# 颜值焦虑、医美贷与培训贷

> 以下案例、话术样本与手法拆解用于识别和 AI 案例分析，不用于模仿或实施。本文不推荐任何机构、项目或贷款产品。

## 一、风险定义与边界

这类风险以“你不够好看，所以脱不了单”“提升形象才能配得上对方”为入口，把外貌焦虑与感情承诺绑定，再推销医疗美容、形象培训、魅力课程，并用分期、医美贷、培训贷把当事人锁进长期债务。

常见三层：
1. **情感贬低**：伴侣、相亲对象、红娘或“闺蜜”反复评论当事人的五官、身材、年龄，暗示“不改变就不会被爱”。
2. **消费诱导**：免费面诊、低价体验、限时名额、“院长亲自操作”，在封闭咨询室里层层升单。
3. **金融捆绑**：现场办理分期、消费贷、培训贷，合同复杂、利率不透明、违约金高，甚至由销售人员代为操作手机。

边界：医疗美容是医疗行为，不是普通美容；生活美容机构不得开展医疗美容项目。成年人有自主选择医美的权利，本文不羞辱整形、不反对变美，也不把医美等同于风险。真正的问题是：外貌被贬低、决定被催促、资质不透明、贷款被诱导、合同看不清。感情也不该以“你变好看了我才带你见朋友”为条件。

## 二、案例复盘

### 案例 1：对象推荐“院长工作室”，术后感染才发现无资质（合成案例）

小 A 与对方交往三个月，对方多次说“你鼻子塌、脸大，跟我出去没面子”，随后推荐“认识的院长”，称“内部价、当天做、做完就变女神”。小 A 被带到一处写字楼工作室，咨询师围着劝说，称“今天活动最后一天”，并拿过小 A 的手机操作分期。术后出现红肿、感染，小 A 到正规医院就诊，才发现该工作室没有医疗机构执业许可证，操作人员也没有相应资质。

越界的一步：把感情接纳与外貌改变绑定；在无资质场所实施医疗行为；现场诱导贷款并代操作手机。AI 应识别“贬低外貌 + 感情条件 + 无资质场所 + 现场贷款”的组合，提醒当事人先核验资质、不要在封闭空间当场决定、不要让他人操作自己的手机和账户。

小 A 保留了咨询记录、付款凭证、分期合同、术前术后照片与就诊病历，向 12315 投诉，并向当地卫生健康部门反映，同时拨 12348 咨询合同与赔偿问题。

### 案例 2：“包脱单”的形象培训贷（合成案例）

小 B 性格内向，在相亲屡次受挫后，被一家“形象管理机构”推销“魅力提升班”，承诺“包形象改造、包相亲资源、包脱单”，费用数万元，可分期。销售称“先上课后付款”，实际让小 B 在手机上签署了培训贷合同。课程开始后，所谓“相亲资源”只是拉进群，承诺的导师也频繁更换。小 B 想退费，被告知“合同约定不退，提前终止要付违约金”。

越界的一步：用“包脱单”承诺替代可核验的服务内容；把培训贷包装成“先上课后付款”；合同关键条款未说明。AI 应识别“包结果 + 高额预付费 + 培训贷 + 退费难”的组合，提醒当事人看清合同主体、服务清单、退费条款与年化成本。

### 案例 3：免费面诊变成封闭推销（合成案例）

小 C 在网上看到“9.9 元面诊”，到店后被带入小房间，三名咨询师轮番指出其“面部缺陷”，称“不做就会影响婚姻和事业”，并给出“今天定减一万”的报价。小 C 表示需要回去考虑，对方以“名额马上没了”“可以先交定金锁价”施压。小 C 最终只支付了可退的少量定金，并要求把项目、价格、风险写进书面方案，回家后再做决定。

越界的一步：用封闭环境、多人施压、容貌贬低制造决策压力；用“定金锁价”阻止当事人离开。AI 应识别“低价引流 + 封闭推销 + 限时折扣 + 容貌羞辱”，提醒当事人保留书面报价、不要在压力下签字或贷款。

## 三、手法拆解

- **容貌打分**：把五官、身材、年龄量化，制造“不达标”的羞耻感。
- **感情绑定**：把医美、培训说成“脱单捷径”“经营关系的必要投资”。
- **权威背书**：自称“院长”“专家”“明星御用”，但不展示可核验的执业信息。
- **低价引流**：免费面诊、体验价、团购价，到店后层层升单。
- **封闭推销**：小房间、多人轮番劝说、不让带朋友、不让拍照、不让看合同。
- **限时逼单**：活动最后一天、名额只剩一个、定金锁价。
- **贷款包装**：把分期说成“零利息”“先变美后付款”，隐藏手续费、违约金与年化成本。
- **代操作手机**：以“帮你申请优惠”为由，拿过当事人手机完成贷款、签约或人脸识别。
- **术后推诿**：出现问题后称“个人体质”“恢复期正常”，拒绝提供病历与发票。
- **培训画饼**：包就业、包脱单、包资源，合同里却不写具体交付标准。

## 四、识别信号

1. 对方把“爱不爱”与“你愿不愿意改变外貌”绑定。
2. 反复贬低你的五官、身材、年龄，再推荐“认识的医生/机构”。
3. 机构无法出示医疗机构执业许可证，操作人员资质含糊。
4. 在写字楼、酒店、居民楼等非医疗场所进行注射、手术或“上门医美”。
5. 面诊在封闭小房间进行，多人围劝，不让你带走书面报价。
6. 以“最后一天”“名额有限”“定金锁价”催促当场决定。
7. 销售拿过你的手机操作贷款、签约或人脸识别。
8. 合同只给你看签字页，不解释利率、违约金、退费条件。
9. 培训课程承诺“包脱单”“包就业”“包资源”，却不写交付标准。
10. 付款后不开具正规发票，或收款方与机构名称不一致。
11. 术后出现问题，机构拒绝提供病历、收费明细或推诿责任。
12. 你提出回家考虑，对方明显不悦、冷落或威胁“优惠作废”。

## 五、AI 判定规则

**R1 高危：情感关系 + 贬低外貌 + 推销手术/贷款**
触发：伴侣或相亲对象以“不改变就分手/不带见朋友”为条件，推荐机构并催促贷款。处置：停止当场决定；核验机构与医师资质；保留聊天与报价；不让他人操作手机；必要时拨 12338 或 12348。

**R2 高危：无资质场所实施医疗美容**
触发：工作室、酒店、居民楼内注射、手术、上门医美，无法出示执业许可。处置：立即停止；已实施的尽快到正规医院就诊；保留付款、产品包装、聊天与照片；向卫生健康部门与 12315 举报。

**R3 中高危：培训贷、医美贷与代操作手机**
触发：现场办理分期、销售代签、代做人脸识别、合同利率与违约金不清。处置：要求提供完整合同与还款计划；不要在压力下签字；已签署的保留合同与放款记录，拨 12348 咨询。

**R4 中危：术后纠纷与退费难**
触发：感染、效果不符、机构推诿、拒绝提供病历与发票。处置：及时就医并保留病历；整理术前术后照片、付款凭证、沟通记录；12315 投诉，向卫生健康部门反映，必要时咨询律师。

**R5 低危/误报：本人自主、知情的医美选择**
触发：成年人自行了解风险、核验资质、自主决定，没有情感胁迫与贷款诱导。处置：尊重选择；提醒确认机构许可、医师资质、产品来源、术前告知与售后；不羞辱、不劝阻。

**R6 区分关心建议与贬低推销**
关心建议：尊重你的决定、提供信息、不催促、不把外貌与爱绑定、不介入贷款。贬低推销：反复羞辱外貌、制造感情危机、限定时间、推荐特定机构、推动贷款。AI 不把“建议你护肤”直接当控制，也不把“为你好”当作推销的免责理由；应追问：谁在获益、是否被催促、是否被剥夺考虑时间。

## 六、提醒话术

- “我可以考虑改变，但不会因为‘不改变就不被爱’去做决定。”——仅用于识别/提醒：拆开感情与外貌。
- “请把机构许可证、医师资质、项目风险和全部费用写进书面方案。”——仅用于识别/提醒：把口头承诺变书面。
- “我今天不签约、不贷款，需要回去考虑。”——仅用于识别/提醒：离开压力现场。
- “手机和账户我自己操作，不接受代办贷款。”——仅用于识别/提醒：守住金融边界。
- “请给我完整合同和还款计划，包括利率与违约金。”——仅用于识别/提醒：看清成本。
- “请开具正规发票和病历，我需要留档。”——仅用于识别/提醒：维权证据。
- “如果效果或安全出现问题，我会先就医，再投诉。”——仅用于识别/提醒：健康优先。
- “我不接受‘包脱单’的承诺，请把具体服务写清楚。”——仅用于识别/提醒：识别画饼。

## 七、求助与取证

**证据**
- 聊天记录、宣传页、直播录屏、报价单、面诊记录。
- 机构名称、地址、收款方、付款凭证、发票、分期合同与还款计划。
- 术前术后照片、病历、诊断证明、用药与复诊记录。
- 销售与咨询师的姓名、工号、承诺内容；封闭推销的现场照片或录音（注意合法性与安全性）。
- 12315 投诉回执、卫生健康部门受理记录、报警回执。

**路径**
1. 安全与健康优先：出现感染、呼吸困难、剧烈疼痛、视力异常等，立即拨 120 或到正规医院急诊，不先与机构争论。
2. 资质核验：查看医疗机构执业许可证、医师执业信息、产品来源；生活美容机构不得开展医疗美容。
3. 消费投诉：12315 投诉虚假宣传、价格欺诈、退费纠纷；要求书面受理。
4. 医疗监管：向当地卫生健康部门反映无证行医、违规操作、病历缺失。
5. 法律咨询：12348 咨询合同撤销、退款、赔偿与贷款责任；涉及情感胁迫可拨 12338。
6. 心理支持：12356；容貌焦虑、术后后悔、债务压力都需要支持，不必独自承受。

## 八、边界

- 不羞辱整形、不反对医美、不把外貌焦虑当成个人缺陷；问题在贬低、诱导与欺诈。
- 不推荐任何机构、医师、项目或贷款产品；不写贷款套现、规避审核的做法。
- 不诊断真实个人，不对术前术后效果作医学判断；以正规医院意见为准。
- 不鼓励网络曝光真实机构与个人；走 12315、卫生健康部门、12348 与报警路径。
- 不替当事人决定是否手术、是否退款；提供信息与陪伴，尊重节奏。
- 案例为合成案例，只代表共性模式，不对应任何具体个人或机构。
