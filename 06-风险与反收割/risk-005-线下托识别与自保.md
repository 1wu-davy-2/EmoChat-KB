# 线下见面风险:酒托 / 衣托 / 婚托

## 1. 酒托/咖啡托/茶托/饭托
**机制**:团伙"键盘手"在社交平台假借交友恋爱诱骗 → "托女"赴约带至合作酒吧/咖啡厅 → 天价账单,店家与团伙分成。有团伙 20 天骗 72 名网友 21.6 万元。

**识别特征**:
- 网聊不久就主动约见面,地点由对方指定,且总在同一两家不起眼的店;
- 点单不看价格,专点"进口红酒"、果盘、高档饮料;
- 席间热情异常、催促点单;买单后找借口快速离开;
- 账单畸高,酒水以次充好。

## 2. 衣托(及"购物托")
**机制**:键盘手(多为男性)冒充年轻女性网恋 → "衣托女"赴约带至指定服装店高价消费,事后衣物退回店家。得手后不立即拉黑,以"工作忙""不合适"慢慢疏远。

**识别特征**:
- "奔现"当天就带你逛指定商店;
- 用"见你父母前要打扮得体"等话术诱导大额消费;
- 会回赠小礼物(600 元项链换 16650 元消费)降低警惕;
- 见面后真人的谈吐细节与网聊对不上(网聊其实是男键盘手)。

## 3. 婚托/婚介托
**机制**:婚介雇佣"婚托"(出场费可低至 50 元/次)高频消耗客户相亲次数,层层收"资源费""见面费";资料按客户喜好量身修改。有男子花 6 万元,相亲对象全是雇来的演员。

**识别特征**:
- 缴高额会费后被快速安排多次见面,个个无下文;
- 对方资料"完美"且总顺着你的择偶条件说;
- 红娘不断推销升级服务、追加收费。

## 4. 线下见面自保清单
1. **首次见面自己选地点**:知名连锁咖啡厅/餐厅,人多公共场合。
2. **点单先看价格**:对"没写价格的推荐款"保持警惕。
3. **账单畸高**:要求逐项核对,保留小票;怀疑被"托"直接报警。
4. **不带大额现金**,设置单日支付限额,绝不透支信用卡买单。
5. **速判口诀**:网聊热情 → 见面即消费 → 之后迅速冷淡,三连齐中大概率是托。
6. 见面即推销、带店、催买单的,借口离场,不必顾全"绅士风度"。

## 5. 被骗后的补救
1. 立即止损:停止转账,不再信"再投一点就能提现"。
2. 保存证据:聊天记录、转账凭证、账号/链接/收款码全部截图。
3. 报警:110 或反诈专线 **96110**;下载"国家反诈中心"App。
4. 不要因羞耻而沉默——衣托案受害者 1500 余起,正是有人报案才捣毁团伙。
