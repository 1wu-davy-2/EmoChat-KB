# 判断标准:喜欢 vs 收割

## 1. 双向性测试清单(过去 3 个月,如实回答)
1. 她主动**出钱**做过什么?(回请过饭?送过你东西?哪怕很便宜)
2. 她主动**出力**做过什么?(任何需要花时间精力的事)
3. 她主动**关心**过你的情绪吗?(你低落时她做了什么)
4. 她把你**介绍**给朋友/家人/朋友圈了吗?(公开性是重要投入)
5. 她**推进**过关系吗?(约见面、确定关系、规划共同的事)
6. 她收到你的钱物后,**回馈**是什么?(回礼、请客、更热情,还是"谢谢"之后消失)

> 6 项中 0-1 项为"是",同时你的对应项都是"是"——基本确认单向收割。硬标准:"真正喜欢你的女人,收到红包后自己也不会忘记为你付出。"

## 2. 收钱方式分类(她怎么收你的钱)
| 收法 | 信号 |
|---|---|
| 坚决不收、或收了马上补回 | 自尊自爱,关系可期 |
| 收下但不好意思,之后明显加大情感投入 | 正常 |
| 秒收+"谢谢",然后几天不联系(真实案例:520 被秒收,"谢谢"后三天沉默) | 提款机候选,钱与情已脱钩 |
| 收得越来越自然、金额越来越大 | ATM 化进行中 |
| 只在你付出后才热情,付出中断就冷淡 | 交易关系,定价权在对方 |

## 3. 时间线原则(阶段与金钱必须匹配)
- **未见面/未确定关系就开口要钱要礼物**:无论理由多动人,直接判高危。
- **确立关系前的投入,投"共同体验"而非"单向转账"**:"如果你总是转账、发红包,但从不约会,她不会爱上你;钱应该花在共同的经历上。"
- **关系信息量与投入量必须同步增长**:三个月过去关系定义、见面频率、社交圈暴露无进展,但你的累计支出在涨——时间线错配,止损信号。
- **节日敛财密度测试**:正常恋爱一年 3-5 个重要节点;若"必须花钱的节日"每月都有(生日、相识纪念日、100 天、520、七夕、圣诞、跨年……),这是**敛财日历,不是爱情日历**。

## 4. "拒绝后看反应"试金石(成本最低、信息量最大)
得体地拒绝一次非必要索取,然后观察:
- **反应 A(理解/沟通)**:关系照常 → 健康,可继续。
- **反应 B(冷淡/消失/降级)**:她要的是供应商,不是你。**她的离开不是你的损失,是筛选成功。**
- **反应 C(发怒/道德绑架/升级)**:"你就是不爱我" → "考验包装"操纵实锤。
- **反应 D(表面接受,记账报复)**:之后持续阴阳怪气拿这事当筹码 → 长期情感勒索型,高危。

## 5. 两条元原则
1. **看行为,不听语言**:所有"我喜欢你但我慢热"的话术,都敌不过行为统计——她**做了**什么比她**说**了什么重要一百倍。
2. **祛魅**:认清"她的美貌、她的资源,并不属于你"——停止为"可能得到她"这个期权付费。
