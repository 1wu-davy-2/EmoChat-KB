# 典型套路对照表

> 话术均为警方公布或媒体披露的真实剧本(上海警方缴获话术剧本证明为批量使用的固定剧本),用于识别。

| 套路 | 常见话术原文示例 | 背后机制 |
|------|----------------|---------|
| **1. 快速升温** | "感觉跟你聊天好舒服""认识你是我今年最幸运的事""怎么才回我,是不是不想我了" | 按剧本扮演理想型,快速建立依赖(养猪期) |
| **2. 测试式小红包** | "你给我发个小红包,看看你对我是不是真心的""红包金额随意,就是个心意" | 测试服从性,为"投资"铺路 |
| **3. 节日/生日索礼** | "明天520了,别人女朋友都有礼物""你连1314都不愿意给我发,你根本不爱我" | 仪式感+情感绑架;未见面的"对象"指定礼物已被警方定性为新型诈骗 |
| **4. 指定链接买礼物** | "我看中一款手表,你买给我就证明你的心意"(附链接) | 链接指向团伙自建店;按"客户"等级分配礼物价位(520/1314 元) |
| **5. 卖惨借钱** | "我妈突然生病住院,先借我5000""项目资金周转不开" | 编造意外骗借款;有案例累计索要 70 余万 |
| **6. 投资带单(杀猪盘)** | "我在做外汇/炒币,带你赚点零花钱""这个平台有漏洞,稳赚不赔""你先投1000试试,能提现的" | 小额可提现建立信任,大额进金后无法提现、失联 |
| **7. 以礼博礼** | "我给你寄了个手机,你也回我一份心意吧" | 先寄低值礼物钓信任,再索高价回礼 |
| **8. 催促见面消费** | "明天见一面吧,我知道一家咖啡厅特别好" | 酒托/衣托,带至分成场所高价消费 |

## 受骗案例速写(增强辨识直觉)
- 小梅在交友 App 认识自称酒吧老板、晒豪车流水的"00后",对方以"为酒店生意倒账"借款,多次转账后失联。(石景山检察)
- 王先生"奔现"当天被"网恋女友"带进服装店,以"见你父母合不合适"为由购衣买包买表共 16650 元,再被索 4600 元化妆品,合计 2 万余元后失联。(新华网)
