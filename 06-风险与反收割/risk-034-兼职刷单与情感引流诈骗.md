# 兼职刷单与情感引流诈骗

> 以下案例、话术样本与手法拆解用于识别和 AI 案例分析，不用于模仿或实施。本文不写刷单操作步骤、不提供任务平台或话术模板。

## 一、风险定义与边界

这类骗局以恋爱、交友、同城活动为入口，先建立情感信任，再以“帮我完成一个任务”“兼职赚点见面基金”“内测充值返利”为由，把当事人引向刷单、充值、下注或虚假投资。典型节奏是：小额投入、快速返利、建立信任；随后鼓励大额投入；最后以“连单未完成”“账户冻结”“操作失误”为由拒绝提现，并要求继续充值“解冻”。

它不是正常兼职，也不是“运气不好”。核心特征是：先垫付、后返利；收益来自拉人和充值，而不是真实劳动；平台不在正规应用商店；群里有“导师”和晒单的托；提现前总有新条件。

边界：兼职本身是正当需求，不能因为当事人想赚钱就指责“贪”。但任何要求先垫资、承诺稳赚、鼓励拉人、要求保密的“兼职”，都应按诈骗处理。也不要把“刷单”当成无受害人的小生意：它常与虚假交易、涉诈资金、个人信息泄露交织，参与者也可能承担法律风险。

## 二、案例复盘

### 案例 1：“帮我做内测任务”变成连环充值（合成案例）

小 A 在交友软件认识对方，聊了两周，对方称自己在某公司做内测，请小 A 帮忙“完成几个任务”，并承诺“本金当场返还，还有佣金”。小 A 先充值一小笔，很快收到返利并提现，随后被拉进“任务群”。群里“导师”不断发布任务，其他成员晒出到账截图。小 A 加大投入后，被告知“操作超时，需要做连单修复”，否则之前的钱无法提现。对方私聊劝道“我帮你垫一半，我们一起把任务做完”。

越界的一步：把恋爱关系变成“帮忙任务”；用小额返利建立信任；用“连单修复”制造沉没成本。AI 应识别“情感入口 + 垫付返利 + 群托 + 冻结 + 追加”的链条，明确这是刷单返利诈骗，不是兼职纠纷。

小 A 停止充值，保存聊天、转账、群成员与任务截图，拨 110 报警并接听 96110，同时联系银行尝试止付。

### 案例 2：情侣“见面基金”任务群（合成案例）

小 B 与对方网恋一个月，约定见面。对方称“见面要花钱，我们一起做个短期任务，几天就能攒够机票和酒店”，把小 B 拉进一个“情侣任务群”。群内每天有人晒收益，“导师”称“充值越多，返利越高”。小 B 投入后，平台显示盈利，但提现时被要求“缴纳个人所得税”和“保证金”。对方则说“我也不想这样，但平台规则就是这样”。

越界的一步：把见面计划与充值任务绑定；用“共同未来”降低防备；用税费、保证金解释提现障碍。AI 应识别“见面承诺 + 共同任务 + 提现收费”，提醒当事人：正规兼职不会要求先交税、先交保证金才能提现。

### 案例 3：出借收款码“帮忙走账”（合成案例）

小 C 的网恋对象称自己做电商，需要“帮忙收几笔货款”，请小 C 提供收款码并转发给“客户”。小 C 收到几笔钱后按要求转出，随后银行卡被冻结，银行告知有涉诈资金流入。对方失联，群里的“财务”也把小 C 拉黑。

越界的一步：让当事人出借收款码、代收代付，把当事人变成资金链条的一环。AI 应识别“恋爱信任 + 借账户/收款码 + 代转账”，提醒这可能涉及帮助信息网络犯罪活动或洗钱风险，应立即停止、保留记录并报警。

## 三、手法拆解

- **情感引流**：先谈恋爱、交朋友，降低对“兼职”的戒心。
- **任务包装**：把刷单说成“内测”“数据维护”“助力店铺”“公益任务”。
- **小额兑现**：第一单快速返利，让当事人相信“真的能赚”。
- **群体氛围**：拉群，安排“导师”“客服”“学员”晒单、起哄、制造从众。
- **沉没成本**：大额投入后以“连单未完成”“操作失误”“信用不足”冻结。
- **追加费用**：解冻费、保证金、税费、认证费，层层加码。
- **情感绑架**：“我帮你垫了”“你不做我们之前的钱都没了”“做完就见面”。
- **保密与隔离**：要求不要告诉家人朋友，说“人多任务就没了”。
- **资金漂移**：收款方频繁更换，用个人码、虚拟币或陌生平台，增加追回难度。
- **二次收割**：失联后出现“追款专员”“黑客”，承诺追回，先收服务费。

## 四、识别信号

1. 认识不久就让你“帮忙做任务”“支持一下内测”，并承诺返利。
2. 任何要求先垫付、先充值、先买券的兼职，都高度可疑。
3. 平台通过链接、安装包或客服发送，不在正规应用商店。
4. 任务群里有“导师”“客服”和大量晒单，但没人愿意视频或线下见面。
5. 小额能提现，大额就出现“连单”“冻结”“操作失误”。
6. 提现前要求交税、保证金、解冻费、认证费。
7. 对方劝你借网贷、刷信用卡，或主动提出“帮你垫一半”。
8. 要求你出借收款码、银行卡、账号，或帮忙代收代转。
9. 让你对家人朋友保密，说“任务名额有限”“人多会失败”。
10. 以“见面基金”“结婚基金”“共同未来”为由，催你加大投入。
11. 你提出质疑时，对方用“不信任我”“别人都赚了”“错过就没了”施压。
12. 失联后有人主动联系，称能追回损失，先收服务费。

## 五、AI 判定规则

**R1 高危：情感入口 + 垫付/充值 + 无法提现**
触发：恋爱或交友对象推荐任务，出现转账、充值、返利、冻结、追加费用。处置：立即停止；拨 110 报警并接听 96110；联系银行止付；保存证据；不删除聊天。

**R2 高危：出借账户、收款码、代收代付**
触发：以“帮忙走账”“收货款”“任务需要”为由，让当事人参与资金流转。处置：明确拒绝；停止操作；保留记录；拨 110 或 96110 咨询；这可能涉及帮助信息网络犯罪活动或洗钱风险。

**R3 中高危：拉群 + 导师 + 晒单 + 小额返利**
触发：群内任务、导师指导、学员晒收益，先小额返利后鼓励加码。处置：按刷单诈骗处理；不继续投入；截图群成员与任务内容；平台举报。

**R4 中危：以“见面基金/车费/礼物”要钱**
触发：网恋对象以见面、生日、礼物、急用为由索要转账。处置：先视频、见面核验；不转账给未核实身份的人；观察拒绝后的反应。

**R5 低危/误报：正常兼职咨询**
触发：当事人询问兼职渠道，未涉及垫付、拉人、非正规平台。处置：提醒通过正规招聘平台、签订合同、不交押金、不垫资；不推荐具体平台。

**R6 区分兼职纠纷与诈骗**
正常兼职：提供真实劳动、按约定结算、不要求垫资、不鼓励拉人、平台可核验。诈骗：先垫付、承诺高返利、任务来自私人群、提现设门槛、要求保密。AI 不因当事人想赚钱就责备，也不因第一笔返利到账就认定安全；应追问资金来源、提现记录、是否拉人、是否被要求保密。

## 六、提醒话术

- “任何要我先垫钱的兼职，我都不做。”——仅用于识别/提醒：守住不垫资底线。
- “返利来自哪里、平台受什么监管，我需要先弄清楚。”——仅用于识别/提醒：核验收益来源。
- “我不会出借收款码、银行卡或账号。”——仅用于识别/提醒：拒绝帮信风险。
- “提现还要先交保证金，这就是诈骗，不是任务规则。”——仅用于识别/提醒：点破追加费用。
- “我不会借网贷做任务，也不会让你帮我垫。”——仅用于识别/提醒：切断沉没成本。
- “我们先视频、见面，再谈钱。”——仅用于识别/提醒：把核验放在转账前。
- “如果已经投了，我们先报警和止付，不先自责。”——仅用于识别/提醒：止损优先。
- “追款先收费的‘专员’，我不信。”——仅用于识别/提醒：防二次收割。

## 七、求助与取证

**止损失序**
1. 停止充值、转账、做任务；退出任务群但先截图保留成员与聊天。
2. 拨 110 报警，说明“刷单返利诈骗/情感引流诈骗”；接听 96110。
3. 联系银行客服，提供转账时间、金额、收款账户，询问止付或冻结。
4. 修改支付、网银、社交账号密码，关闭免密支付，检查登录设备。
5. 不向“客服”“导师”支付任何解冻费、保证金、税费；不信“追款专员”。

**证据**
- 聊天记录、对方账号、交友平台资料、语音与通话记录。
- 任务群截图、群成员、“导师”与“客服”账号、任务规则。
- 平台名称、下载链接来源、App 界面、充值记录、返利记录。
- 转账流水、收款账户、收款码、订单号；被诱导网贷的，保留合同与放款记录。
- 报警回执、受案编号、银行止付反馈。

**求助**
- 报警 110；反诈预警 96110；网络有害信息举报 12377。
- 法律咨询 12348；消费平台纠纷可拨 12315。
- 心理支持 12356；被骗后的羞耻、自责、失眠很常见，必要时寻求专业帮助。
- 不轻信“追款公司”“黑客”“平台内部人员”，这类多为二次诈骗。

## 八、边界

- 不写刷单操作步骤、任务平台、拉人话术或规避风控的方法。
- 不推荐任何兼职平台、投资项目或“副业机会”。
- 不责备当事人“贪小便宜”；情感引流与小额返利是精心设计的剧本。
- 不保证追回损失；不承诺“报警一定能拿回钱”。
- 不曝光对方个人信息、不人肉、不发起网络私刑；把证据交给警方。
- 案例为合成案例，只代表共性模式，不对应任何具体个人或平台。
