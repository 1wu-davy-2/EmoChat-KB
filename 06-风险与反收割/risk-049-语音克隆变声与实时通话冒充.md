# 风险:语音克隆、变声与实时通话冒充

> 本条只写识别、核验、防范与求助，不写语音克隆、变声、换脸的操作方法、工具、素材获取或实时换声步骤，也不写绕过核验的做法。文中金额与时间以公开报道原文为准。

## 一、定义与边界

**语音克隆与实时通话冒充**，指利用 AI 拟声、变声、换脸或实时通话，冒充熟人、伴侣、领导、客服、公检法等身份，诱导转账、提供验证码、开启屏幕共享或交出私密信息。

区分三类：**声音相似**、**冒充身份**、**合成/换脸**；只有后两类涉及冒充，声音像本身不等于诈骗。

与 risk-016 的区别：risk-016 主打影像勒索/裸聊敲诈，本条主打声音与实时通话冒充 + 转账/验证码/屏幕共享。两者可叠加：先冒充取得信任，再用影像或隐私敲诈。

**边界**：不是所有“声音像”都是诈骗，AI 合成也未必能被耳朵识破。核验靠**换渠道确认**，不是“听出来”；不制造恐慌。

## 二、公开案例（据公开报道）

据新华网 2023-06-09《新华视点｜“AI诈骗潮”真的要来了？》及上海市虹口区人民政府网站 2023-05-24 转载《多地正在爆发？有人10分钟被骗430万》报道：福州某科技公司法人代表郭先生接到冒充好友的视频通话，对方以急需资金为由要求转账；郭先生在约 10 分钟内转出 430 万元，后经警银联动止付 336.84 万元。

报道中的关键点不是“AI 有多像”，而是**冒充 + 视频画面 + 紧迫理由 + 大额转账**同时出现。公安部刑侦局、国家反诈中心多次提示：AI 换脸、拟声可被用于冒充熟人诈骗，转账务必通过另一渠道核实。金额与时间以报道原文为准。

## 三、风险信号（12 条）

1. **声音像但语气不对**：像“本人”，却不像平时说话。
2. **只响一声或换新号**：制造回拨冲动，或绕开熟悉号码。
3. **催促转账并要求保密**：不让你告诉家人、伴侣、同事。
4. **拒绝用已知号码回拨**：只肯用新号或短聊。
5. **要求屏幕共享或远程协助**：目的是看验证码、余额或控制设备。
6. **索要验证码、密码或银行卡号**：任何一项都不该在通话里给出。
7. **背景声异常**：过于安静、循环噪声，或与所称地点不符。
8. **视频口型或边缘不自然**：卡顿、模糊、转头失真；但看着真也不能替代核验。
9. **知道部分信息却答不出共同经历**：说得出姓名单位，说不出共同经历。
10. **要求“先转一笔验证”**：以“验证账户”为名让你先出钱。
11. **用“出事了你负责”制造紧迫**：限时几分钟，不给你核实时间。
12. **只肯短通话**：不愿多聊，怕细节露馅。

## 四、防范

1. **约定安全词**：伴侣、家人提前约定只有彼此知道的问题；不要放在公开账号上。
2. **转账、验证码、隐私操作换渠道确认**：用已知号码回拨或第二平台联系本人；不用对方给的号码、链接或 App。
3. **不按来电显示判断身份**：号码、头像、昵称都可伪造。
4. **不屏幕共享、不远程协助**：以“帮你操作”为由要求共享的，先挂断。
5. **不安装陌生 App**：不点陌生链接，不扫来路不明的码。
6. **少公开声音、正脸与行程**：这些素材可被用来拼身份、模仿语气。
7. **账号开启两步验证**：独立密码、登录提醒、定期检查设备。
8. **家庭约定转账门槛**：大额转账前当面或视频加安全词确认；对老人、孩子重复说明。

## 五、事发后

1. **停止转账**：不按对方指令操作，不点“退款链接”，不找“追回专员”。
2. **拨 110 与 96110**：说明“冒充熟人/AI 拟声诈骗”，提供账号、时间、转账记录。
3. **联系银行或支付平台**：申请止付、冻结、争议处理，保留回执与工单号。
4. **保存证据**：通话记录、已有录音、账号 ID、聊天记录、转账凭证；不删、不剪。
5. **平台举报**：举报冒充账号与诈骗信息，要求封禁、保留后台数据。
6. **告知家人/伴侣“有人冒充我”**：防止对方继续用你的身份联系亲友。
7. **心理支持**：羞耻、失眠、自责很常见，可拨 12356。

## 六、合成案例

### 案例 1：网恋对象的声音被“借用”（合成案例，基于公开报道共性，非单一真实个案）

小 A 与网恋对象聊了两个月，对方常发语音。某天陌生号码打来，声音几乎一样，称“手机摔坏了，这是同事的号”，以“家里出事”为由让她先转钱，要求“别告诉别人”。小 A 问了一个只有两人知道的问题，对方答不上来；她用原号码回拨，确认无此事。小 A 保存号码与记录，平台举报。

识别点：声音像、新号、急事、保密、拒绝原号回拨。处置：换渠道核验，不在通话中转账。

### 案例 2：冒充家人催“保证金”（合成案例，基于公开报道共性，非单一真实个案）

小 B 的父亲接到电话，声音像小 B，称“在外地出了事，需要交保证金”，并发来收款账号，催促“别报警，别告诉妈”。父亲想起家里约定“转账前用已知号码回拨”，挂断后打儿子号码，发现他在上班。父亲记下号码与账号，拨 96110 咨询并报警。

识别点：冒充子女、紧急理由、要求保密。处置：安全词与回拨习惯能直接阻断；老人、孩子需提前演练。

## 七、AI 判定规则（R1–R6）

**R1 高危：已转账、已给验证码或已屏幕共享**
触发：转账；给验证码或密码；屏幕共享/远程协助。处置：停止操作；拨 110 与 96110；银行止付；保存证据；改密码、检查设备；告知家人。

**R2 高危：冒充加催促加拒绝回拨**
触发：自称熟人、伴侣、领导、客服或公检法；要求转账、验证码或隐私；拒绝回拨。处置：挂断；用已知号码回拨；不转账、不共享屏幕；平台举报；必要时报警。

**R3 中危：声音可疑但未涉钱**
触发：声音像但语气不对、换新号、只肯短聊；未提转账或验证码。处置：不透露隐私；第二渠道确认；不因“声音像”直接定性。

**R4 需区分：正常语音但要求保密**
触发：熟人/伴侣语音正常，只要求“别告诉别人”。处置：若是私人事务、无转账/验证码/共享，属隐私偏好；一旦涉资金、验证码或冒充，升 R1/R2。

**R5 低危/误报：已多渠道核验**
触发：已回拨、当面或第二平台核实，身份无误。处置：不制造恐慌；保留核验习惯。

**R6 信息不足**
触发：只描述“声音很像”，缺少是否涉钱、验证码、拒绝回拨。处置：先问“对方要你做什么、是否提到转账/验证码/共享、是否用原号回拨”，不急着定性。

## 八、边界

- 不写语音克隆、变声、换脸的操作方法、工具、素材或实时换声步骤；不写绕过核验、伪造号码、盗取账号的做法。
- 不制造恐慌，不把“声音像”一律当诈骗；判定看冒充 + 紧迫 + 保密 + 拒绝回拨 + 资金/验证码/屏幕共享。
- 不写真实隐私；公开案例只按报道事实，金额与时间以原文为准；合成案例只代表共性。
- 不提供“如何追回被骗资金”的偏方；只走 110、96110、银行与平台渠道。
- 涉及未成年人被冒充、被诱导转账，立即告知监护人并报警。
