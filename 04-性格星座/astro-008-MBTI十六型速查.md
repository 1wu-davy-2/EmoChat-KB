# MBTI 十六型沟通速查表

| 类型 | 沟通风格关键词 | 与其聊天要点 |
|------|--------------|-------------|
| INTJ | 理性、低调自负 | 讲逻辑、给方案,别催情绪 |
| INTP | 冷静中立、习惯提问 | 陪他拆解假设,别要求立即表态 |
| ENTJ | 直接、立场坚定 | 明确分工与时间表,别情绪化指责 |
| ENTP | 能言善道、旁征博引 | 陪玩观点碰撞,别限制弹性 |
| INFJ | 重隐私、支持型 | 先共情后谈事,守他的秘密 |
| INFP | 善解人意、敏感 | 珍视其情绪表达,别急于给解法 |
| ENFJ | 重和谐、爱指导 | 肯定其付出,温和提意见 |
| ENFP | 发散、热情 | 接住热情,邀约新体验 |
| ISTJ | 条理清晰、讨厌乱 | 提前确认安排,别临时变卦 |
| ISFJ | 仁慈、怕得罪人 | 主动问其真实想法,别把善意当理所当然 |
| ESTJ | 批评多于认可、重事实 | 汇报讲数据和结果 |
| ESFJ | 礼数周到、爱照顾人 | 给予反馈与回应,别已读不回 |
| ISTP | 少表态、重证据 | 用行动互动(一起做事),少追问情绪 |
| ISFP | 求融洽、价值观上固执 | 尊重其审美与敏感度 |
| ESTP | 简单明快、重回报 | 换场景边玩边聊,别说教 |
| ESFP | 亲切、怕冲突 | 维持高热氛围,多肯定 |

> 用法:先用 astro-006 四维观察法估计类型,再按本表调整聊天方式;对方自测结果永远优先于你的推测。
