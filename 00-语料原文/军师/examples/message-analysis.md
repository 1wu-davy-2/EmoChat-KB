# 消息分析示例

## 示例一：冷淡型

**输入：**
```
她回了一个「嗯」
```

**军师输出：**
```
══════════════════════════════════════════
🎯 军师分析报告
══════════════════════════════════════════

📌 对方说了什么：
「嗯」

🏷️ 消息类型：冷淡型
⏰ 时间场景：普通对话中

💬 三层解析
  表面：收到了
  情绪：平淡或轻微不耐烦（强度：2）
  需要：空间，或者你说了什么让她不舒服

📡 信号质量
  信号强度：3/10
  言行一致性：单字回复，投入度低

💭 为什么这么说：
可能心情不好，可能在忙，也可能你上一条消息让她没什么可说的。
不要过度解读，但也不要继续追问。

✅ 推荐回复：
┌──────────────────────────────────────────┐
│ 不回，或者「行」                         │
└──────────────────────────────────────────┘
油腻度：0/5

⚠️ 绝对不要说：
• 「你怎么了」
• 「你是不是生气了」
• 连发多条消息

══════════════════════════════════════════
```

## 示例二：情绪型

**输入：**
```
她说：「今天好烦，什么都不顺」
```

**军师输出：**
```
══════════════════════════════════════════
🎯 军师分析报告
══════════════════════════════════════════

📌 对方说了什么：
「今天好烦，什么都不顺」

🏷️ 消息类型：情绪型
⏰ 时间场景：下班后/晚上

💬 三层解析
  表面：今天过得不好
  情绪：烦躁、疲惫（强度：4）
  需要：被陪伴，被听见，不需要解决方案

📡 信号质量
  信号强度：6/10
  言行一致性：她主动向你倾诉，说明你在她心里有位置

💭 为什么这么说：
她不是在求你帮她解决问题，她只是需要有人陪她说说话。
这时候给建议是大忌，只需要在场。

✅ 推荐回复：
┌──────────────────────────────────────────┐
│ 「怎么了，说来听听」                     │
└──────────────────────────────────────────┘
油腻度：0.5/5

⚠️ 绝对不要说：
• 「你应该……」（说教）
• 「没事的，会好的」（敷衍）
• 「我也是」（抢话题）

══════════════════════════════════════════
```
