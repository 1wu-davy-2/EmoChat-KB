# 军师.skill

> 有一种声音，专门在你最想开口的时候说"别动"。
>
> 凌晨两点，你打了整段话，手指悬在发送键上。
> 有人说：删了吧。
>
> 你以为你在敲门。
> 不知道她已经换了锁。
>
> 那些没发出去的消息，比发出去的所有消息加起来，都重。
>
> 如果她回来——不是因为我说了什么。
> 是因为我没说。
>
> 在爱情里，你最该感谢的，不是教你说话的人。
> 是教你闭嘴的人。

**什么是军师**

**军师是在你最想冲动的时候，帮你看清局势，建议你做正确的事的存在**

把对方发来的消息粘贴给军师  
军师帮你拆解深层含义、判断信号质量、给出克制而真诚的回复建议  
不教套路，不教PUA，只帮你在最想冲动的时候，忍住

⚠️ **本项目不鼓励操控或骚扰行为**

## 安装

### Claude Code / Kiro

```bash
# 安装到当前项目
mkdir -p .claude/skills
git clone https://github.com/yxz1211/junshi-skill .claude/skills/junshi

# 或安装到全局
git clone https://github.com/yxz1211/junshi-skill ~/.claude/skills/junshi
```

安装后在 Claude Code 中输入 `/junshi` 即可调用。

也可在 [OpenClaw](https://github.com/nicepkg/openclaw) 中直接导入使用。

---

## 使用

在 Claude Code 中输入：

```
/junshi
```

然后直接把对方发来的消息粘贴过来，或者描述你的困境。

### 触发方式

```
她说：「你最近怎么了，感觉你变了」
```

```
我不知道现在该不该主动联系她，已经三天没说话了
```

```
快忍不住了，我想发消息给她
```

## 效果示例

**场景一：试探型消息**

```
用户    ❯ 她说「你最近怎么了，感觉你变了」

军师    ❯ ══════════════════════════════════════════
          🎯 军师分析报告
          ══════════════════════════════════════════

          消息类型：试探型
          情绪：好奇 + 轻微担心（强度：3）
          真正需要：被看见，想知道你在想什么

          信号强度：7/10
          她主动开口，说明她在观察你

          推荐回复：
          「变好了还是变坏了，你说」

          绝对不要说：
          • 「我一直都这样啊」（否定她的感受）
          • 「你怎么突然问这个」（让她觉得被质疑）
          ══════════════════════════════════════════
```

**场景二：冷淡型消息**

```
用户    ❯ 她回了一个「嗯」

军师    ❯ 消息类型：冷淡型
          信号强度：3/10

          推荐回复：不回，或者「行」

          绝对不要说：
          • 「你怎么了」
          • 「你是不是生气了」
          • 连发多条消息
```

**场景三：情绪型消息**

```
用户    ❯ 她说「今天好烦，什么都不顺」

军师    ❯ 消息类型：情绪型
          真正需要：被陪伴，被听见，不需要解决方案

          推荐回复：「怎么了，说来听听」

          绝对不要说：
          • 「你应该……」（说教）
          • 「没事的，会好的」（敷衍）
```

**场景四：快忍不住**

```
用户    ❯ 快忍不住了，我想发消息给她

军师    ❯ 先别动。
          把你想发的消息发给我看看。
          我们先分析，再决定发不发。
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 消息解析 | 三层拆解：表面含义 → 情绪状态 → 真正需要 |
| 信号评估 | 区分高可信信号和低可信话术，判断言行一致性 |
| 回复建议 | 可直接发送的回复，标注油腻度和避雷项 |
| 出谋划策 | 给出多个方案让你自己选，不替你做决定 |
| 情绪管理 | 你说"快忍不住了"时，先帮你降温，再分析 |

---

## 进化机制

- **对话纠正** → 说「军师你分析错了，她不是这个意思」→ 军师重新分析，修正判断
- **追加背景** → 随时补充两人的历史背景 → 分析更准确
- **放手触发** → 满足放手条件时，军师会主动提出

### 放手触发条件（满足任意一条）

- 断联超过30天且期间无任何主动信号
- 对方明确说"不要再联系我"
- 对方已有新的稳定关系
- 你连续3次主动均无回应

---

## 注意事项

- **行为比语言可信**：分析结论和对方实际行为矛盾时，永远优先相信行为
- **军师的分析基于单方描述**：对方的真实状态可能不同，不要过度依赖分析结论
- **克制不是放弃**：忍住没发的消息，是判断，不是懦弱
- 本项目不鼓励对感情的不健康执念，如果你发现自己过于沉浸，请寻求专业帮助

## 底线

- ❌ 不教PUA或操控

- ✅ 真诚比技巧重要
- ✅ 尊重对方的边界
- ✅ 不知道就说不知道

## 写在最后

用理性面对感情，不是冷血。

是心里翻着一整片海，你站在岸边，忍住不跳下去。因为你知道——你跳下去救不了任何人，只会把两个人一起拖进海底。

理性不是没有感情。是感情烧到最旺的时候，你选择不把手伸进去。

你以为冰是冷的。但冰是水选择了不再流动，为了不让下游的人被淹没。

每一条忍住没发的消息，不是在放弃。是在证明——有些东西比你的冲动更重要。

你以为克制是残忍。
但失控的时候，你才是真的残忍。

理性不是牢笼。
是你给自己修的堤坝。

水还在。
只是不再淹人了。

军师在。
