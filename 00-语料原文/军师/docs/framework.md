# 分析框架详解

## 六步分析协议

### 第一步：消息分类

拿到消息，先判断类型：

| 类型 | 典型特征 |
|------|---------|
| 试探型 | 问在干嘛、问近况、旁敲侧击 |
| 关心型 | 问吃饭没、累不累、注意身体 |
| 分享型 | 发图片、发链接、分享日常 |
| 冷淡型 | 嗯、昂、哦、好 |
| 抗拒型 | 不用你管、我自己来 |
| 推开型 | 我们只是朋友、别这样 |
| 情绪型 | 抱怨、吐槽、说丧气话 |

### 第二步：三层解析

任何一条消息都有三层：

- **表面**：字面上说了什么
- **情绪**：发这条消息时的情绪状态
- **需要**：她真正需要的是什么

情绪类型参考：
开心 / 撒娇 / 难过 / 生气 / 焦虑 / 期待 / 平淡 / 试探 / 受伤

真正需要参考：
被看见 / 被夸认可 / 被陪伴 / 被哄 / 被安慰 / 被主动 / 被逗笑

### 第三步：信号质量评估

**高可信信号（Costly Signal）**
- 记住你说过的话
- 主动调整自己的计划
- 在你身上花时间和精力

**低可信信号（Cheap Talk）**
- 零成本话术："我想你""有空再约"
- 说了但没有行动跟进

**言行一致性检验**
她说的 vs 她做的，矛盾时优先相信行为。

### 第四步：拒绝识别

| 类型 | 特征 | 应对 |
|------|------|------|
| 直接拒绝 | 明确说不 | 尊重，退出 |
| 软拒绝 | 模糊语，无替代方案 | 不追，等信号 |
| 延迟拒绝 | 回复频率持续下降 | 已在退出，不要追 |

### 第五步：语言学分析

违反合作原则时，注意推断含义：

| 违反类型 | 典型表现 | 推断 |
|---------|---------|------|
| 量的准则 | 极短回复"嗯嗯" | 敷衍，不想继续 |
| 关系准则 | 话题突然转移 | 回避，不想谈 |
| 方式准则 | "再说吧""看情况" | 刻意模糊，大概率不想 |

### 第六步：安全感检验

每条回复发出前必问：
- 这条消息会不会让对方感到被质疑？
- 这条消息会不会让对方感到被施压？
- 这条消息会不会让对方觉得不安全？

有任何一条是"会"，重写。
