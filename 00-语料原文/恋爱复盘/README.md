# 恋爱复盘.skill

单次聊天的胜负，决定不了什么。**跨案例的重复模式，才决定你以后每一段感情。**

「恋爱.skill」回答的是：她这句话怎么回、这段关系怎么推进。

「恋爱复盘.skill」回答的是：**为什么每段感情都走到差不多的地方？问题到底在她，在我，还是在这段关系的结构？我下次能不能靠自己看出来？**

它不替你聊天。它让你不再需要每句话都问 AI。

---

## 这是什么

一套 AI 可读的**跨案例恋爱复盘框架**：读取你多个已经完成的恋爱案例（聊天记录、线下经历、已有分析报告），通过 18 个阶段的分析流程，识别你**稳定的**行为模式、认知偏差、情绪循环和决策习惯，最终沉淀为你的**个人恋爱操作系统**和**长期恋爱档案**。

它本质上是一份精心编排的 Markdown 主文件（SKILL.md），不依赖任何平台——只要 AI 能读 Markdown，就能用它。

### 核心理念

| 理念 | 说明 |
|------|------|
| **分析对象是"我"** | 不分析某一个女生，分析跨案例的你自己 |
| **证据分级** | 原始聊天记录 > 当事人陈述 > 旧 AI 分析报告；禁止"AI 根据 AI 的结论继续推理" |
| **不贴标签** | 单个案例的行为不构成稳定人格标签；模式分 A/B/C/D 四级可信度 |
| **优势也复盘** | 不只找问题——每个优势都标注"最佳区间"：主动，适度是优势，过度是追逐 |
| **反偏差自检** | 11 项输出前强制自检：不许把所有问题归因于你，也不许全归因于她 |
| **去依赖化** | 终极目标是让你自己能识别健康关系、失衡关系、不值得投入的关系 |

## 它能帮你解决什么

| 你现在的状态 | 它能做什么 |
|---|---|
| "几段感情都无疾而终，我不知道问题在哪" | 跨案例比较 → 识别重复的行为/情绪/决策模式 |
| "我总觉得自己在感情里越来越不像自己" | 人格漂移分析 → 回答"我喜欢一个人以后，最容易失去什么" |
| "每次对方一冷我就焦虑、就加倍主动" | 触发链拆解 → 识别完整的焦虑循环并给出情绪急救协议 |
| "之前的 AI 分析，到底靠不靠谱？" | 强制审查旧报告 → 输出《前次分析修正表》，标注过度解读和归因偏差 |
| "我不想每次都问 AI 怎么回消息" | 个人恋爱操作系统 → 十项可执行原则 + 红黄绿信号系统 + 自检清单 |
| "以后遇到喜欢的人，怎么知道该不该投入？" | 阶段风险地图 + 投入控制系统 → 什么时候推进、等待、退出 |

## 十八个阶段

```
第 0 步  案例完整性检查（证据分级，缺原始记录则降级）
第 1 阶段  分别理解案例（先理解，不急着找问题）
第 2 阶段  跨案例比较（20 个维度找五类重复）
第 3 阶段  识别稳定个人模式（A/B/C/D 四级可信度）
第 4 阶段  建立恋爱触发链（完整焦虑循环识别）
第 5 阶段  分析"人格漂移"（喜欢一个人后我失去了什么）
第 6 阶段  问题归因（我 / 她 / 关系结构 / 现实环境）
第 7 阶段  认知偏差分析（12 项常见偏差逐项核查）
第 8 阶段  稳定优势分析（最佳区间概念）
第 9 阶段  三个最高杠杆问题（重复 × 影响 × 可改变）
第 10 阶段 恋爱阶段风险地图（七个阶段）
第 11 阶段 红黄绿信号系统（七项核心依据）
第 12 阶段 个人投入控制系统（自然投入 vs 焦虑投入）
第 13 阶段 情绪急救协议（不在情绪最高点做决策）
第 14 阶段 个人恋爱操作系统（十项可执行原则）
第 15 阶段 下一次恋爱自检清单（十个问题）
第 16 阶段 长期恋爱档案（支持未来增量更新）
第 17 阶段 重新审查过去的 AI 分析（强制步骤）
第 18 阶段 心理学框架使用规范（有证据、能解释、有帮助）
```

最终输出《我的恋爱行为模式与个人关系操作系统》（十七章）+《我的长期恋爱档案》+《我的恋爱模式摘要》（500~800 字）。

## 安装

```bash
git clone https://github.com/<你的用户名>/lianai-fupan.git
```

把整个目录放到你所用工具的 skills 目录，AI 会自动加载 `SKILL.md` 作为入口。

### 建议搭配

本 Skill 是 [恋爱.skill（yuehui-tegong）](https://github.com/mountainwaterr/yuehui-tegong) 的上层复盘工具，二者上下游关系：

- **恋爱.skill**：单案例分析——聊天话术、约会策划、信号解读、推进策略
- **恋爱复盘.skill**（本仓库）：跨案例复盘——稳定模式、认知偏差、个人操作系统、长期档案

单案例用恋爱.skill 产出分析报告；案例攒多了，用恋爱复盘做跨案例研究。

## 使用方式

直接把你的多个案例交给 AI，它自动进入复盘模式：

```
# 跨案例复盘（自动触发）
"这是三段感情的分析报告和聊天记录，帮我复盘我的恋爱模式"

# 模式识别
"我为什么总在暧昧期搞砸？帮我根据过去几段感情总结"

# 档案建立与增量更新
"建立我的恋爱档案" / "新的一段结束了，结合旧档案帮我对比这次有什么不同"

# 显式调用
$恋爱复盘
```

单案例问题（"她这句话怎么回"）会分流回「恋爱.skill」，本 Skill 默认禁止生成聊天逐字稿。

## 输出风格

温暖、清醒、直接。允许指出你的问题，但不制造羞耻感。不 PUA、不操控、不冷暴力、不把恋爱简化为博弈。

**这个 Skill 的成功标准，是你越来越少地需要它。**
