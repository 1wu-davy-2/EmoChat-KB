# 处境画像：休闲关系长期参与者

> 这是一张处境画像，不是标签。它描述一种已经稳定下来的关系安排，帮当事人看清自己站在哪里；具体的人永远优先于画像。

## 一、这张画像描述什么

指在一段时间内（通常半年以上）持续处于 FWB、casual 或类似低承诺关系中的人。原因可能很不一样：事业忙、刚分手、生活阶段不匹配、明确不想要承诺、暂时不想恋爱，或者只是没有遇到想认真的人。同样是“长期休闲关系”，有人松弛，有人耗竭，差别不在形态，在是否透明、是否可退出。

## 二、处境特征（10 条）

1. 关系长期不定义，靠默契运行，谁都不先开口。
2. 性友谊并存，但“朋友”的部分在慢慢流失。
3. 对外不公开，在共同圈里被介绍为“朋友”。
4. 多线或排他不清：没谈过，就按非排他处理。
5. 动情风险随时存在，时间越久越难说。
6. 朋友与性的边界模糊：借宿、深夜聊天、共同群。
7. 节日与周末的孤独感更明显，临时召唤变多。
8. 年龄增长与婚育压力，家人开始追问。
9. 退出成本上升：共同圈、住处、生活习惯。
10. 被朋友问“你们到底算什么”时，答不上来。

## 三、常见需求与担忧

需求：稳定的陪伴与亲密、被尊重、不被当工具、保留自由、不被逼着定义。

担忧：先动情的人输；被更年轻或更新鲜的人替代；被共同圈议论；检测与健康；提出结束就失去朋友；年龄越大越难退出。

## 四、关系状态与需求核验

- 我想要什么：陪伴、性、情感支持，还是稳定的生活协作？
- 我能给什么：时间、情绪、排他、公开，分别能给到哪一层？
- 我不能给什么：哪些是我明确不给的，我有没有说过？
- 我动情了吗？如果动了，我打算说，还是设一个期限？
- 我想转正吗？还是只是不想失去现在的便利？
- 这只是暂时状态，还是我已经默认它会一直这样？
- 对方的答案和我一致吗？不一致的部分，我们谈过吗？

## 五、沟通适配

- **直接、低羞耻**。不用“你会不会觉得我烦”开头，直接说事。
- **不逼承诺**。谈边界不等于要名分；可以只要一个具体的频率与规则。
- **用“我”开头**。“我最近会想你”比“你到底怎么想的”更容易被接住。
- **给选择**。“继续但排他，或者就此结束”比开放式考题更清楚。
- **定期复核**。每两三个月，或生活变化时，重过一次排他、防护、频率、情感边界。

## 六、常见雷区

- 把“不承诺”当成“不用负责”：不承诺未来，仍要对当下诚实。
- 用“自由”掩盖隐瞒：自由是双方知情，不是单方面不被追问。
- 用“朋友”名义占用对方：享受着恋人式的投入，却说“我们只是朋友”。
- 不敢谈结束：用渐淡、忙碌、失联代替一句话。
- 用“我们不一样”跳过防护与检测。
- 把对方的动情说成“玩不起”，把自己的动情说成“被勾引”。

## 七、边界（不是标签）

不病理化：长期休闲关系可以是诚实、松弛、双方满意的选择。也不美化：如果靠隐瞒、施压、占用维持，那不是“自由”，是转嫁成本。

- 与 **persona-029（暧昧未定义）** 的区别：那里是还没谈过的模糊状态；本卡是已经形成稳定模式的长期安排。
- 与 **persona-037（交易型）** 的区别：那里资源是关系准入条件；本卡不以钱、房、机会换亲密。
- 与 **persona-038（权力差下位者）** 的区别：本卡不必然有评价权或资源控制；一旦出现，按那张卡处理。
- 与 **persona-041（准社会）** 的区别：本卡是现实互动，不是单向的虚拟亲密。

## 八、AI 使用规则

1. **不贴标签**。不说“你就是玩咖”“长期这样会废掉”，也不说“这才是成年人该有的样子”。
2. **不劝分也不劝和**。呈现代价与选项，由用户决定；出现欺骗、胁迫、暴力时明确止损。
3. **不生成留人话术**。不提供“如何让对方离不开你”“如何用身体换承诺”的方法。
4. **健康优先**。非排他或排他不清时，把防护、检测、告知讲在前面。
5. **不病理化也不美化**。尊重阶段性选择，同时指出隐瞒与占用。
6. **识别权力差**。住房、收入、交通、共同圈、工作关系一旦不对称，转 method-138。
7. **危机转介**。威胁、影像、跟踪、暴力：拨 110；情绪危机拨 12356。

## 十、合成案例

> 合成案例（基于公开报道共性，非单一真实个案）。只代表常见模式，不对应具体个人。

小 N（34）维持了三年的 FWB。平时各忙各的，节假日对方会来她家，春节和生日从不出现。她一度觉得“这样也挺好”，直到发现自己开始为“他今年在哪过年”失眠。她做了一次核验：想要的是稳定陪伴，能给的是不公开、不排他，不能给的是“随时被叫”。她把这些说给对方，对方说“我以为我们一直很轻松”。

两人重新定了频率与节日安排，试了三个月，对方两次临时取消。小 N 提出结束，停联两个月，把共同朋友的口径统一为“我们聊过，觉得不合适”。

要点：长期不等于稳定；松弛感可能只是没人敢问；核验之后要么重谈，要么结束。
