# 处境画像:暧昧未定义与 situationship

situationship 指双方有亲密互动，却没有明确关系定义的状态：会聊天、会见面、可能上床，但不确认是不是男女朋友，也不约定是否排他。它可能是过渡，也可能是长期安排。问题不在“没定义”本身，而在双方对它的理解是否一致。具体的人优先于画像。

## 处境特征
- 关系停在“聊得来、会见面、有身体接触，但没名分”的区间。
- 投入可能不对等：一方当恋爱经营，一方当低承诺陪伴。
- 多线约会常见：未约定排他时，对方可能同时见别人，这不自动等于欺骗。
- 不确定性有吸引力：新鲜、自由、低压力，也带来焦虑、猜测与消耗。
- 性关系与情感期待容易错位：身体亲近被误读为承诺。
- 回避定义的原因多样：刚分手、工作忙、怕负责、享受现状，或确实没那么喜欢。
- 沉没成本让人难退出：等得越久，越不愿承认没有进展。
- 也有人确实满足于低承诺关系，只要双方透明，就不构成问题。

## 关系状态与需求核验
- 先确认自己的目标：要排他恋爱、要稳定陪伴，还是也能接受低承诺。
- 直接问关系状态：“我们现在算什么？你是否还在见别人？”允许对方诚实。
- 区分“没定义”与“已约定”：没有明说排他，就按非排他处理，直到双方确认。
- 看行动一致性：是否主动约、是否介绍朋友、是否在困难时出现。
- 确认性健康与同意：是否使用防护、是否告知其他伴侣、是否尊重撤回同意。
- 设定观察期与节点：给彼此时间，但不超过自己可承受的范围。
- 如果对方说“顺其自然”，追问一次具体含义：是不排斥发展，还是不想改变现状。

## 沟通适配
- 用“我”开头，不审问：“我发现自己想要更明确的关系，你呢？”
- 给对方诚实空间，也给自己退路：“如果你现在不想定义，我也能理解，但我会按自己的节奏调整。”
- 不在深夜、酒后或刚发生关系后逼问承诺；选平静、私密、清醒的时机。
- 提出具体期待：见面频率、是否排他、是否公开、未来几个月怎么走。
- 对方回避时，追问一次即可，然后看行动，不反复索要口头保证。
- 如果答案是不定义，明确自己的选择：留下、降级或退出。
- 退出时简短、体面，不羞辱、不报复、不公开对方隐私。

## 常见雷区
- 把“没定义”自动当排他，然后用“你出轨”指责对方。
- 用性、陪伴或礼物换承诺，越投入越不敢问。
- 玩“谁先认真谁输”，用冷落、试探、故意让别人吃醋来争主动。
- 对方回避就加倍付出，把不确定当成需要更努力。
- 同时欺骗多方，隐瞒其他关系或性健康风险。
- 用“我们只是朋友”否认已经发生的亲密，逃避责任。
- 把对方的犹豫当“再等等就会答应”，无限期消耗自己。

## 边界（不是标签）
- 未定义关系不是道德缺陷，但透明与不欺骗是底线。
- 同意可以随时撤回；不因“都到这一步了”就默认继续。
- 双方都可以说不：可以拒绝低承诺，也可以拒绝被逼着承诺。
- 不把对方当“备胎”，也不把自己当等待被选的人。
- 与 persona-015 的区别：那里对方已有明确伴侣；这里是双方都未定义，但同样需要核验。
- 与 user-007 的区别：user-007 是用户自己的需求画像，这里描述的是关系状态。
- 具体的人优先于画像：有人很快确定，有人需要更久，关键是诚实与一致。
